# RNA 特征小实验建议

## 问题

在接入完整 FewClick Phase 3 之前，验证配对空间 RNA 是否为 H&E/形态细胞特征提供可量化的附加信息。

## 查阅依据

- `docs/数据集情况/【7】基因-病理-疾病相关数据.csv`：COAD 的 Xenium 数据被登记为配对的 H&E/DAPI、空间转录与蛋白数据，粒度为细胞级。
- `/nfs-medical3/fyx/PKU_DATA/Xenium/COAD`：已检查到 `HE.tif`、细胞边界、带 `cell_id` 的转录本表和细胞级空间坐标。
- `benchmarks/v4/phase_3_cell_region/src/cells.py`：当前基线的细胞输入由位置、面积、核类别和 XCellFormer 表征构成。

## 建议

先运行一个小窗口、空间分块交叉验证的表征验证。以未参与输入构建的一部分基因形成 RNA 分子标签，比较：

- 仅 H&E/形态特征；
- H&E/形态特征加其余 RNA 特征。

这不等价于最终 FewClick 分割提升；它只检验 RNA 特征是否携带独立且可泛化的细胞级信息。

## 备选方案

- 直接接入完整 Phase 3：结论更接近最终任务，但需要完成跨数据集适配与更长训练。
- 仅做 RNA 聚类可视化：成本最低，但不能比较 RNA 对预测任务的增益。

## 预期收益与风险

- 预期：获得可复现的细胞数、空间坐标、RNA 表征维度和相对验证指标，为是否开展完整消融提供证据。
- 风险：RNA 标签来自同一数据集，不能证明跨癌种或最终分割收益；空间邻近细胞可能造成乐观估计，故采用四象限空间分块验证。

## 验收标准

输出可视化、细胞清单、运行元数据和指标。若融合特征的空间分块平均 macro-F1 与 balanced accuracy 均较形态基线至少高 `0.02`，标记为“通过初步表征门槛”；否则标记为“不支持继续直接接入”。
