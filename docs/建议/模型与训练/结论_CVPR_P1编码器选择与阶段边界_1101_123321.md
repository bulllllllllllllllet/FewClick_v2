# P1编码器选择与阶段边界

依据原阶段路线、逐项审计p1_obligation_audit_1101_122702、三encoder公共decoder、完整935对、双seed细胞/冻结修订、Phikon有限适配、颜色敏感性与原生XCell分环节cost。问题是冻结后续机制研究输入，而不是追认未通过的分割升级。

图像工作底座冻结Phikon-v2，使用既有单fine512/1024×32×32 FP16空间cache和全部原对照。原因是固定公共decoder下local优于另两臂、有匹配成本和完整迁移诊断；其初始absent FPA失败与mixed任务代价均保留，不能声称全面优于SAM。最后block联合适配无增益，不替换为joint权重、不扫超参。P2具体decoder初始化/训练方式须另行事前登记，不能偷偷取最好checkpoint。

细胞机制研究候选冻结LEMON：原10µm/40px中心crop、同InstanSeg实例/坐标、每图最多255、1737图304747保留细胞。保留既有train-only234056细胞PCA64和标准化；val拟合0。它在粗粒度BC/TC probe和固定颜色扰动有优势；两seed连续残差与冻结修订均未证明可靠组织分割收益。因此这是P2表示假设的输入选择，不是原生XCell替换验收；原XCell数据、mask/context先验和对照全部保留。

P2按原路线比较同LEMON/同图像底座下连续表示、train-only K128固定词表、可学习词表。正式执行前必须冻结统一融合decoder、参数容量/初始化、训练任务/预算、损失、定量停止规则和真实门控；不能把P1失效残差配方原样再跑，不允许以细胞分类代替组织mask。无词表收益则保留连续，不为贡献强凑升级。

成本账本范围明确：image1737缓存墙钟与字节、中心crop暖机后含读取/预处理cells/s、native四场654细胞分环节成本分别报告。native单次检测不与暖机feature中位数合成严格端到端速度。不是等FLOPs、外部染色域或WSI在线延迟。原数据空间块split/脂肪监督、local与remote分表、query无GT输入、XCell内部训练与上游公开预训练来源保持。

P1只允许作为有局限的encoder筛选阶段完成。P2/P3受控机制、P4原生SAM系统强基线与WSI质量效率、P5独立确认及多seed、P6论文证据仍是完整goal必需事项，不豁免，不宣称当前超过SAM。
