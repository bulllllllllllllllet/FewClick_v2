# 组织边界像素细化开发对照

- 问题：用户要求暂停细胞探索，尝试组织边缘分割优化。
- 依据：冻结 v4 `joint_model.py`、Phase2 `model.py`、`joint_losses.py`、联调台账；全预算 J5 epoch4 validation Boundary F1@2px=0.314241。像素概率为双线性上采样 assignment 与 region 概率的混合，没有独立 RGB 像素修正路径；原模型已有0.1权重边界损失。
- 推荐：冻结全预算 J5 epoch4，以标准化 H&E、原概率和不确定性为输入，增加零初始化、最大±2 logit 的轻量卷积残差头，仅在预测边界8px邻域或原概率[0.2,0.8]内允许修改。门控不读取GT。不同时改细胞、region或prompt模型。
- 对照：原始冻结模型；像素细化+BCE/Dice；相同初始化/顺序的像素细化+BCE/Dice+GT边界带BCE+原边界损失。GT仅用于训练监督和评价。首轮不宣称复现PointRend。
- 参考：PointRend, CVPR2020，https://openaccess.thecvf.com/content_CVPR_2020/html/Kirillov_PointRend_Image_Segmentation_As_Rendering_CVPR_2020_paper.html （局部高细节解码动机，不作为本实现性能证据）。
- 替代：仅增加原边界loss可能受region表达分辨率限制；解冻assignment会改变提示几何，首轮不采用；高分辨率深层特征细化成本较高，留待本轮诊断。
- 预期收益：检验细节输入/独立像素自由度是否改善轮廓；收益未证明。
- 风险：RGB核边缘不同于组织语义边界；预测带外错误不能纠正；原10x图像的物理分辨率不提升；旧模型历史暴露与小样本过拟合。
- 验证：真实loader/模型前向/反传/保存严格重载先4 train/2 val smoke，再128 train/64 val、4 epochs配对开发实验；阈值0.5；BF1@1/2/4、两侧边界带IoU@2/4、Dice、点击符号违约及带外修改数。边界缺失预测计0，双方无边界记不可评估，不只保留有预测轮廓的样本。
- 推进条件：相对冻结基线BF1@2与边界带IoU@2均改善，Dice不低于-0.005，已有提示符号违约不增加；以val选checkpoint，不读取test。仅开发性结论，后续更大独立验证与人工看图。
- 数据：既有空间split `tissue_spatial_split_0922_001235`，完整三尺度footprint隔离；同病例允许跨split，历史初始化可能见过val。现有台账和工作树含无关未提交内容，保留。
