# 区域证据、匹配与查询细化三步实验

状态：planned。用户询问具体做法；本轮完成方案，不启动模型训练。依据goal、CVPR registry、同片9500三模型运行记录、1111_110224剩余瓶颈诊断及实际模型/loss代码。权威当前run保持不变。

## 问题与控制

研究目标：支持3正2负、同片不同patch零query人工提示，提升大组织迁移Dice，同时保留完整类别、缺失目标误报和WSI缓存优势。原Few large73.8085%、FPA6.7115%；SANSA77.2201%、14.7866%。前者是本轮同预算机制对照，不自动取代早期已冻结主模型或修改旧晋升门槛。

原9500实际队列保持：local4000、CRC同片present5000、absent500，2375update×4，seed20261103，Phikon冻结、三视野、原episode loss/学习率不变；完整4x隔离不变。损失含query原mask_loss、remote支持mask .25、支持点击 .1及assignment正则。训练已有支持GT监督不等于允许推理读GT。

三个阶段均最终是一套模型，不按query GT大小/类别挑模型。新输入只取支持/查询图像及已有支持点击。所有参数/缓存/耗时变化单独记录。每个正式候选从公共初始化训练一次完整9500，不接着前一候选累加训练后与2375步对照比较。既有原Few/SANSA仅在数据、权重、代码、阈值完全一致时复用接受结果。

## 0：先固定诊断（执行时先于改模型）

从现有训练池按类、support大小、query大小、present/absent确定最多128个训练诊断任务，保存ID/抽样SHA；保留四域功能检查的原32任务。不足槽位明确记录，不借用评估数据补齐。对原Few和SANSA输出support预测、query预测、点击、GT、FP/FN；量化support Dice/召回/正点保留，query大目标覆盖与2µm边界误差。开发集既有诊断只用于报告，不用它挑阈值、提示或checkpoint。

须回答：支持区域本身是否差、支持预测正确时迁移是否仍差、query误差集中边缘还是内部漏区域。必要的support-GT替换只能作为train-only更强监督机制诊断；替换引起分布变化，单次无收益不能证明支持信息无关。不得把GT支持mask带入少点击主结果。

## A：区域证据，先保留原匹配方式

最小改造：先用现有本图解码路径预测support概率p（region+原SignedMatcher），然后将support dense embedding按固定4x4网格、正负分别加权池化，每种最多16个区域descriptor；原3正2负点descriptor仍保留。

首个候选的确定性权重建议w+=(max(2p-1,0))²，w-=(max(1-2p,0))²；接近.5的像素权重自然降低。权重小不代表真实不可靠，必须实测校准和错误传播。p在池化权重路径detach，保留原支持mask监督，避免第一轮同时引入额外query→support mask梯度机制。数学零mass槽位按显式valid mask排除，原点仍始终存在；数值eps仅作除零保护并在工程合同固定。

区域descriptor与原点一同进入原64维投影/正负max与mean相似度，仍输出原7通道、原1x1残差头。原region task和query图解码不变。这样A主要测试“点的局部证据扩展成多个区域证据”，无需外加SAM，不引入额外训练标注或新loss。max/mean受descriptor数目改变的影响属于A机制，必须披露，不能称纯support mask质量消融。

先验风险：错误support区域被放大、正常间质混腺体、脂肪背景误报。按support小目标分层和完整类别/FPA检查；必要时用固定train-only打乱/屏蔽区域证据诊断其贡献。若support质量差且A无收益，停在此处定位support；不直接加更复杂memory。

## B：匹配，保留A的证据形成方式

A有质量证据后，固定同一组正/负区域descriptor，引入一层小型query-to-support cross-attention：query空间特征作Q，support区域descriptor作K/V，保留正负sign和区域几何；得到每个query位置对应的支持内容，而不是只剩max/mean标量。

首个B保留原SignedMatcher，把attention输出通过零初始化输出层作额外logit残差，以便初始行为等于A并容易观察真实新增贡献。只改交互，不同时换encoder/解冻底座/加对比loss/改负任务比例。具体head数/维度/参数预算在实现前写入合同，不边看开发结果边扫参。

检查正常间质–腺体、浆膜–肌肉及脂肪–背景的FP/FN；要求正负支持交换、记忆内容扰动能够改变输出，且不是全部抑制成空mask。A失败不意味着所有attention路线失败；若要做原点B-only，应作为重新登记的独立假设，不自动续跑。

## C：查询细化，先确认定位证据可靠

以A+B为父架构，新增小型、任务条件化的query残差细化头。输入query浅层RGB/图像特征、粗logits、B的支持匹配上下文；输出细化logits。高分辨率路径先限定128/256网格（具体层宽在工程合同冻结），零初始化末层，初始等于父架构。全图统一应用；不靠GT判大小，不做无条件膨胀/填洞。

首轮仍用原loss，避免同时修改边界系数。图像浅层特征可缓存；support相关特征每次点击更新。报告准备成本、每次点击成本、每query延迟/显存及缓存字节，防止以大幅WSI代价换分数。

首先看脂肪内部召回、上皮/腺体BF1及误报。边界变漂亮但Dice不涨、内部错分未修复，均不足接纳。历史PixelResidual已未晋升，本轮须以B的空间匹配上下文为新增条件并作受控对照，不能原配方重跑后宣称新机制。

每候选：真实四组forward/loss/梯度/冻结状态/缓存一致和fresh optimizer恢复→原32train任务256步功能门控→全新初始化2375步→完整11000同片评价及磁盘mask独立复算。门控阈值沿用当前协议，不因失败放宽；新增机制还要有效梯度、支持依赖及边界/记忆路径真实使用证据。数据/损失没变也须验证support-first路径无循环、无跨任务缓存污染、query GT不进推理。

继续研究的证据：完整大目标Dice较直接父架构改善，完整类别/脂肪/淋巴没有严重代价，absent FPA不能靠持续上升换召回；目标以不高于新9500原Few6.71%为方向，而最终晋升依旧按历史冻结守门逐项核对。已有原Few新旧FPA超原守门的问题保留，绝不把6.71%变成自动放宽后的正式通过线。报告配对空间聚类不确定性、同片依赖和单seed局限，不用微小涨点宣称显著或保证反超。

研究失败时保留原模型及全部产物，更新goal/registry/run/status，不自动改变配额、增加seed或重跑旧失败架构。GPU并行只用于已授权独立工作；A/B/C存在依赖，不能为占满GPU而同时盲训练。
