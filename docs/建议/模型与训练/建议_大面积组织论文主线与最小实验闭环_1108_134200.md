# 大面积组织论文主线与最小实验闭环

用户最新方向：论文重点写大面积组织，小目标改进移至局限与未来工作，不再以小目标结构搜索作为下一步主线。保留核心同片少量支持点→远端query零人工点，跨片队列保持终止，无新seed。依据已接受同片11000任务及75片聚类分析、当前goal/registry/P4–P6缺口。方法型论文，创新围绕可复用支持信息和远端组织匹配展开，不能仅把优于特定SAM桥写作全部SAM上限。

主张边界：当前“大目标”指标按目标占512查询视野面积>=20%定义，属于已观察数据的事后分层；不等于原生WSI绝对大区域，也不等于排除某些组织类别。Few59.80/无matcher47.02/SAM桥32.38为task mean，不能代替全任务class macro32.45/23.08/19.51。全量和各面积分层/失败均需保留，正文或补充清楚报告；不得仅挑高分图、根据GT在推理时决定使用模型。后续冻结面积定义，并在未用于选模的空间验证上确认；不要求患者互斥，保留空间政策。

推荐最小剩余闭环（不在本轮自动启动）：
1. 优先执行既有SHA固定3片完整域工程/安全区域质量与持久特征缓存：首片准备、存储、首次预测、同一完整域追加支持点击、解码/融合/输出分段实测。边界缺口和train/support重叠位置只能工程展示，不计验证质量；不称单窗口22ms为全片点击时间。完整域结果必须独立mask/GT复算，同片prompt协议公平对比。
2. 同片交互预算和支持位置稳健性：1/3/5正点等固定嵌套前缀、明确负点预算，统计大面积与全体结果。重复支持位置是提示稳健性，不当新增独立图像。
3. 同片大面积机制证据与强参考：保留full/no_match主要受控消融；若声称负证据机制，则用已有no_negative权重补同任务只读评估；已有细胞两接入负结果保留，不重开sweep。必要的闭集组织分割参考或合适迁移基线先审计同目标训练/输入账本，不能将旧不同数据baseline直接放新主表。
4. 候选和主要终点固定后，用符合既有空间划分、未反复用于选模的同片区域独立确认大面积收益，给按片区间、逐类和全量结果。当前统计区间不是新独立确认。
严格类别留出(坏死/肌肉/黏液)不再作为近期强制大训练；若论文声称“未见组织类别泛化”则必须补严格训练排除与同片测试，否则限制主张为已监督类别的用户指定匹配。细胞词表和小目标新模块移至deferred。
