# 组织边界不确定像素细化

- 问题：同96k更新预算3k/32轮BF1=0.557040，12k/8轮=0.555609，配对差+0.001432、95%区间[−0.002244,+0.004621]；未证实12k数据量的独立优势。下一步优先增加边界细节自由度。
- 依据：系统方案184115、续跑清单200033、同预算报告221710、当前冻结稠密解码输出。已有PointRend论文思路是粗语义预测与细粒度特征在不确定位置联合预测，本实验仅借鉴点采样/细化，不宣称完整复现其逐级渲染算法。
- 推荐：冻结3k/32轮dense128作为粗预测和128×128任务条件特征；新增RGB卷积stem生成256×256/24通道特征，与已有shallow、任务条件特征、提示图、粗概率拼接，点MLP预测最大±4 logit修正，零初始化复现粗预测。
- 训练控制：每图4096点，其中512目标正点/512负点保证双侧训练，其余3072点分别为均匀随机或75%从随机候选中取不确定点+25%随机。两臂同初始化/顺序/数据/步数，改变点选择策略；GT只用于训练采样和loss，不输入模型预测。
- 推理：固定选择粗预测最不确定的65536个像素，不读取GT/valid；其余像素保持粗概率不变。两臂相同推理预算，独立比较采样效果。
- 数据：复用finetune阶段的3000/1024含RGB缓存、原task/提示；不增加数据、encoder冻结、不做几何变换，避免缓存task几何不一致。相比之前只有RGB的小头，本细化有当前更强的稠密语义上下文。
- 预期：更精确轮廓；风险是追随核纹理、点Dice采样偏差、粗预测置信错误被遗漏、额外点击/ROI时延。若没有达到门槛，明确拒绝此路线。
- 门槛：相对当前coarse BF1@2至少+0.01，macro/micro Dice均≥coarse−0.002，GT一致提示违约不增加；另报边界带IoU、逐类和空间块差值。先真实4/2/1 smoke，再两臂各8轮3k/1024。
- 限制：当前val同时开发选模、旧encoder历史暴露、仅固定提示；不是独立泛化或真实点击验收。主模型不替换。
