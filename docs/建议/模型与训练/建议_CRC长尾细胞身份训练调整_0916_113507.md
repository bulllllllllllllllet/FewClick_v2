# CRC 五类细胞身份：长尾训练调整建议

## 已确认的事实

- 监督标签是医生审核的 panel2 mIF 身份标签向 H&E 的几何转移结果，**不改标签、不重新按阈值判类**。
- 当前训练池（仅 train）为 CD4 44,210、CD8 39,492、Treg 1,731、B 31,214、Macrophage 282,920。Treg:Macrophage 约为 1:163。
- `effective_num(beta=0.999)` 在数万级类别上饱和，四个大类权重几乎相同，不能称为有效的主类均衡。
- 严格逆频率可让每类总损失质量相等，但实测会将 Treg 验证预测从 0 提升到 3,379（真实仅 53），并压低 Macrophage 召回；因此不能直接作为最终方案。

## 本轮先做的、可归因的调整

使用平方根逆频率，而非严格逆频率：

`w_c = n_c^{-0.5} / mean(n^{-0.5})`

在当前 train 计数上，预期权重约为 `CD4=0.576, CD8=0.609, Treg=2.91, B=0.684, Mac=0.227`。Treg/Mac 权重比约 12.8，明显低于严格逆频率的 163.5。它只改变 loss 权重，训练/验证分割、标签、输入 `reg64` 都保持不变，便于判断“过度补偿”是否缓解。

## 可比较的后续方法（不能一次全叠加）

| 优先级 | 方法 | 解决什么 | 本项目用法与风险 |
|---|---|---|---|
| 1 | 幂次重加权（本轮） | 让少类有更多梯度但不完全反转先验 | 扫描 `alpha=0.25/0.5/0.75`；Treg 仍可能过拟合，需看 precision 与 recall。 |
| 2 | 延迟重加权（DRW） | 先学习稳定表征，再强调少类 | 前 2–3 epoch 不加权，后续启用最佳 alpha；适合当前冻结 `reg64` 上的分类头，需单独对照。 |
| 3 | 类感知采样 / repeat-factor sampling | 使一个 epoch 实际看到更多含少类的样本 | 必须做**细胞级**而非只做图块级采样，Treg 允许有放回但不能把复制样本当新数据。 |
| 4 | LDAM 或 Balanced Softmax / logit adjustment | 修正长尾决策边界，而非仅改 loss 权重 | 作为与幂次权重互斥的独立候选；不要与强逆频率直接叠加，否则更难解释。 |
| 5 | class-balanced focal loss | 将梯度放在难例 | 标签转移边界与组织形态本就存在噪声，focal 可能放大噪声；不作为第一选择。 |
| 6 | 原型/对比学习 + 空间组织上下文 | 当纯 `reg64` 本身不能区分 CD4/CD8/Treg 时提高可分性 | 是后续第二阶段候选；不能把 mIF marker 或身份标签泄漏到 H&E 输入。 |

上述方法对应的代表性原始研究为 Focal Loss（Lin et al., ICCV 2017）、Class-Balanced Loss（Cui et al., CVPR 2019）、LDAM-DRW（Cao et al., NeurIPS 2019）、Logit Adjustment（Menon et al., ICLR 2021）和 Decoupled Long-Tailed Recognition（Kang et al., ICLR 2020）。本次在线检索接口返回 403，文献条目需在联网恢复后再逐篇核验，不以此替代本项目的实际对照结果。

## 实验纪律与判定

1. 固定现有 pooled validation 仅做最终候选比较；另从 train 划出 development 图块用于选择 `alpha`/阈值，不能反复按 val 调参。
2. 每个候选同时报告五类 precision、recall、F1、混淆矩阵和每病例 macro-F1；Treg 验证支持数很少，必须同时报告支持数，不能只看 macro-F1。
3. 通过门槛建议：不低于现有 Mac F1 的合理幅度，同时 CD8、B、Treg 不再为零；其中 Treg 必须有可接受的 precision，不能用大量假阳性换 recall。达到门槛后才接入组织/空间上下文模块。
4. 当前阶段是同病例混合图块内部验证，不应表述为患者独立泛化或临床性能。
