# P1C细胞颜色敏感性固定合同

问题：共享10µm中心crop的三encoder已训练probe对固定颜色扰动是否稳定。不是新encoder/输入修订或第三残差配方，也不宣称模拟了全部真实H&E染色变化。

输入固定OCELOT570清单中全部186val（99fields/57slides/41patients，非186独立WSI）。保持原40px物理crop。identity+四合成扰动：OD=-log((RGB+1)/256)，逐通道系数[1.1,.9,1]/[.9,1.1,1]/[.9,.9,.9]/[1.1,1.1,1.1]，RGB'=round(256exp(-OD×系数)-1)，clip[0,255]。强度不看结果选择；不分离真实H/E组分、不重采图像、不改变实例/位置/标签。

先CPU930输入验收：原186canonical像素SHA匹配，恒等精确，其它四条件用独立幂公式逐像素复算，磁盘PNG精确。之后共享同三个候选CTransPath点中心/LEMON/Phikoncenter4输入及既有预处理，冻结train-only mean/std/PCA和paired probe头，不再拟合、不选阈值。gallery仅原384train特征。identity必须复现旧特征/预测，差异先查数值路径。原XCell mask/context不同，中心CTransPath不能冒充原XCell。

正式指标各条件macroF1/balanced accuracy/precision@5、预测翻转、特征余弦、逐器官n/NA、来源依赖与cost；全部扰动均报告，不挑最优。CPU输入完成不等于这些结果完成。GPU提取等当前单GPU正式joint pilot结束，门控后串行；不改当前job、不启动第二GPU作业。此合成敏感性不是跨机构/真实染色外部验证，组织mask收益仍需独立证据。输入及run记录引用同时间戳NFS根。
