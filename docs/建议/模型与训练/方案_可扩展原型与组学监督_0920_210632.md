### 1.3 核心判断

现有交互解码器不是固定 12 通道分类器，而是提示条件下的目标/非目标预测。主要限制来自训练标签覆盖、episode 构造和表示能力。增加最终分类通道不是首要改动。

原型只能利用表示中已有的差异。冻结特征分类失败不能单独证明图像完全不可辨，但提示只换分类头可能不足；还需检查细胞对应、分辨率、裁剪、类别分布和上下文，并允许图像侧表示学习。

## 2. 产品目标与语义组织

### 2.1 交互目标

用户通过正点、负点或区域标注指定当前任务；系统输出同类区域 mask，并支持继续纠正。添加新任务原则上不改变最终二元输出通道。可选任务名称用于澄清意图，不作为唯一使用入口。

“任意癌种、任意组织”是持续扩展和验证的目标，不是当前已验证能力。对从未训练的类别，少量支持样本匹配是候选能力，需单独报告。

### 2.2 采用多维标签，不建立一个无限增长的互斥类别表

| 维度 | 示例 | 监督边界 |
| --- | --- | --- |
| 结构 | 上皮/腺体、肌肉、血管、淋巴管、脂肪、纤维、神经 | 组织 mask 与细胞身份不能直接互换 |
| 病理状态 | 癌变、非癌变、坏死等 | 不从单个上皮 marker 自动推断癌变 |
| 细胞身份 | 上皮、内皮、成纤维相关、免疫亚类 | 接受具体数据集明确提供的类别 |
| 分子/功能状态 | SULF1 阳性、marker 强度等 | 可与身份共存，缺测不代表阴性 |
| 空间复合语义 | 免疫聚集、炎症相关区域等 | 需要密度、结构与区域级证据 |

同一区域可以同时具有上皮结构、癌变状态和免疫浸润信息。Tumor ROI、tumor_epithelium 和癌细胞不是同一标签；tumor_stroma 也不表示组成它的每个细胞都癌变。

一个癌变腺体上的正点不能唯一确定用户要“所有上皮”还是“癌变腺体”。通过正负例、支持区域及可选任务层级消除歧义；不能默默把一次提示解释成所有层级。

## 3. CRC 监督资源与优先级

| 目标 | 已确认数据 | 推荐用途 | 不能直接声称 |
| --- | --- | --- | --- |
| 肿瘤区域 | panel_2 三例各一个 Tumor Polygon，QuPath 有同类 annotation | ROI 分割任务 | 完整癌/非癌穷尽标注或癌细胞 mask |
| 上皮 | CKPAN、Epithelial | 细胞身份、区域组成 | CKPAN 阳性等于癌变 |
| 血管 | CD31、Blood_endothelial | 内皮及结构辅助监督 | 细胞点等于完整管壁/管腔标注 |
| 淋巴管 | CD31/D2-40、Lymphatic_endothelial | 淋巴内皮辅助监督 | 所有 D2-40 阳性都是淋巴管 |
| 肌肉相关 | SMA、SMA_stromal | 当前标签定义下的身份/组成 | SMA_stromal 直接等于纯平滑肌 |
| 纤维相关 | FAP、FAP_SMA_CAF 等 | 成纤维相关身份和组成 | 已有完整纤维组织边界 |
| 神经 | S100 附加表型 | 保留可测状态 | 当前数据已有专一神经真值 |
| 脂肪 | 当前 panel 未确认专用监督；既有 12 类含 fat | 优先沿用已有组织标注 | CRC 蛋白表补齐了脂肪监督 |
| 免疫 | panel_2 五类专家标签及 marker | 身份、组成、空间分布 | 必须先成功区分所有免疫细类才能做组织分割 |

优先顺序：肿瘤 ROI 任务 + panel_1 结构相关细胞监督；随后扩展已有组织 mask 支持的结构任务；免疫细类作为独立辅助支线。神经、精细平滑肌等需要明确的适配标签，不能由图示中的 marker 对应关系直接生成真值。

三例都有公共坐标细胞表，但跨 panel 是区域配对，不假定同一物理细胞。公共简表主要保留类别；连续蛋白监督从明细表读取，通过 case、panel、section/scan、patch、cell_id 和变换版本关联。不可只用裸 cell_id 跨图块连接。

## 4. 不按病例划分的数据协议

### 4.1 固定原则

不使用 case_id 作为 split group；同一病例可出现在 train、val、test。case_id 仍作为来源字段、分层统计与复现依据。默认优先按空间块及其相关数据分组，不随机拆分细胞行或高度重叠图块。

### 4.2 先建立划分，再生成任务和缓存

1. 建立 canonical source：病例别名、切片、scan、panel、容器版本、配准版本与源文件身份。
2. 在统一物理坐标下划分空间块，记录每条样本实际使用的全部图像范围。
3. 将同源重复表示、同一区域多尺度裁剪、增强版本、跨 panel 对应区域、重扫与组学配对归入同组。
4. 对跨组有重叠或过近的输入范围，设置缓冲区或排除边界样本；分配之后再生成 split 专属图块、episode 和缓存。
5. 固定 seed、分组清单和 split hash，所有对比实验复用。

初始候选比例为 70/15/15，按有效空间组而非细胞数划分，再报告实际组织面积、图块数和类别覆盖。数据不足时可以先做 train/val 内部实验，明确未设独立 test；不能将反复调参的 val 更名为 test。

### 4.3 缓冲距离依据真实上下文确定

不能写死一个像素距离适配所有倍率。若两个样本实际上下文半径分别为 r1、r2，配准容差为 e，保守中心距离应大于 r1+r2+e；矩形/多边形输入优先直接检查扩张后的 footprint 是否相交。e 来自对应版本 QC 或显式保守配置，不预设未经测量的数值。

检查范围包括细胞 crop、低倍上下文、Phase 4 邻域及图消息传递。若区域图连接跨 split，应裁剪邻接或限制传播；若需要整张 WSI 无监督推理/适配，应单独标为 transductive 协议，不能混入严格区域隔离对照。

如果连续滑窗重叠关系使整张切片成为一个连通组，优先先分空间块并去掉边界滑窗，不因此自动退回病例划分。配准不确定时扩大缓冲、将相关区域绑定，或暂不纳入该项跨模态监督；记录原因。

### 4.4 不只检查图像重复

- 学习型染色归一化、特征标准化、PCA、类别权重、聚类中心、全局原型和数据驱动 marker 阈值只能从 train 拟合。医生交付的固定标注规则作为源数据版本保留。
- val 用于选模型/阈值，test 在方案固定后评估；测试标签不参与原型库构建或困难样本挖掘。
- 测试时用户在 support 区域提供标签是任务允许的输入；不把完整 query GT 当成 support。模拟交互若使用 query GT 的错误区域选下一点击，明确这是 oracle 点击模拟，各模型使用同一选点规则，不能用于参数拟合。
- support/query 尽量分离区域；评分排除用户已提供的支持标注范围，另行报告包含提示位置的指标时明确口径。
- 旧 checkpoint 若用过新 val/test 的位置，改变 manifest 不能消除历史暴露。正式对照需从允许的共同初始化重新训练，或明确该实验不是未见区域评价。
- 不要求同病例完全独立；仍承认共享染色、扫描、形态分布带来的相关性，报告“同队列内部区域验证”。

审计产物应列出重复源组、跨 split footprint 相交、配对跨界、fit 数据来源、checkpoint 暴露和可用类别覆盖；对已知直接重复/重叠要求零未处理冲突，对无法完全消除的相关性明确披露。

## 5. 模型设计

### 5.1 六模块保持兼容

| 模块 | 建议变更 | 保持的约束 |
| --- | --- | --- |
| Phase 1 输入 | 增加任务/坐标/有效监督信息 | 多尺度物理范围可追踪 |
| Phase 2 区域编码 | 可训练适配器或后部层；接收结构相关辅助监督 | 区域 token、soft assignment 契约兼容 |
| Phase 3 细胞注入 | 可训练局部细胞表示、身份/组成监督、受控残差融合 | 仅 H&E 推理；不强制先过五类免疫身份门槛 |
| Phase 4 跨尺度 | 保留上下文；限制跨 split 图传播 | 边界与缓存来源可审计 |
| Phase 5 提示 | 正负多原型、任务条件化匹配 | 输出单个当前任务，不要求固定类别 ID |
| Phase 6 解码 | 当前目标二元 mask 和边界细化 | 不改成不断扩展的互斥输出通道 |

新代码仅在 `benchmarks/v5/` 实现，v4 冻结用于复现。已有 12 类可保留为辅助头和防遗忘任务，不作为唯一标签空间。

### 5.2 多原型提示

对正支持 token 生成 P+={p1,…,pk}，对负支持生成 P-；k 取决于实际有效支持数。单个点不足以产生可靠的多个语义模式，先使用单原型，再随区域/点击增加更新。

基础匹配可比较候选 z 与正负原型的余弦相似度，用归一化 log-mean-exp 或最大相似度得到 s+、s-，再将 s+−s- 与 task token、空间结构送入 matcher。采用 log-mean-exp 时归一化原型数量，避免仅因原型更多分数升高。原型使用归一化特征；聚类/注意力聚合方法通过消融选择。

动态用户原型是当前任务的主要证据。可选全局原型库只由 train 建立，保存任务定义、器官、特征版本和样本来源，作为先验而非覆盖用户提示。特征模型更新后必须重建原型库及缓存。

初步不加入伪标签自训练和全图预测回灌，避免错误原型不断自我强化；后续若需要，另设明确实验。

### 5.3 任务化监督接口

建议 manifest 包含：

```text
sample_id, source_id, case_id, section_id, scan_id, panel
coordinate_system, pixel_size_um, source_footprint, context_footprint
registration_version, pairing_level, spatial_group_id, split, split_hash
task_id, ontology_version, supervision_level
target_mask_path, valid_mask_path, support_definition
cell_table_path, marker_observed_mask, label_provenance
encoder_version, cache_hash
```

`supervision_level` 区分 pixel、cell、region、spot；`pairing_level` 区分同细胞、同区域、相邻切片区域。新增训练任务不应要求改写旧的全局类别 ID。

对于组织任务，target=0 仅在已知非目标的 valid 区域使用；未知区域由 valid mask 排除。细胞位置/组学 spot 只参与对应辅助损失，不自动变成组织像素 mask。ROI 外的负监督范围必须来自标注契约。

## 6. 蛋白/组学如何监督表示

### 6.1 先做可训练且可诊断的图像路径

候选学生输入：高分辨率细胞及邻域 crop、区域形态 token、多尺度上下文。优先对比冻结特征基线与可训练 adapter/后部 encoder；是否新增独立细胞 encoder 由真实图像 smoke 和效果决定。

注意：在已缓存的冻结特征后加 adapter 可以改变特征组合，但不会更新图像 encoder。若目标是更新 encoder，必须从像素走可微前向，训练后重建离线缓存。训练状态与推理缓存版本必须一致。

### 6.2 分层监督而不是恢复所有组学

1. 专家提供的细胞身份用于分类或度量学习；不能把 Undefined 直接当作真实背景。
2. 观测到的 marker 阳性/强度提供辅助多标签或回归损失；缺失 marker 用 observed mask 屏蔽。
3. 配准不支持逐细胞时，预测区域细胞组成、密度或 marker 分布；不将粗配准变成硬逐细胞监督。
4. RNA 优先映射到任务相关身份或基因程序；spot 混合信号仅约束区域。跨数据集保留标签粒度与来源，不强行统一不同口径。
5. 需要教师蒸馏时，教师可在 train 使用组学，学生输入仍只含 H&E；预测值和实测值在产物字段上明确区分。

形式上可组合：L = Lseg + λid·Lidentity + λmarker·Lmarker + λcomp·Lcomposition + λmetric·Lmetric。各项仅在有效标注上计算，权重不是预先证明有效的常数；先逐项加，再考虑组合，并监控分割损失与梯度冲突。正负类不均衡时权重仅来自 train。

区域组成要记录分母：五类已知细胞内部比例不等于全体细胞比例，两个 panel 也不能相加当独立细胞总数。尽可能分别记录 observed_count、known_count、面积和 coverage。

### 6.3 组织结构不能由身份计数替代

区域融合同时保留形态、细胞组成、细胞空间排列和不确定性。细胞标签不一定能提供管腔、纤维基质、脂肪空泡等边界；没有组织真值时只主张辅助表示学习，不报告该组织的分割精度。

## 7. 训练阶段与验收

| 阶段 | 工作 | 产物 | 验收 |
| --- | --- | --- | --- |
| S0 数据契约 | 空间划分、监督范围、源配对、历史 checkpoint 暴露审计 | manifest、split audit、任务覆盖表 | 无未处理直接泄露；每个任务监督语义明确 |
| S1 统一基线 | 将既有任务接入二元任务接口，复现提示模型 | checkpoint、统一点击结果 | 真实 loader→loss→保存→重评估可复现 |
| S2 提示扩展 | 单/多原型、正负提示对比 | 原型模型及消融 | 相同 encoder、split、提示预算下比较 |
| S3 表示学习 | panel_1 身份/组成及可选蛋白监督 | 可训练表示与新缓存 | 辅助任务改善，并检查分割迁移及退化 |
| S4 联合融合 | 受控残差注入与交互分割联合优化 | 联合模型 | 主指标优于同协议基线，旧任务退化可接受 |
| S5 持续扩展 | 新组织/新癌种任务登记、支持样本测试 | 新任务包与逐任务报告 | 区分已训练类别和新类别支持推理 |

每阶段先跑一个真实代表样本，验证坐标、valid mask、有限损失、梯度、缓存/权重版本和评价路径。没有有效组织标注的结构不进入分割分数统计。阶段失败应定位原因，不自动扩量长跑。

长任务执行前另写运行记录：输入、提交、时间戳、GPU、命令、验收和监控；使用 aligner 环境、tmux 和带退出码日志。产物在 `/nfs-medical3/zyh/fewclick_v2/` 下新建时间戳目录，原数据只读。

| F | 与 E 相同，再加 marker/组学监督 | 与 C 相同 | 测试额外分子监督贡献 |

训练预算、有效样本、初始化、split 和点击规则尽量一致，参数量/计算量差异显式报告。不能把“更多训练+解冻+额外标签”整体收益都归因于蛋白监督。

### 8.2 指标和统计

- 主指标：预设点击预算下的 task-macro Dice/IoU、边界指标、NoC@目标阈值；阈值和最大点击数在看 test 前固定。
- 未达到阈值的任务报告失败率及截断规则，不能只平均成功样本。
- 辅助指标：身份逐类 F1、组成误差、marker 预测误差与覆盖率；不将辅助指标提升代替组织分割提升。
- 报告新增任务与原 12 类任务，监控防遗忘；保留病例分层描述，但不以病例分组划分数据。
- 比较新类别时，明确它是否在预训练/辅助监督出现；“新类别未用于分割训练”不同于完全未见语义。
- 置信区间优先按空间组重采样，并说明同病例仍相关；不把数百万细胞当成独立统计样本。候选收敛后建议至少三个训练 seed。
- 点击协议固定同一初始提示和后续选点规则；自适应点击位置可以不同，不能要求不同模型错误区产生完全相同位置。

推荐验收原则：相同协议下主指标改善，并检查逐任务退化、边界、失败率和延迟；具体最小收益幅度在基线方差评估后预先确定。当前不编造预期提升百分比。

## 9. 推理、缓存与实施范围

部署仍为：H&E → Phase 2/3/可选 4 离线区域缓存 → 用户提示 → Phase 5 多原型 → Phase 6 mask。组学/蛋白仅在训练期提供监督，部署不要求上传 mIF 或 RNA。

记录首次 WSI 准备时间、缓存大小、追加点击延迟三个不同成本。细胞分支处于离线准备，不因追加点击延迟而直接删除。encoder、ontology、原型或 assignment 版本变化时明确哪些缓存失效。

建议后续在 v5 新增任务 manifest/episode 层、split audit、多原型模块和组学辅助训练入口；具体目录与接口在实现前核对现有代码，本文名称不表示已存在可执行脚本。

本轮仅交付方案与 skill 划分规则；不改动 v4、不搬迁数据、不生成训练缓存、不启动 GPU 任务。

### 9.1 初始实现状态（2026-09-20）

已在 `benchmarks/v5/phase_5_prompt_encoder/` 建立首批可执行接口，未修改冻结 v4：

- `src/extensible_task_contract.py`：`extensible_prompt_task_v1` manifest。它允许同一 `case_id` 出现在不同 split，但要求 `spatial_group_id` 不跨 split；对相同 `source_id` 和坐标系的上下文 footprint 执行缓冲重叠检查。它输出 manifest hash、跨 split 病例列表和任务覆盖审计，供后续真实 CRC 清单构建使用。
- `src/multi_prototype.py`：正负多原型的归一化 log-mean-exp 余弦匹配。重复相同原型不会仅因原型数量增加而改变分数；匹配器可选学习温度并保持对输入和温度的梯度。
- `tests/`：合成测试验证上述隔离边界、数值性质和反向传播；它们不是 CRC 数据、组织分割或模型收益证据。

尚未接入真实图像 loader、实际 Tumor ROI、CRC 蛋白/RNA 清单、Phase 5/6 训练循环或 GPU 训练。下一实现步骤是以真实 CRC 肿瘤 ROI 建立带 footprint 的任务 manifest，并通过真实 loader 完成 S1 基线。

### 9.2 panel 分开观测组成接口（2026-09-21）

`ObservedRegionEvidenceHeads` 为 Phase 2/3 的区域 token 产生独立的结构 panel 和免疫 panel logits；`observed_composition_loss` 仅在有观测细胞、映射类别计数且 coverage 大于零的区域计算，并以 coverage 加权。它不替代现有 `composition_target` 的完整组成含义，也不合并两个 panel。

当前 inventory 尚未与真实 H&E patch 的 source footprint、Phase 2 assignment/region slot 完成对齐，因而该头尚未接入 `SemanticCellToRegion` 或训练脚本。下一步必须建立该对齐 manifest 并以真实 loader 做一次单 patch forward/loss smoke，之后才可启动训练。

### 9.3 panel_2 候选空间对齐（2026-09-21）

已将 1,553 个医生审核通过的局部 H&E patch 通过既有配准矩阵映射到公共 H&E 坐标，并与 1024 µm panel_2 免疫区域网格求相交，得到 2,473 条候选记录。每条记录保留五类免疫细胞计数（CD4_T、CD8_T、Treg、B_cell、CD163_Macrophage）、观测/映射细胞数、覆盖率与 `spatial_group_id`。三个病例的 panel_2 覆盖率中位数约为 0.942、0.862、0.643，高于 panel_1 结构观测的约 0.319、0.327、0.218，故优先验证 panel_2。

候选表的空间相交仍不等价于 FewClick Phase 2 region token 的精确 receptive-field 对齐，全部保持 `candidate_only=true`。下一步是为真实 Phase 2 token 输出其 H&E 坐标 footprint，并只保留一对一/高重叠对应；之后用该子集运行一次真实 patch → region token → panel_2 loss 的 forward/backward smoke。此前不能把这批候选当作训练真值或宣称蛋白监督已生效。

### 9.4 真实 Phase 2 软空间投影冒烟（2026-09-21）

Phase 2 token 本身没有全切片物理坐标字段，故实现 `region_footprint_contract.py`：将 `assignment_low[K,H,W]` 的每个低分辨率像素中心按显式 `source_pixel_stride` 还原至 512 px 源 patch 坐标，再映射至公共 H&E 1024 µm 网格；对每个 token 聚合其网格质量，只有某个网格质量比例不低于 0.80 才附加 panel_2 观测组成 target。此举避免把 token 固定编号误作物理位置。

在三例各一真实 CRC 注册 H&E patch 上，冻结 Phase 2 → panel_2 head 的 forward/backward 均完成；有效 token 数为 58、64、61，损失有限。该实验证明接口可执行，但每个 512 px patch 只覆盖一个或两个 1024 µm 网格，故它大多是 patch 级区域上下文监督，而不是可用于报告组织边界精度的细粒度真值。后续训练须将这一点写入 target schema 和评价解释。

### 9.5 冻结 H&E token 的 panel_2 可学习性 probe（2026-09-21）

在空间隔离清单中按病例均衡抽取的 96 train / 30 val patch 上，冻结 Phase 2 token 经免疫观测组成 head 的最佳验证 CE 为 0.754778，优于只使用 train split 总组成均值的无图像信息基线 0.770354（约 2.02% 相对降低）。这支持“token 含有少量与区域免疫组成相关的 H&E 信号”的有限结论。

这不是分割增益、逐细胞分类或跨队列泛化证据；提升较弱，且 target 是局部区域观察。下一阶段只能采用严格相同空间 split 的主任务 `seg-only` vs `seg + panel_2` 融合对照，并以主分割指标决定是否保留辅助项。

## 10. 备选方案、预期收益与风险

| 方案 | 优点 | 风险/取舍 |
| --- | --- | --- |
| 扩大固定类别头 | 有穷闭集任务实现简单 | 重叠语义困难，新任务持续改头；不作为交互主线 |
| 冻结表示+原型 | 成本低、最容易做有效对照 | 表示缺少细粒度信息时增益有限 |
| 可训练表示+多原型+身份/组成 | 兼顾任务扩展和细胞证据 | 需控制解冻过拟合与配准误差，推荐主线 |
| 先生成全部蛋白图像 | 可提供直观可视化 | 任务更复杂，重建改善不等于分割改善，暂非首选 |

预期收益是减少固定标签表依赖、提高结构相关表示、支持以用户示例定义任务。尚未证明收益大小。主要风险包括标注粒度混淆、配准误差、细胞检测误差、低频类别不稳定、强度批次偏移、同病例区域相关以及额外监督损害主任务；分别通过 valid mask、配对粒度、train-only 拟合、统一消融和逐任务报告管理。
