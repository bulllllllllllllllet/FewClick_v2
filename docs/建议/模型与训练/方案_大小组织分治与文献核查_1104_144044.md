# 大小组织分治：文献与当前证据

用户提出大小目标分开试验或检索组织分割解决方案。本轮执行只读检查与文献检索，训练保持明确暂停；不自动重新训练/恢复seed2。推荐为待执行方案，非功能门控或研究成功。

## 当前证据

固定首seedmatch、3+2验证：local小目标(<5%)120例，Dice.2548；大目标(>=25%)108例，.8267。remote有目标小222例.1220，大143例.5727。面积比例不是组织本体，不能将脂肪一律算大、淋巴一律算小；补充分量还需物理面积µm²、连通组件大小/数量、细长度、同类内面积分层及标注质量。

本轮从原rows的TP/FP/FN额外只读复算：local-small pooled precision .0975418659、recall .7421935294，median(pred area/GT)5.62482949，empty1/120；remote-small pooled precision .0722581519、recall .4713077580，median area ratio4.06898189，empty35/222。pixel pooled precision不等于逐任务平均。predarea包含有效像素，GT正面积含valid；不能据中位面积比断言每例都扩张。小目标同时存在漏检，但当前错误更不能解释为只需提高召回。

现4000train任务：CRC-local small495/medium316/large309；CRC-remote small276/medium134/large129/absent528；TIGER-local small178/medium243/large459；TIGER-remote small98/medium133/large230/absent472。小目标共1047/3000present=34.9%，local CRC44.2%，remote CRC51.2%；不能未经核查断言小目标没有训练。实际source kind同片样本包含在local/remote身份分类内。

## 已核查原始论文

1. HookNet (Medical Image Analysis2021)：https://arxiv.org/abs/2006.12230 。高分辨率细节分支与低分辨率上下文分支对齐融合；应用乳腺组织、肺TLS/生发中心。启发为“语义范围与细节边界分工”，不是按query GT面积选两模型。现FewClick已有三视野，不能仅加多尺度就称新。
2. DMMN (2021版本)：https://arxiv.org/abs/1910.13042 ，作者代码https://github.com/MSKCC-Computational-Pathology/DMMN 。多倍率输入/解码中间特征融合，乳腺组织任务；类别均衡不等价解决所有小目标。空间视野变化与单纯插值分辨率区别需披露。
3. Learning Class Difficulty via Dynamic Focal Attention for Histopathology Segmentation (MICCAI2026)：https://papers.miccai.org/miccai-2026/0555-Paper6050.html 。按类别难度调节query-mask attention，而非把稀少等同困难；BCSS/BDSA/CRAG。其per-class偏置属于固定语义类设定，不能直接给FewClick推理组织class ID或预设类别头，否则改变用户指定概念任务。
4. Benefits of spatial uncertainty aggregation for segmentation in digital pathology (2024)：https://pmc.ncbi.nlm.nih.gov/articles/PMC10790788/ 。对预测阴性区域聚合不确定性以发现漏检，支持疑难区域自动复查思路；属于肿瘤转移任务，不证明对FewClick微小组织已有效。需要同时处理误检，且不能只复查已有阳性区而无法找回完全漏掉的组织。
5. Focal Tversky (ISBI2019)：https://arxiv.org/abs/1810.07842 。医学小病灶精确率/召回权衡，原实验超声/皮肤病灶，不是组织分割直接证据。对当前FP占主导，照搬偏重FN的参数可能扩大误报；只作候选，参数需train-only预登记/验证，不能用验证分数搜索。

## 建议顺序

A. 先分开评估和解释，不删小目标。已有<5%、5–25%、>=25%分层继续保留，在CRC/TIGER、本图/远端分别看precision/recall、面积比、组件召回、FP远离GT距离及细长结构；GT只用于离线标注分层/训练loss与评分，不用于推理选路。另查训练曲线与是否同类内小目标更差；类、尺寸与训练难度混杂须保留。

B. “分开训练”可作诊断，而非直接最终部署：小目标专家与大目标专家若执行，保留各自远端absent任务，公平预算、相同公共起点与完整评价集；先各自在全评价集评分。严禁按query GT大小在推理时选最优专家，两个模型参数/算力与额外监督全部计账。大小专家上界只能叫oracle诊断。此轮未定最终预算/任务序列，尚不可启动。

C. 正式优先一套支持匹配模型的“上下文匹配＋细节/精度约束”分工。若train-only错误诊断支持，先登记一项小目标FP抑制/概率校准训练改动与原模型两臂对照，控制相同任务/预算，特别看远端target absent FPA与脂肪。不能直接调高验证阈值或对小目标过滤小组件；这会删掉真实小组织。保留统一阈值，阈值变化须另行train-only校准合同。

D. 第二条件方向是高分辨率支持对齐的局部细化：两个尺度/分支融合，输入高分辨率必须有真实新细节；Phikon原32网格插值64不是新增信息。此前pixel head已做过且未通过原守门，不能原样重跑；仅在强匹配基础上有新证据支持时，测试支持条件化细化或真实高分辨率融合，先单改动。query自动选区只用图像/支持证据/模型置信度，不读GT；需记录候选覆盖召回、完全漏检以及WSI开销，保留全图结果避免硬选路漏掉小组织。

E. 大目标/远端主指标不被牺牲：维持原总体remote类别宏Dice>=+1pp、BF1/FPA/小目标/脂肪/CRC/TIGER等原10守门；补充小目标机制目标可预登记+5pp，但不能仅小目标上涨就宣称晋升。大小两表和整体表都报告，支持少量点击/远端人工零点击不变。只做一项训练改动后再做架构改动，避免同时变采样、loss和decoder而无法归因。实验合同/数据清单待用户检查后冻结，本轮不启动。
