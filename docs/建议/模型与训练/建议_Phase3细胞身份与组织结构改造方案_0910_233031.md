# Phase 3：细胞身份与组织结构改造、训练和验收方案

日期：2026-09-10。状态：设计建议，尚未实现或启动训练。范围：FewClick_v2 v5；最终任务为不同器官、癌种 H&E 的点击引导组织分割。

本文中的结构尺寸、学习率、数据抽检量和数值门槛均为建议的首轮实验设置，不是已有实验结果或领域公认合格线。实施前在训练/开发集完成可行性检查并冻结协议，不根据测试结果反复调整。

## 1. 问题、依据与选择

导师要求的中间能力是细胞识别，最终目标是组织识别与分割。蛋白/RNA 的作用是提供身份或组织组成监督；训练好通用组学回归头，不足以证明模型认识了所需组织。

核对依据：

- `docs/指导意见/第二次组会指导意见.MD`：现为逐字稿，重点为 02:48:47、02:49:00、02:51:29–02:52:31；`第二次组会.md` 为表格图片引用。
- `benchmarks/v4/phase_3_cell_region/src/{cells,model}.py`、`train_phase3.py`、`configs/phase3_cell_region.yaml`、`tests/test_cell_attention.py`。
- `docs/运行记录/模型实验/运行记录_Phase3全切片RNA联合分割Gate_0908_213000.md`：三 seed region accuracy 均值 seg-only/paired/shuffled 为 0.917837/0.915706/0.915869；这是特定设定下区域分类的负结果，不是最终分割实验。
- `docs/运行记录/模型实验/运行记录_v4下游TLS细胞置零消融_0907_234105.md`：单 WSI smoke 中完整细胞输入的 Union Dice 为 0.7764，置零为 0.7110。仅支持该模型在该例使用了细胞证据；置零有分布变化，不能替代重新训练的无细胞基线。

- 数据目录 CSV `docs/数据集情况/【7】基因-病理-疾病相关数据.csv`、SRRSH CRC 审计报告；会话中直接读取了 SRRSH 两份原始染色说明。目录 CSV 是资源索引，不是文件可用性证明；其他器官尚未在本方案中选定为正式训练集。

选择：保留六模块和现有 Phase 3 基线，增加可解释的细胞证据残差分支。先验证身份与组成，再验证空间关系，最后验证多器官条件。v4 冻结不改；新模块、数据契约和实验放在 v5。

不优先采用：直接回归全部蛋白/RNA、一次增加几十个互斥细胞类别、先替换大 backbone 再全量重训。它们会同时改变多个因素，当前证据无法支持其优先级。

## 2. 总体结构及与下游的接口

```text
Phase 2 region_tokens R [B,K,256] + assignment A [B,K,H,W]
                         │
H&E 原有 74 维 cell ──────┼── 原 Phase 3 ─────────── Z_base
         │               │                              │
         ├─ A.身份预测    │                              │
         │   概率 p、表征 h、预测不确定性                 │
         ├─ B.组成汇聚 ← 同一 Phase 2 soft assignment    │
         │   组成、物理密度、覆盖信息                    │
         └─ C.局部关系（第二版）                         │
                         └─ D.区域证据编码 → 门控残差 ──┤
                                                        ↓
                                               Z_new [B,K,256]
                                                        ↓
                                    Phase 4 → Phase 5 点击 → Phase 6 mask

训练侧标签：mIF / RNA / 人工核验 → y_cell、y_comp、组织 ROI
推理侧输入：H&E、其检测细胞、器官元数据；不含真实组学或真实组织标签
```

默认 K=64、region_dim=256，沿用现有配置。输出保持 `fused_tokens` 的形状；保留/提供 `cell_context`、`attention`、`has_cells`、`region_cell_count` 供兼容和诊断。新增审计输出单列，不假装旧 attention 是新分支的全部解释。

结构接口一致不等于表示分布一致：新 token 接入旧 Phase 4–6 的零微调测试只能作为兼容性检查；正式效果比较需要给基线和新方案相同的下游适配预算。

离线路径：H&E cell features → Phase 2/3 → region cache。在线点击只读取 cache 并执行 Phase 5/6（Phase 4 按现有部署契约），不重复运行细胞识别。器官条件也在缓存前固定；改变器官或模型需要重建相关缓存。

## 3. 数据和标签契约：先决定可以监督什么

### 3.1 输入分成基线、轻量全量统计、监督三组

| 组 | 必备内容 | 用途 |
|---|---|---|
| 基线输入 | 原 74 维 cell、valid、原有确定性抽样规则、真实总数量 | 复现 Z_base；首轮保持原 max_cells=255 的 attention 预算 |
| 轻量细胞统计 | 全量可用 H&E 检测中心、物理坐标、身份预测概率、预测有效标记 | 用于区域数量、密度、组成；不以 attention 子样本冒充全量统计 |
| 训练标签 | 来源、标注版本、允许类别集合/软标签、标签可用 mask、配准质量、人工核验状态 | 仅计算 loss，不进入推理特征或门控 |
| 区域监督 | 多类别组织 ROI、有效标注像素 mask、软区域组成 target、覆盖率 | 未标区域使用 ignore，不当背景 |
| 样本身份 | patient/case、section、scan、organ、panel、来源、split_group | 防止同病例不同 panel/扫描进入不同集合 |

若原缓存仅含 255 个细胞的特征，不能宣称有全量身份概率。首轮明确采用“均匀抽样组成估计”并报告采样误差；需要全量概率时另建分块、分批特征提取缓存，先确认 XCell 提取接口，不能直接突破其固定 token 上限。全量几何计数与子样本身份估计分开记录。

H&E 检测器的选择与覆盖率也属于数据契约：核中心不等于完整细胞，漏检的结构不能靠分类头补回。首轮保持基线检测器，避免与本次改造混杂。

### 3.2 细胞本体

首轮采用固定的父类词表候选：上皮、内皮、成纤维相关、肌性、免疫、其他已确认类别。具体激活哪些类，由训练数据和人工核验决定。没有足够证据的标签保存允许集合，例如 `{成纤维相关, 肌性}`，不强制单类。

子类在父类内条件预测，如内皮相关细分、免疫亚类、器官相关上皮亚类；仅在有监督和可验证性的分支启用。首轮 CRC 不启用缺少标签的上皮亚型头。

`Undefined` 是未确定身份，不能直接训练成统一的生物学负类。`S100_positive`、`SMA_stromal`、`D2-40_positive` 等不能只改名字就得到真身份；共表达/阳性状态采用独立 masked 多标签头，默认只是可选训练辅助，不进入第一版身份词表。表型状态预测是否进入区域分支另做消融。

“未测量”“不确定”“确证其他”分别编码。未检测到某 marker 不等于其对应谱系的可靠阴性。概率熵可作不确定性的一个输入，但不能代替校准或未知类别识别验证。

### 3.3 CRC 首轮用途

panel_1 优先：CKPAN、CD31、D2-40、FAP、SMA、S100 对应结构性证据；panel_2 留作免疫扩展。S100 不能单独区分神经与脂肪；SMA 涉及多种组织；原始说明记录 FAP 上皮染色及 CD31/D2-40 共表达，均须纳入标签规则。

现有 Tumor polygon 不足以训练血管、肌性、纤维等多类别组织分割。需先获得/核验这些类别的组织 ROI，不能把细胞点扩张的 mask 当独立组织真值。审计报告未完成深层产物逐项验收，因此现有更细 ROI 是否可复用仍需核对。

配准分级：只有确认同一物理细胞且局部匹配可信的区域，才使用逐细胞监督。相邻切片即使组织对齐很好，也不能自动逐细胞配对；采用匹配区域的组成监督，并承认相邻层面的组成差异。全局 affine 分数不作为微米误差或细胞配对合格证。

建议先每例选 20 个组织多样的 QC 视野，每个候选细胞类每例争取 50 个可核验实例；稀有类不足则报告全量支持数。该数量用于发现问题，不保证精确估计泛化性能。组织 ROI 需覆盖内部、边界与易混淆阴性，按物理面积和实例计数记录。病例级划分必须先于调阈值和采样。

## 4. A：H&E 细胞身份模块

第一版不替换 XCell backbone。独立身份识别主实验用 `reg-64` 经 LayerNorm、两层 MLP 得到 128 维 h_i；建议隐藏宽度 128、dropout=0.1。H&E 检测得到的 log面积可作单独增强对照。绝对 x/y 不输入身份分类器，防止学习切片位置捷径；位置只用于 assignment 和空间关系。

原74维并非视觉模型直接输出：H&E 经 CTransPath 得到768维，再经 XCellFormer 得到64维 reg 特征，加载时拼接 x/y、log面积、7维核类别编码，形成 Phase 3 输入。独立身份识别禁止输入与目标同源的真实核类别或由真值映射的类别；已有 H&E 分类器预测的核类别只能作为单列对照，记录其训练病例与来源。原74维仅保留在历史基线复现路径；若其类别字段来自测试真值，该结果只能标为 oracle，不能作为 H&E-only 部署主结果。

父类 head 输出 p_i=softmax(W h_i)。子类 head 输出条件概率，最终细分概率为父类概率乘条件概率。未启用的子类不凭空补标签。器官 embedding 首轮固定为 CRC 条件，等第二个器官进入时才验证其价值。

身份训练后，在训练/验证划分内校准概率；保存温度、类别支持与校准集来源。冻结身份模型生成区域训练概率时优先采用病例交叉拟合；若训练病例太少无法稳定交叉拟合，则使用联合训练并显式记录，没有“无偏 OOF”声明。测试始终使用未见该病例的身份模型。

如果 A 阶段失败，先排查标签与 crop/检测覆盖，再进入下面第二阶段的编码器实验；第一阶段失败不等于组学监督无效。即使第一阶段通过，第二阶段仍是已确定的后续研究任务，用于验证自有编码器是否优于固定 XCell 特征。

### 4.1 两个项目阶段与第二阶段任务（09-10 补充）

用户已确认将“训练自有细胞编码器”列为第二阶段。这里的项目阶段不等同于六模块中的 Phase 2，也不等同于第9节的 A/B/C 训练步骤。

| 项目阶段 | 细胞视觉特征 | 工作目标 |
|---|---|---|
| 第一阶段：XCell 基线 | 冻结 CTransPath→XCellFormer，使用 reg-64 | 完成身份识别基线、组成融合与可行的组织分割验证，建立对照 |
| 第二阶段：自有细胞编码器 | 从预训练视觉权重初始化，用本任务监督微调 | 独立评价 H&E 细胞检测与类型识别，并检验新表征是否改善组织分割 |

自有编码器不是用3例 CRC 从随机权重训练视觉模型，也不是仅在冻结 XCell 后加分类头。具体预训练 backbone 尚未确定，实施时核对权重可用性、输入尺度与数据来源；不预先宣称哪一种最好。

```text
H&E 检测细胞的本体视野 + 周围组织视野
                   ↓
          可训练的细胞视觉编码器
                   ↓
           表征 h（建议先统一为128维）
             ├─ 身份头 → 概率 p / 不确定性 → 独立细胞识别评价
             └─ h + p + 几何 → Phase 3 B–D → 点击组织分割
```

两视野按物理尺度定义，候选32与128 µm，仅为开发集待验证起点。细胞中心或 H&E 检测 mask 用于强调目标细胞，不使用测试时不可得的 mIF mask。主实验保留相同检测器和采样规则，以隔离视觉编码器差异；全切片输出包括检测位置、类别概率和不确定状态，不承诺有限标签覆盖全部生物学亚型。

第二阶段训练顺序：

1. 冻结预训练视觉主干，训练视野融合、128维投影与身份头。沿用 L_id/可用的 L_sub、病例划分和校准协议；新头学习率建议1e-3。
2. 小学习率解冻视觉主干最后一部分层（确切层由选定模型确定），建议主干1e-5、新头1e-4。先只验证细胞识别；最多30 epoch、patience=5作为初始预算，按开发集病例宏平均 macro-F1 选择。增加前层解冻需另做对照，不默认全量微调。
3. 冻结训练好的自有编码器，用其 h/p 重新生成训练侧合规缓存，重跑第9节 B/C 的融合与组织分割训练。原 XCell 基线获得相同数据、prompt与下游适配预算；暂不同时升级空间关系模块。
4. 只有冻结新编码器的组织分割版本通过后，才探索小学习率联合微调编码器与 Phase 3/下游。联合阶段需读取 H&E 并在线重算可训练特征，不能通过冻结缓存训练编码器；部署前按最终权重重建缓存。

第二阶段验收分为两个独立结论：细胞识别相对第一阶段同词表基线提升，及组织分割相对同预算 XCell 版本提升。细胞侧沿用第11节指标与建议门槛，增加冻结预训练特征 vs 部分解冻的对照；组织侧仍以 J5 Dice ≥+2 pp、边界不退化为建议推进门槛。若只改善细胞任务，记录为独立细胞识别收益，不据此替换组织分割模型。三例CRC结果仍只作原型，独立泛化需要更多病例。

交付包括：自有encoder checkpoint与输入尺度、身份词表与校准参数、逐病例细胞检测/分类报告、全切片细胞结果、重建cache的版本信息，以及相同划分下的组织分割对照。h无需压回64维，通过新分支投影维持最终256维region接口；原基线路径保留用于归因，第二阶段是否完全移除对XCell的依赖须另做替换消融，不能仅替换新残差分支就称系统已不使用XCell。

## 5. B：软区域组成和物理密度

令 a_ki 为 Phase 2 assignment 在第 i 个 H&E 细胞中心的采样值；k 维归一化。v_i 表示检测/坐标有效，不是标签质量。

```text
n_k       = Σ_i a_ki v_i
f_k,c     = Σ_i a_ki v_i p_i,c / max(n_k, ε)
area_k    = Σ_pixel A_k(pixel) × pixel_area_um2
d_k       = n_k / max(area_k / 10^6, ε)          # detected cells / mm²
u_k       = Σ_i a_ki v_i uncertainty_i / max(n_k, ε)
```

area_k 在实际标定网格积分，正确计入下采样比例；有效组织面积口径要预先固定并同时记录有效像素比例。极小区域不输出无限密度，标记无效并屏蔽该统计。检测密度不是组织内真实细胞总密度。

低置信细胞仍计入检测数量。不能因为身份不确定就把它从分母删除，造成确定类别比例虚高。对身份特征缺失的检测分别记录覆盖率；组成定义为“已获得预测的检测细胞内组成”，不能伪装为完整组成。

若只能对子样本预测，使用已知纳入概率的加权估计并记录有效样本量；不能用训练时稀有类过采样后的原始比例作为自然区域组成。首轮最稳妥的是原有确定性均匀采样并另报采样稳定性。

区域标签 y_comp 必须来自相同空间范围、相同 soft assignment 和明确的标签覆盖。在部分 marker 只支持特定类时，只监督对应边际量或允许类别集合；不能把“已标细胞内比例”直接当成“全部细胞内比例”。不满足分母条件的比例不使用组成 loss。

首轮 Phase 2 冻结，构造 target 的 assignment detach。以后解冻 Phase 2 时重新定义并重建 target，不能继续沿用旧区域缓存。

## 6. C：局部关系模块，作为第二版

仅在身份/组成版本有效后增加。输入 h_i、p_i、相对物理坐标和相对面积；建立半径内 kNN，建议上限 k=8、半径 50 µm作为首轮候选，开发集比较 25/50/100 µm。空邻域有明确 mask，不连接远处细胞凑满 k。

建议两层 128 维局部消息传递，输出关系特征 r_i，再按 a_ki 聚合至区域。复杂度接近 O(Nk)，不采用全切片 N² attention。图由全量几何或明确记录的子样本建立；训练与部署保持相同构图规则。patch 边缘读取至少等于关系半径的 halo，只监督中心有效区域，避免截断邻域。

空间关系的价值通过“组成不变、关系分支的相对坐标/边打乱”对照验证。该对照不能打乱给基线和 soft assignment 的原位置，否则同时破坏区域归属，无法归因。

此模块学习的是可用于分割的关系特征，不声称两层图网络必然能完整重建血管或腺体。没有收益就不纳入第一版部署。

## 7. D：与基线兼容的区域融合

```text
e_k   = MLP([Σ_i normalized(a_ki) h_i, f_k, log1p(d_k),
             u_k, prediction_coverage_k, optional pooled(r_i), organ_embedding])
g_k   = sigmoid(MLP([R_k, e_k]))
Z_new = Z_base + valid_evidence_k × g_k × W_out(e_k)
```

e_k 建议 128 维，W_out 投影至 256 维并零初始化。因此初始化时精确保持 Z_base，训练后仍需实测旧任务表现。门控输入只使用推理可得信息；训练标签可信度、mIF signal 或真实组织类别不进入 g_k。

没有有效细胞证据时残差为零，保留基线路径。这是显式的缺失输入设计，不是捕获异常后静默换模型。文件缺失、维度错误、未知 schema 直接报错。

训练期增加区域 tissue head 与 composition head。它们用于监督与诊断，最终像素 mask 由 Phase 6 输出。基线复用同一个冻结 checkpoint；不靠形状兼容强行载入新权重。

## 8. 损失函数和缺标签处理

每项 loss 先按其有效监督数归一化，再组合。没有有效监督的 batch 跳过该项并记录，不生成虚假零标签。

| 损失 | 定义与作用 | 数据要求 |
|---|---|---|
| L_id | 可信单类用加权 CE；允许集合 S 用 -log Σ(c∈S)p_c；软标签用交叉熵/KL | 经核验的细胞对应，权重来自训练侧标签可信度 |
| L_sub | 条件子类 CE，只作用于父类与子类都确定的样本 | 禁止用未知子类当阴性 |
| L_comp | 完整组成用 target→prediction KL；仅可靠边际量用 masked Huber | 相同分母、区域、覆盖口径 |
| L_tissue | 由有效人工组织 mask 与 A 聚合得到软组织分布，以软 CE 监督区域 | 使用混合比例保留边界信息；同时可报告基线多数票 accuracy |
| L_seg | 沿用真实点击 episode 的主分割 loss；若需新定义，建议 BCE+Dice，所有 arm 一致 | 独立组织真值与有效标注 mask |

区域组织分布 t_k,c = Σ_x A_k(x) 1[y_x=c] / Σ_x A_k(x)1[y_x有效]。低标注覆盖区域屏蔽，不把“未标”并入背景。这里的组织分布与细胞组成是不同 target，分别建头。

建议初值：阶段 B 用 L_tissue + 0.2 L_comp；阶段 C 用 L_seg + 0.2 L_tissue + 0.1 L_comp。只有解冻身份模块时再加 0.1 L_id 防遗忘。阶段 A 单独优化 L_id（可选 0.2 L_sub）。状态 marker loss 默认不开。数值仅为起点；记录各项梯度量级，开发集只搜索辅助权重 {0,0.1,0.2}，正式测试前锁定。

## 9. 分阶段训练、冻结和停止条件

下表首先执行于第一项目阶段的 XCell 基线；第二项目阶段按第4.1节先微调自有编码器，再复用 B/C 训练与评价流程。A/B/C 表示训练步骤，不表示项目阶段编号。

| 阶段 | 更新参数 | 冻结参数 | 首轮训练预算与选择指标 |
|---|---|---|---|
| 0 数据验收 | 无 | 全部 | 身份、坐标、组织 ROI、split、真实 loader smoke 通过后继续 |
| A 细胞身份 | 128 维 adapter、身份 head | XCell、Phase 2、旧 Phase 3、Phase 4–6 | AdamW lr=1e-3，wd=1e-4，有效 cell batch≈512，最多30 epoch、patience=5；按病例宏平均 cell macro-F1 选 checkpoint |
| B 组成与融合 | 新残差融合、区域辅助 heads | 身份模块、Phase 2、旧 Phase 3、Phase 4–6 | lr=3e-4，wd=1e-4，有效 patch batch≈16，最多30 epoch、patience=5；按 region macro-F1 选 checkpoint，组成误差作门槛 |
| B2 关系增量 | 新关系模块与残差融合 | 同 B | 和 B 同预算，组成/关系消融；未通过则不进入部署 |
| C 组织分割 | 新分支及 Phase 4–6 中当前部署实际使用的可训练模块 | 先冻结 Phase 2、XCell、身份模块、旧 Phase 3 | 新参数 lr=1e-4，下游已有参数 lr=1e-5；最多30 epoch、patience=5，按验证 J5 病例宏平均 Dice 选 checkpoint |
| D 多器官 | 共享模块、器官 embedding/必要子类 head | 首轮仍冻结基础视觉主干 | 需第二器官和独立病例；器官条件/无条件同预算比较 |

epoch 明确定义为固定 manifest 的一轮病例平衡采样，同时记录有效 cells/patches/optimizer steps。GPU 显存不足用梯度累积保持有效 batch，不暗改采样范围。三 seed 使用相同 split、标签与 prompt 协议。首个真实 smoke 用代表性非空、空细胞、缺标签样本验证所有开启路径、loss/backward/checkpoint reload，再开展正式训练。

阶段 B 保留原 Phase 3 的优点，主要验证新增证据。阶段 C 的基线必须获得相同组织数据、点击 episodes、训练步数和下游微调机会；不能拿充分微调的新模型与完全未适配的旧 checkpoint 比较后宣称结构收益。

身份阶段若未通过但可靠区域组成可学习，允许单独登记“区域组成版本”实验；不能继续声称身份模块已通过。若 B 通过、C 不通过，则结论是辅助能力增强但组织分割未获益，不扩大训练掩盖该结果。

## 10. 划分与统计单位

CRC 当前约 3 个病例，重扫、不同 panel、相邻切片和相同病例 patch 全部绑在同一个 split_group。CRC_1 等来源未确认前不进入正式 manifest。

三例只适合探索性 leave-one-case-out：每次一例测试，两例内部按空间块开发（大于最大上下文并设隔离带，禁止重叠 crop/halo 跨界）；该内部开发不是独立病例验证，必须说明。协议可预先冻结后做外层评估，但不应看过一折测试结果再为后续折挑参数。若已有测试窥视，将这三例全部视为开发数据，另找独立病例验证。

cells/patches 数量不能替代患者数。三 seed 衡量优化稳定性，不增加独立病例数量。三例报告每例差值和范围，不凭 patch bootstrap 给出很窄的“泛化置信区间”。扩大队列后使用患者级配对 bootstrap 95% CI；同患者多切片先聚合。建议至少拓展至约 10–20 个独立测试病例再做较稳定的区间估计，实际精度仍由方差和样本量决定。

多器官阶段分别评价：同器官新病例、同器官新中心/平台、跨器官迁移。新器官是否已知决定条件设置：未知器官使用预先定义的 unknown 条件；不能训练不存在的器官 embedding。癌种或组织诊断真值不作为器官条件输入。

## 11. 三层指标与建议门槛

所有百分比差异下文均指绝对百分点；例如 Dice 0.80→0.82 为 +2 pp。门槛用于内部推进决策，不是医学合格标准，也不保证一定可达。

### 11.1 细胞层：监督是否变成 H&E 可识别能力

主指标为患者宏平均 supported-class macro-F1，附每类 precision/recall/F1、support、混淆矩阵。各 fold 类别覆盖不同时单列，不将不同词表的宏平均直接比较。完整词表还需报告误报；不能只删除难类来提高分数。

补充：Brier score、固定15个等宽概率箱的 ECE；已知标签子集的 risk–coverage 曲线。校准参数只由开发集确定。分别报告“高置信人工核验细胞上的分类”和“包含 H&E 检测漏检的端到端检测+分类”；分类只评匹配成功细胞时必须报匹配/检测覆盖。定位匹配用一对一匹配，距离阈值依据开发集的核尺度和标注误差冻结。

对照：同输入同容量的无组学/已有标签训练；若没有相同词表基线，则用同特征的线性 probe 和仅标签先验基线，并标明它们回答不同问题。另设 train 内病例/批次约束的标签打乱对照，验证始终使用未打乱标签。

建议推进门槛：有支持的大类 macro-F1 ≥0.70，且比同词表基线 +5 pp、比打乱对照 +5 pp；核心类 recall ≥0.60，ECE≤0.10。粗类身份未到门槛先排查；不要求所有细亚类都达到，也不以稀有类 n 很小的结果作通过依据。初始 pilot 若显示核验一致性不足以支持这些数值，正式评估前修订任务粒度和协议，不在测试后放宽。

### 11.2 区域层：细胞是否成为正确组织证据

| 指标 | 定义 | 建议推进门槛 |
|---|---|---|
| composition MAE | 有效类别/区域绝对比例误差，先患者内平均再患者间平均 | 比训练集组成先验误差相对下降≥10%；报告每类；MAE≤0.10作为完整组成的参考目标 |
| region tissue macro-F1 | 同一冻结 Phase 2 区域、同一标签规则 | 比同预算基线 +2 pp |
| 边界区域结果 | 真值混合区域，建议最大组织占比<0.8，开发前固定 | 不低于基线；另报纯区域，防止内部区域掩盖边界退化 |
| 身份配对有效性 | 身份/组成真实配对 vs 训练侧打乱 | region macro-F1 至少 +1 pp；作为机制门槛，不替代组织分割 |

组成目标若与输入概率来自同一个身份模型，只是自一致性，不能作为独立正确性指标。评估需要独立核验或配对模态标注，且说明其噪声。用完整概率组成做监督的版本和仅可监督部分 marker 边际量的版本，MAE 不混合排名。

### 11.3 最终组织分割：是否值得替换 Phase 3

**主指标：固定 5 次点击（J5）的病例宏平均目标组织 Dice，再对预先定义且有支持的组织类别宏平均。** 每个病例、类别、episode 的聚合顺序固定，不能由像素多的病例主导。

必须同时报告 J1/J3/J5/J10 Dice/IoU、Boundary-F1、NoC@IoU0.85（最多20次）、失败率、每类及每器官结果。NoC 未达阈值记 censored，同时给 failure rate，不把失败样本删掉后只报告成功平均点击数。Boundary-F1 容差按物理尺度及双人标注偏差在开发集确定，测试前锁定。

提示采用两套互不混淆的协议：固定 prompt replay 用相同坐标隔离模型差异；模拟交互用相同点击策略和初始 seed，后续根据各自误差生成点击，因此坐标可以不同。主 J5 使用预先固定的一套协议；另一套为敏感性结果。人工点击验收单独记录，不能和模拟结果混合。

建议替换门槛：J5 Dice 比同预算基线 ≥+2 pp；Boundary-F1 不下降；核心组织平均不退化超过1 pp；至少2/3探索病例方向为正，并报告全部病例。三例达到也只称原型通过。扩大后的独立队列还要求患者级配对差值95% CI下界>0，且各器官没有系统退化，才支持稳定收益结论。

补充工程门槛：在线 p95 点击延迟增幅≤5%，单 tile region cache增幅≤10%作为初始目标；离线准备时间与峰值显存分别报告，允许为精度付出经测量的代价。相同256维 token不代表实际cache不增大，辅助细胞输出默认不装入线上cache。全量细胞身份预测的离线成本必须实测。

## 12. 必做消融与归因

| 编号 | 版本 | 要回答的问题 |
|---|---|---|
| E0 | 原 Phase 3 + 同预算下游适配 | 公平主基线 |
| E1 | E0 + 同容量纯视觉残差，无身份监督 | 提升是否仅来自增加参数 |
| E2 | E0 + 身份概率/表征残差 | 身份监督是否有用 |
| E3 | E2 + 组成/物理密度/覆盖 | 显式区域统计是否增加收益 |
| E4 | E3 + 局部关系 | 相同组成下空间结构是否有用 |
| E5 | E3/E4 + 器官条件（多器官后） | 条件是否优于共享无条件模型 |
| S | 相应版本训练标签/组成打乱 | 是否使用真实配对语义 |
| G | 只扰动关系分支边/相对位置 | 空间关系收益是否真实 |
| O | 经核验标签替代预测身份，仅作训练/验证诊断上限 | 瓶颈在身份预测还是组织聚合；非可部署结果 |

先运行 E0/E1/E2/E3/S，小实验通过后才做 E4/G；E5 不能在只有 CRC 时宣布有效。无细胞重新训练版可作补充；推理置零仅为敏感性分析。所有 arm 匹配数据、训练步数、下游调参预算和 seeds，记录参数量及计算量。

打乱 target 只在训练集合内执行，保持类别先验/标注可用模式等尽可能一致，验证和测试标签不打乱。随机选择 RNA batch、数据增强、episode 的随机流在各 arm 对齐，防止把采样差异算作监督效果。

## 13. 工程拆分和验收交付

建议新增文件（尚未创建代码）：`benchmarks/v5/phase_3_cell_region/src/semantic_cells.py`、`composition.py`、`spatial_relations.py`、`semantic_cell_region.py`、`semantic_losses.py`；配套 versioned config、train/evaluate 工具和测试。精简复用必须登记来源路径/revision；不拷贝权重或修改 v4。

checkpoint 保存 `schema_version`、父类/子类词表、organ词表、原checkpoint指纹、训练split hash、温度校准、坐标尺度、模块开关。cache key 还包括 detector/feature/identity模型、Phase2 assignment、采样策略、marker/标签映射版本、视野和分辨率。模型训练后不得复用旧身份概率缓存；Phase3变更后重建其region cache。

最小验证覆盖：初始化输出与旧模型一致；零细胞/单细胞/padding不产生NaN；无效坐标拒收；组成归一化和缺失覆盖正确；物理尺度改变时密度单位正确；同病例隔离；训练标签不进入推理；relation打乱不改变assignment；checkpoint重载输出一致；真实loader→loss→backward→cache→Phase4–6→组织mask路径可运行。

交付表应同时列：split/patient数、标签来源与覆盖、细胞F1及校准、组成MAE、区域F1、J1/J3/J5/J10、Boundary-F1、NoC及失败率、逐例差值、离线成本、在线延迟。每项都标“未运行/未通过/通过”，禁止用辅助loss下降代替最终验收。

预期收益是组织相关细胞证据更明确、混合区域和边界识别更好；主要风险是标签不可靠、逐细胞不可配准、H&E对细亚类辨别力不足、样本太少、检测覆盖不足，以及新增分支学到数据来源捷径。以上风险分别由数据分级、层级标签、独立组织真值、病例划分和消融验证约束。

第一执行优先级是 CRC 标签/ROI 与配准可用性检查，其次 A 和 E0–E3 的小规模训练，最后真实组织点击分割。当前没有启动训练，也没有将本方案视为已验证可部署模型。
