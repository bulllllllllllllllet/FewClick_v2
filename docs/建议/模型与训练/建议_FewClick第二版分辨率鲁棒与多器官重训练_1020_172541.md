# FewClick 第二版：分辨率鲁棒与多器官提示分割重训练方案

日期：2026-10-20。用户要求：针对已验证的分辨率退化，重新训练 FewClick，并纳入此前下载的器官/癌种数据。本文为实施建议与验收设计；本次核对代码、既有实验、公开数据说明及本地样本，未启动新训练。

## 1. 推荐决策

从当前最佳 J5 + dense128 权重初始化，保留稠密解码能力，重建训练数据和提示任务，分阶段微调视觉编码、细胞融合、提示匹配和解码器。

必做三项：

1. **统一物理视野，同时训练清晰度变化**：输入 MPP 对齐只能统一组织大小；还要让模型见到同一视野的清晰、降质图像，以及清晰度不同的支持—查询组合。
2. **多器官、按提示定义目标的联合训练**：接入 CRC、OCELOT、IGNITE、TIGER、PUMA。不同数据集保留各自标签含义，训练时转为“当前目标/其他已标注组织”的二元任务。
3. **动态本片提示—查询训练，包含目标缺失**：每次更换目标、正负点击、支持和查询位置，学习同片远处检索，以及查询没有目标时输出空结果。

优先解决新 WSI、新癌种上“用户在本片点击少量示例，再找本片其他区域”。另一张片/另一癌种提供支持示例作为单独协议，不混成同一个成功标准。这仍是提示定义的组织分割，不等同于自动诊断癌症类型。

“重新训练”首选已有权重的分阶段微调，不先随机初始化整网。分辨率条件模块、通用语义适配、真实高低清晰度一致性作为后续可独立检验的增量；不同时更换所有模块。

本次只读复核还确认：

- IGNITE 的 816 对文件是 408 个 ROI 及其 context 版本，不能按 816 个独立区域计数。H&E 部位为 lung 327、brain 18、liver 34、adrenal 8、bone 16、bone and meninges 5；它们均来自 NSCLC 队列，肝/脑部位不能改称原发肝癌/脑癌。train 中只有其中五种部位，无 bone and meninges。

- TIGER 有 151 个 BCSS 大 ROI 配对和 1,879 个 tissue-cells ROI 配对；两类有空间包含/重叠，必须按实际组织区域去重。官方发布版本是约 **0.5 MPP**，不能沿用原 BCSS 的 0.25 MPP。来源可追踪不代表图块互相独立。
- TIGER 完整 WSI 下载阶段仍是 failed：S3 目录标记被当文件处理，当前 image 目录完整 TIF 数为 0。ROI 已完成，可先训练；整片验收前需单独修复下载计划并补齐校验。保留原失败日志，不把它标为仍在下载。
- PUMA 两个实读 TIFF 的 MPP 约 0.2263–0.2269，视野约 232 µm；不能硬填 0.25。统一到 0.5 MPP 后不足 512²，可保持物理尺度居中 padding，padding 为无效区。该 ROI 不足以产生两个不重叠的 256 µm 支持/查询视野；先用于局部提示训练/评测，不能伪装同片远端能力。
- OCELOT 的每个 train 样本还存在高细节 cell RGB，共 400 张，文件采样约 0.1940–0.1945 MPP。它仅覆盖 tissue 大视野的一小部分，而且文件采样 MPP 不等于扫描仪原生光学分辨率。

## 4. 分辨率处理设计

### 4.1 把两个量分别记录

统一主输入为 **512×512、目标 0.5 µm/px、约 256×256 µm 视野**。图像按物理坐标裁切并使用明确的抗混叠降采样；标签最近邻变换，ignore 单独传播；不足视野 padding 为 invalid，不拉伸组织凑满。

每条清单同时记录：

- `scanner_mpp_xy`：原始扫描标定，缺失则显式 unknown。
- `available_mpp_xy`：实际可读图像文件采样间距，例如 OCELOT tissue 约 0.778。
- `input_mpp_xy`：整数尺寸取整后的真实网络输入间距。
- `source_extent / transform_to_source / valid_mask`：原始范围、可逆坐标变换、有效区。
- `quality_variant / blur / interpolation / upsample_ratio`：实际生成过程，不将最终 0.5 MPP 当成真实细节质量。

所有点击、组织 GT、核位置与核裁剪共用坐标变换。缩放核面积时使用物理面积核验；旧 74 维合同中的面积值可转回“0.25 MPP 等效像素面积”保持数值尺度，另存 µm²，不能无记录地改单位。

### 4.2 固定视野的清晰度增强是第一优先

对高质量训练图构造“降采样→恢复输入大小”，保持 GT 和物理视野不变：

| 训练质量版本 | 初始采样比例（候选） | 处理 |
| --- | ---: | --- |
| 原始可用质量 | 50% | 保留当前图像质量 |
| 约 0.8 MPP 等效采样 | 25% | 同一视野约 320²，再恢复 512² |
| 约 1.0 MPP 等效采样 | 25% | 同一视野约 256²，再恢复 512² |

实际尺寸按各轴 MPP 计算。原图本来更差时不能生成虚假的“更清晰版本”；记录最大可用质量，不强行给它高质量标签。0.65、0.9 等未作为离散训练档位的退化可作为开发验证插值档位。模糊/压缩/染色增强随后逐项加入，不在第一轮同时改动。

支持—查询同时包含同质量和不同质量组合，起始各占 50%，以验证示例清晰度变化是否影响匹配；几何变换后重新更新点与核位置。这是训练增强，不宣称真实同片扫描分辨率天然独立变化。

**两条图像/细胞路径要保持一致**：正式联合训练为每个质量版本从对应 RGB 重新准备核检测、CTransPath/XCell 输入。只降组织图、复用清晰细胞缓存的版本继续保留为单因素对照，不冒充真实低清晰度部署输入。先做少量离散质量版本，控制重提取成本；不能在训练时任意连续降质却始终读取不匹配的细胞缓存。

### 4.3 第二阶段的可选增强

- **分辨率条件**：将 available/input MPP、放大比例与缺失标志编码为小向量，调节支持特征和查询特征/细胞融合权重。零初始化增量使首次前向保持主模型行为；加入条件遮挡对照，避免模型拿 MPP 当数据集/癌种标签。此项需独立消融后采用。
- **清晰—低清晰一致性**：同一训练视野两种质量都接受 GT 监督，再给低质量分支一个弱的一致性约束；高质量教师 stop-gradient。仅在训练 GT 有效且教师判断可靠的区域启用，低质量无法分辨的细边界不强制完全复制。先以权重 0 开始，候选 0.05；未见增益就不加入。
- **OCELOT 真实配对**：利用 cell RGB 与 tissue RGB 的实际重叠位置，得到真实清晰/低清晰局部对照。优先完成像素配准和共同有效范围检查；组织 GT 从 tissue 对应范围映射，仍是原有较粗 GT，不能称获得新高分辨率标注。禁止将局部高细节贴到外部范围或跨 split 配对。

本次对 OCELOT train 的 400 对坐标发现：所有 cell 范围位于 tissue 内；按浮点中心与 metadata offset 做 1e-6 严格比较有 508 个轴不完全相等，最大仅 0.875 个 level0 像素。可能来自整数坐标取整，尚不能称像素配准完成。训练应优先使用完整 source start/end 变换，先核验视觉重合，不能盲用中心偏移假设完全相等。

单纯放大输入为 1024 或增加超分辨率生成器不是第一轮方案：插值本身不补回采集时丢失的细节。真正多视野上下文也是另一变量，待这一轮建立可信基线后再测。病理多倍率训练已有研究依据，但不直接证明本任务收益；例如 [Virchow2](https://arxiv.org/abs/2408.00738) 支持研究数据/尺度多样性的价值，本方案仍以自身配对实验验收。

## 5. 多器官标签和划分

### 5.1 用各数据集自己的目标定义二元任务

训练任务为 `(support RGB + 正负点, query RGB) → 当前目标 mask`。任务生成器可读 source GT 来模拟点，训练 loss 可读 query GT；模型前向不接收 query GT、query 目标类别 ID、癌种 ID。

不把所有数据生硬映射到 CRC 的固定 12 类：

- OCELOT 的 Cancer Area、IGNITE 的 Tumor epithelium、TIGER 的 invasive tumor / in-situ tumor、PUMA 的 melanoma tumor 不自动当成严格同一标注概念。
- `Unknown / unannotated / outside ROI / padding` 均为 ignore，不能补成负例。
- PUMA GeoJSON 未覆盖处先保持 unknown；只有发布定义和覆盖核验明确证明的 background 才作为负例，栅格初始化为 0 不代表其语义就是背景。
- OCELOT 的非癌和 TIGER 的 rest 是复合概念，可作当前任务的已标注非目标，但不把一个点击解释成所有组织语义的天然代表。首轮优先具体组织目标；复合类作为目标时单列。
- 有组织 GT 不等于有相同核类型 GT；不能由组织癌区标签给每个核赋“肿瘤核”输入。
- 若增加语义辅助监督，用各数据集专用训练 head 加有效标签 mask，不能直接拿外部 16 类去监督现有 12 通道。

### 5.2 数据采样与逐步纳入

首次开发模型建议训练比例：CRC 30%、TIGER 25%、IGNITE 25%、OCELOT 20%；每个来源内部再平衡器官、目标组织与目标面积区间，限制同一 ROI 反复采样。比例是初始候选，依据 train 可用覆盖锁定，不按 test 分数倒推。

先保留 PUMA 的黑色素瘤作为一个**训练未见病种**检查：冻结选择规则后评估一次，报告提示协议只能是当前数据能支持的局部/跨图像范围。随后第二版面向覆盖面的正式模型可纳入 PUMA 的预先划定 train 部分，初始比例 CRC/TIGER/IGNITE/OCELOT/PUMA = 30/22/20/18/10；PUMA 保留的评测部分继续不参与训练。这时应改称“训练已覆盖黑色素瘤”，不能继续报未见病种成绩。

该顺序兼顾用户要把下载数据用于训练，以及保留一次真实迁移检查。额外的 leave-one-organ/domain-out 是后续复验方案，不把首轮成本扩大成默认六折全重训。

### 5.3 划分先于裁剪、提示和缓存

- 继续遵循用户允许同病例跨 split 的规则，采用空间块和完整输入 footprint 检查；不新增患者独立硬性要求。
- 有官方 split 的 OCELOT、IGNITE 保留其 test；IGNITE train 的 fold0 可作开发验证，其余四折训练（实际 train 215、dev 54），先审计同 ROI/context 对应关系。
- CRC 保留现有空间 split，扩图只从原 train 取；旧验证结果单列初始化暴露。
- TIGER 按发布坐标的空间块划分，大/小重叠 ROI、同一物理区域不同表示归同组。无法证明无重叠的区域先排除，不凭不同文件名认为独立。
- PUMA 缺可靠全片关系时以完整 ROI 为最小组，绝不把同一 ROI 小块分到不同 split；同片远端结论缺数据支持就不报告。
- 另建确有新 slide ID、无训练区域来源的挑战子集回答“新 WSI”问题；这是附加评估，不替换用户现行划分政策。
- OCELOT 已反复查看的 23 例归开发诊断，不能再称盲测。测试只在设计、阈值及 checkpoint 选择规则锁定后运行。

## 6. 模型训练：保留有效结构，调整学习内容

基线权重：

- J5：`/nfs-medical3/zyh/v4/phase6/formal_full_runs/phase6_joint_pixel_20260722_142455/checkpoint_epoch_004.pth`
- dense：`/nfs-medical3/zyh/fewclick_v2/boundary_refinement/next_stage_1014_200033/matched96k_1014_221710/dense128_epoch_031.pth`

| 模块 | 推荐第一轮处理 |
| --- | --- |
| DeepLabV3-ResNet50 图像骨干 | 短暖身冻结，之后小学习率解冻 layer3/layer4；保留早期纹理层，BN 统计先固定 |
| 软区域与图像投影 | 在联合阶段参与更新，避免永久固定为 CRC 的区分方式 |
| Cellpose / CTransPath / XCell | 初期冻结，统一预处理；不要求外部有 RNA，不将预测 reg64 当真实转录组 |
| 细胞—区域融合 | 与提示/解码联合训练，让模型适应低质/unknown 核类型输入 |
| 正负提示编码、J5 匹配与图细化 | 训练动态 local/remote/absent 任务，不能继续固定 task |
| dense128 | 保留已有浅深层融合与残差输出，继续训练 |
| 旧 12 类 semantic 支路 | 第一轮保留以控制变量；后续对照训练时遮挡/共享投影替代，不直接推理置零 |

细胞输入第一轮统一采用图像预测核，核类型没有统一可靠来源时在**所有域，包括 CRC**显式编码 unknown，保留几何与 reg64。需先报告旧模型在统一输入上的分数变化；不能只给外部 unknown，却把后续差距全归给器官。原 CRC 核类型可留作另一条有监督上界/输入消融，不作为外部无法获得的特权输入。低质量下可训练显式细胞缺失 mask/分支 dropout；这需要训练，不在推理时悄悄清零。

如果多域后模型仍明显依赖 CRC 的 12 类先验，再独立比较“semantic 支路训练遮挡”和“用通用学习特征替代该支路”。替代会改变输入通道与权重合同，应单独初始化新层、说明迁移映射、重新训练；不能把增加组织类别简化为 12→更多通道。病理基础模型空间 token 可作后续骨干候选，不以全 patch 单向量替代稠密特征，不重启已放弃的 SegNext 路线。

## 7. 提示任务与损失

### 7.1 每轮动态生成 episode

起始任务组合为 30% local、有目标 remote 50%、无目标 remote 20%。source 始终要有可用的目标示例；无目标指 query 中缺少目标，并不要求 source 也没有目标。

- local：在本图点击、预测本图；可增加屏蔽点击邻域的评分，避免仅记住点附近。
- remote：优先同 WSI/同大 ROI 内不同位置，实际视野与上下文不重叠；远端 query 本地点热图为零，只接收 source 的视觉任务信息。
- absent：仅在已标注有效范围内确认目标缺失的 query 构造，不能把未标注区当空目标。
- 来源不能支持某类任务时明确记录覆盖和跳过率。PUMA 局部任务可以用于联合训练，但不能冒充 remote；配额按可行源清单显式分配，不静默复制相同图块。

正负点在目标/非目标有效内部采样，距离边界以 µm 规定；从多个连通区域和不同外观位置取代表点，混合相似组织负例，避免只点白背景。训练先使用 1–5 个正点、1–5 个负点；支持多块时固定总点击预算。无负点等模式需补明确空集合实现和测试后再开放。

开发验证固定 3 正 + 2 负，并另报 1+1、5+5 曲线；随机点序列预先锁定。模拟点与真实人工点分开报告。连续交互纠错作为后续阶段，在上一预测 FP/FN 上加点，不将真实 query GT 当部署输入。

### 7.2 损失与空目标

第一轮保留有效区 BCE + soft Dice，边界损失沿用已有实现但以物理宽度核对；各臂使用同一设置以隔离数据/清晰度影响。

- 现有 `balanced_pixel_bce` 已确认会对无正像素或无负像素的 episode 抛出异常，因此新增无目标任务必须同步改 v5 loss 路径。空目标使用有效区 BCE 和误报面积项；全目标也有单独有效区损失，不能因没有边界而产生 NaN 或零训练信号。v4 原实现保持冻结。
- 点一致性损失仅施加在点所属的真实 source/local 图像，不在远端 query 相同 xy 施加。
- 不把 unknown 区当 FP/FN，不沿 ignore 边缘制造组织边界。
- 需要时再加入质量一致性、困难负例排序或缺失判别 head；先验证目标缺失 episode 本身是否有效。

## 8. 实验顺序与预算

这些是建议预算和筛选门槛，不是已测耗时/收益。首轮保持相同初始化、有效 batch、更新次数、提示预算和可训练模块；记录源 ROI 数、独立视野数、episode 数、梯度步数、GPU 时间，不能把它们混为“数据量”。

| 阶段 | 内容 | 完成条件 |
| --- | --- | --- |
| P0 数据/输入 | adapter、MPP、ignore、split、统一细胞输入；建立各域冻结基线 | 每个来源真实样本对齐；跨 split footprint 无冲突；输入来源差异可量化 |
| P1 训练链路 | 可微 support/query forward、动态任务、空目标损失、缓存拆分 | 全链 loss/backward/参数梯度/保存重载 smoke；每种任务至少一个真实例 |
| P2 四臂初筛 | C0 CRC动态；C1 CRC动态+质量增强；C2 多域动态；C3 多域动态+质量增强 | 同预算判断清晰度训练与新增域分别带来什么 |
| P3 联合微调 | 最佳组合扩大原 train 覆盖，阶段解冻；复验第二 seed | 收敛曲线稳定、质量/器官分层改进、CRC回归和空目标同时过门槛 |
| P4 增量结构 | 分辨率条件；必要时通用 semantic 替代；每次只加一项 | 相对P3独立消融增益，不能只看最好单例 |
| P5 新域与整片 | 首次保留病种评估→纳入其train后的覆盖版；接 dense WSI 推理 | 分清未见病种与已见病种；WSI仅标注范围评分并检查拼接/点击状态 |

P2 各臂先做 **2,000 更新短筛**；有效 batch 初始 4，即每臂约 8,000 episode，不等于 8,000 独立图像。共享的训练能力都经过同一 smoke 后，再把候选和对应控制延至 **20,000 更新**（约 80,000 episode）。短筛只因数值错误、无有效梯度、明显塌缩等明确失败而停止并保留日志；2k暖身未涨分不足以否定后续解冻训练。

20k 候选初始建议前 2k 暖身，之后解冻 layer3/layer4 及区域投影；head 学习率 1e-4、骨干 1e-5，AdamW、混合精度、有效 batch4，具体显存与有限梯度由 smoke 确认。各对照同阶段执行，不能候选解冻而控制保持冻结。原模型只训 head 的同预算成绩另列。

P3 根据训练与开发验证曲线延长到最多 60k 更新，验证间隔初始 2k；只有在学习率已下降且多个连续验证点没有联合改进时才停止，不再用固定“8轮看起来够了”判断。阈值/最佳 checkpoint 只根据开发验证；多域均值不能掩盖单域明显退化。

**时间估计方法**：原 96 例冻结推理 126 秒、旧 dense 缓存训练速度都不能换算成新的双图编码+反向训练速度。先用代表性的 100 个图像质量版本测细胞提取与缓存成本，200 个训练 step 测吞吐/显存/IO：

`总耗时 ≈ 质量版本数 × 每版本准备秒数 / 实测准备并行效率 + 更新数 × 每步秒数 + 验证与IO时间`

若实测 0.5/1/2 秒每步，20k 更新纯训练分别约 2.8/5.6/11.1 GPU小时；这只是算术情景，不是已测 ETA，也不包含数据准备。第一轮先使用单张可用 RTX 5880 48GB、CPU4 做基准；当前机器有6卡不等于6卡可独占，不承诺线性提速。

## 9. 验收标准：必须同时过几类测试

以下数值为预先建议的开发门槛，可在正式跑前锁定；不是保证达到的指标。

1. **清晰度鲁棒性**：在同一固定 CRC 96 例、同一输入合同的原图/降质对照中，争取回收至少一半已测 Dice 损失。原输入合同的参考目标约为低质 Dice≥0.7891，同时原图下降≤0.005；正式统一细胞输入后必须重测控制、按相同公式重算门槛，不能硬套旧分数。再用更完整固定空间验证及第二 seed 复验。
2. **原有能力保留**：旧 1024 例的 Dice/BF1 作为部署回归，初始容忍各≤0.005下降；若更换细胞合同，分别报告旧部署合同和统一新合同的比较，不能靠换分母过门槛。
3. **多器官收益**：按器官×目标类别 macro 汇总，并报告最差器官、面积区间、scanner/quality分层。对匹配的冻结基线争取 Dice +0.05，且超过全前景等简单基线；+0.05但仍低于面积基线不能单独判成功。该阈值是候选筛选目标，不预测外部具体提升。
4. **空目标拒识**：平均有效区误报面积相对减少≥30%，同时报告≥1%误报率、任意阳性率，以及有目标召回；不能全空输出刷拒识。
5. **提示依赖**：正确目标、替代目标和无/零任务对照；替代提示要对替代类 GT 评分。正负点预算、query和阈值固定，另有真实人工点击子集。
6. **真正域外能力**：留出的病种模型训练时未见，所有设计/阈值不由其结果挑选；承认预训练暴露边界。纳入训练后的同域测试不能称跨未见癌种。
7. **整片能力**：在TIGER等有全片坐标/ROI GT的数据上运行完整tile推理，检查边界拼接、跨tile追加点、缓存更新及无目标误报；只在标注ROI计分，不能把未标注全片当非癌真值。

尺度变更时 BF1 的容忍距离按 µm 统一，并保留历史 BF1@2px 回归列。按来源空间块/WSI聚类计算区间，不把同片重复patch当独立样本。泛化结论分开写“已见病种的新区域”“已见病种的新WSI”“训练未见病种”。

## 11. 风险、替代选择与预期边界

- **数据增加但任务没有变化**：仍可能只学癌区面积/器官偏好。用动态目标和提示替代实验检验。
- **更多低质数据损伤原清晰图**：保留原质量和CRC回放，独立回归；不用把所有训练图先糊成同一最低质量来换表面一致。
- **器官与分辨率绑定**：每个可行域做多质量版本，分辨率条件遮挡；不提供数据集ID作为推理捷径。
- **低质核分割失败**：统一准备流程、质量分层和显式缺失训练；不能假定细胞分支总能补偿组织图细节。
- **外部mask概念和边界粗细不同**：使用数据集本地目标、ignore、物理边界评测；标签粗糙不能靠更大decoder变成更精确GT。
- **小ROI无法证明全片泛化**：PUMA局部任务与TIGER远端任务分开，后者完整WSI未齐前不给整片结论。
- **换大型病理骨干**：保留作当前多域联合训练仍失败后的替代方案，先比较可用空间特征和相同提示协议，再决定计算投入。

预期是减少对单一清晰度和CRC形态的依赖，提高本片示例在新域的可迁移性；无法恢复从未采集的细节，也不能承诺少数点击覆盖所有未知组织概念。成功与否按第9节实际结果判定。
