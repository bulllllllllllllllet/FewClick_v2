## 实际运行链路与代码证据

当前dense使用的是：512图像 → 已训练的DeepLabV3-ResNet50区域encoder → 256维像素特征/64软区域/12类语义概率 + XCell细胞融合 → Phase5正负提示task → J5区域预测 → dense像素残差 → 二元mask。

- J5实际run配置没有cross_scale_variant，构造器默认fine_only；没有启用parent context。概念上的六模块/多尺度设计不能当作当前选定checkpoint已启用的全部计算。10-15的多层dense实验是CNN不同层特征融合，不是新增5x/2.5x WSI上下文。
- `benchmarks/v5/phase_6_mask_decoder/dense/dense_prompt_decoder.py`：读取deep、shallow、task、base、semantic、prompt_maps；semantic有12通道，最终是base logit加可跨区域边界的像素残差。不是12类硬选类器，也没有把目标类别ID喂给dense推理。
- `dense/train_dense_boundary.py`：每张唯一patch选一个固定episode；task/base/点击热图一起缓存，迭代仅改变样本顺序。缓存构造明确拒绝目标全空或全满的任务。当前3k32轮是3k独立图块、96k更新，不能说是96k不同提示任务。
- `benchmarks/v4/whole_slide_inference/src/prompt_transfer.py`：源tile点击视觉token编码成全局task，应用于所有候选tile；输出仍是区域投影。`infer_wsi.py`/`runtime_worker.py`未调用v5 DensePromptDecoder；旧region cache仅保存assignment/tokens/xy/area/active等，没有dense所需浅深层像素特征/semantic。
- `v5/.../iterative/whole_slide_interactive.py`确有跨tile追加点击状态，但使用旧IterativePromptDecoder，未连接当前最佳dense。存在接口不代表有dense整片质量证据。
- 因此，局部固定提示BF1=0.557040不是“一个提示覆盖整张WSI”的已验证成绩。不能直接在每个远端tile复制源tile的局部xy/点击热图；远端应共享视觉提示，只有真实点击覆盖的tile具有本地点图。每次改提示，task/base/点图需要一致更新。
- `benchmarks/v4/phase_3_cell_region/src/cells.py`：这条保留主线实际读取74维细胞输入（位置/面积3 + 核类别one-hot7 + reg64）。前期5类/3类身份探索并未自动替换这条链路。新癌种需要可用且坐标对齐的细胞分割/类别来源；训练所用已有核图与新片预测核图的差异应单列检查。细胞分支在离线准备阶段，不因交互时延直接删除。

## “同一WSI里找目标”为什么仍受癌种影响

用户的设想是合理目标：每张新片都重新提供本片正负例，通过当前支持样本定义任务，应该比固定输出癌种特定类别更有适应空间。同片往往减少染色、扫描和制片条件差异，支持样本也不必跨片迁移。

但相似性计算依赖已训练的特征函数。如果特征未保留新区分所需的形态或组织上下文，即使支持与查询来自同一WSI，也会把不同结构混在一起，或把同一目标的不同形态分开。少量正点只覆盖局部外观；负点数量有限也不能定义全部非目标。用户要找的是“与示例属于同一个目标概念的全部区域”，不一定是“纹理最像示例的区域”。

当前至少有四层域偏好：结直肠12类训练的region/semantic特征；基于这些特征训练的提示匹配器；有目标的局部episode训练分布；核图/细胞类别与物理尺度输入约定。没有cancer_id输入仅说明API不要求癌种标签，不足以证明这些偏好消失。

因此分别回答：

1. 新片、已有熟悉形态、本片重新给提示：有迁移可能，需实测点击数/召回/误分。
2. 新癌种、共享组织形态、本片给提示：值得验证，不能仅由同片关系保证。
3. 新癌种、新结构/复杂语义目标：提示覆盖及特征表达要求更高；可能需要更多代表性示例或适配。
4. 完全不含目标的query：正确输出应为空，不应强制匹配一个最相似区域。

这些是机制判断，不是当前模型已测出的跨癌种排名。

## 历史实验对整体优化的提示

- 边界：J5→dense大幅提升；多层、逐点视觉交互、小点头的后续增益有限；SegNext停止。64例诊断中55.78%的dense错误距GT边界超过8像素，因此后续不能只聚焦几像素边缘。
- 旧同片跨patch实验已做过，不重提为完全空白。最终严格配对70对的多原型75%local+25%cross训练，远处提示Dice0.5365，local-only0.5318，全cross0.4989；改任务分布有小信号但不足以宣称解决整片泛化。该模型和指标协议均不同于当前dense，不能直接和0.8034比较。
- 旧mixed多原型的64个无目标query、三seed：空目标误触发0.7448、平均错误阳性面积0.2909。前者是“任意阳性像素即触发”，后者补充误分规模。它证明当时该原型路线缺拒识能力，不是本次dense的测量结果；当前dense需要补测。
- 已有旧J5 TLS整片实验，不把WSI能力说成完全没做。单片202247613完整cell vs置零的held-out censored Dice0.7612/0.6992，支持细胞证据实际参与，但不能外推当前dense、所有癌种或全WSI任意组织。旧TLS30及censored指标与密集组织GT也不能混算。

## 下一阶段建议与验收

### 优先1：用当前dense建立实际使用协议，先测缺口

在固定空间验证区域构建同一组query，分别使用query本地提示、同片远处support、同片多个代表性support；另设无目标query。每种协议规定相同的人工点/笔画预算，支持区不计入查询评分；同片远处support仍保持已约定的上下文空间间隔。保留现有固定1024作为回归，不用其GT指导部署点击。

实现v5推理桥接：离线保留图像层级特征和区域/细胞信息；在线先按真实支持生成全局task及query base，再运行dense。未被点击query的本地点图为空，不能把源点复制到各tile；这会偏离目前dense训练输入分布，应先作为诊断并清楚标注，不能保证直接接入即涨分。先做本地模式和缓存模式等价验证，再测跨图块及整片重叠融合。旧v4保持冻结。

输出：local/cross/absent逐例报告，目标存在Dice/BF1/召回、目标缺失错误面积/误触发、同片跨距离和组织分层；来源提示区域排除。检查patch接缝；现有整片已用重叠Hann加权拼接，不把“增加重叠”包装成未实现的新结构。首片准备时间、缓存容量、一次全片响应、局部预览响应分别计时。

验收：数据身份、坐标、GT独立、提示归属、任务版本一致；local重放差异解释清楚。此阶段以测出缺口为完成条件，不把指标必须上升当审计要求。

### 优先2：训练真正的同片匹配与空目标拒识

在同一dense起点上，用匹配更新预算比较固定local任务、local/cross混合任务、混合任务加明确空目标episode；先沿用75/25作一个有历史依据的候选比例，不能默认最优。按固定规则重采样支持位置和目标形态，加入train内相似负例；空目标损失需正确处理空mask，不能沿用当前构造时拒绝空目标的约束。

全片检索先检查召回与拒识，不先加硬候选裁剪；否则漏掉的tile无法靠dense恢复。多个用户确认正例保留不同形态，负例保留不同混淆来源；可以评估多原型/显式匹配度量，但旧逐点注意力负结果已记录，不默认再堆相同attention会有效。人工确认区域才进入支持库，自动预测不直接作为真值回灌。

初筛建议：远处提示macroDice较匹配控制至少+0.01，空间块配对区间支持正向；空目标错误面积相对下降至少20%，存在目标macroDice下降不超过0.002，报告召回及每类结果；本地固定提示BF1回退不超过0.002。门槛是后续实验决策标准，不是预计收益。通过后复验第二seed；任务组合逐项消融，不同时混改encoder、数据规模和损失。

### 优先3：在强dense上加入连续纠错

与优先2分阶段，接入上一轮mask，从train预测FP/FN生成追加正负点，保护原正确区域。已有旧region迭代试验不等于当前dense已经做完。更新提示时重算所有相关task/base，固定提示静态指标和1/3/5次追加点击曲线分别报告；按前向次数/总GPU时间核对预算。

验收：NoC、未达目标比例、可信提示违约、误删正确面积和空目标行为；局部点击不得在所有tile制造同位置硬约束。对同时出现正负点的同一区域保留像素级解决能力。

### 优先4：新WSI/新癌种检验与有针对性的表示优化

追加评估而非改变现有训练split：先选少量新CRC片和两个外部癌种，每张片只用本片支持，包含共享形态目标、不同外观目标、无目标query；模型/阈值固定。由既有目录核实H&E、MPP、核图准备和少量人工组织ROI，空间组学H5AD不直接冒充像素组织GT。目录中的COAD/HCC/OV/肺/乳腺候选只是可核查资源，本次未声明新的组织GT已就绪。

如果跨patch已良好而新癌种失败，再优先比较病理预训练空间特征和现有ResNet特征，在同一提示/decoder协议下做小规模检索及分割比较；使用像素/空间token，不以单个全patch向量承担精细边界。可独立测试减少固定12类semantic输入依赖的训练消融，不能仅在推理时置零后将退化解释为癌种依赖程度。随后按证据决定有限encoder适配和多域训练。冻结细胞分支的领域偏差也需单列，不直接更换成前期未通过的身份头。

替代方案：立即继续加分辨率/随机扩37k、再换一个通用交互模型、直接整模型解冻。现有证据使其优先级低于实际同片协议与任务多样性；并非判定这些方向永远无效。真正高倍细节与MPP/标签精度核验后仍可探索。

## 文献核查与边界

- [UniverSeg，ICCV2023](https://arxiv.org/abs/2304.06131)：通过支持图像-mask定义新分割任务，并通过多数据集任务训练获得未见任务能力。这支持“用支持样本定义任务”的方向，也说明泛化依赖训练设计；不保证病理WSI少量点即可等效。
- [MultiverSeg，ICCV2025](https://arxiv.org/abs/2412.15058)：结合用户交互与已标注图像上下文，减少后续图像交互量。与同片支持库方向相关，但其论文收益不能套用到本数据，不在本轮启动替换模型。
- [UNI，Nature Medicine2024](https://www.nature.com/articles/s41591-024-02857-3)：多组织病理预训练支持更通用的表示；不把通用特征表述成保证任意癌种分割。优先读出空间特征并按本任务核验。

本次仅完成审计和建议；停止SegNext已生效。下一实施阶段应从优先1的dense同片远处/空目标诊断开始，先建立可复现协议和真实smoke，再进入匹配预算训练。

## 用户优先级更新与历史补查（10-16）

用户授权先做当前dense提示—查询诊断，明确后续更需要泛癌种、泛片能力。后续研究以“支持样本定义目标、查询端可靠匹配和拒识”为主要目标；边界指标作为局部质量约束。分别建立新癌种本片支持、同癌种跨片支持、跨癌种支持迁移、未见目标概念评测，避免以CRC局部Dice代替泛化结论。实现独立source/query接口，支持库保留多种外观，训练任务向跨图块/跨域和空目标扩展；在同一协议下再比较通用病理空间特征及有限适配。

补查发现[缺失目标拒识训练0922_134102](../../运行记录/模型实验/运行记录_缺失目标拒识训练_0922_134102.md)已经在旧多原型上完成：同轮mixed/reject的cross Dice=0.5440/0.5517、空目标FPA=0.2672/0.2366、activation=0.7188/0.6510。上文更早0.7448/0.2909是训练前评测，不是最终拒识候选；本次补记后应优先引用同轮对照。拒识有改善但仍有较多误触发；这些结果仍不能当作当前dense或跨癌种成绩。
