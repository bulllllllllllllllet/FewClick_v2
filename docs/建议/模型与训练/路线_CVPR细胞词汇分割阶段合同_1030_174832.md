生效：2026-10-30，用户明确要求废弃旧goal、以后按新goal执行。旧AAAI/rebuttal待办已被替代，不要求补齐历史项目。新原生Goal已创建active；唯一当前入口为根目录goal.md，状态以其链接的新registry和运行记录为准。本文是执行合同，文献动机见[总体大纲](方案_CVPR细胞词汇与双分支编码器探索_1030_173241.md)。

## 1. 目标与完成定义

研究更强的组织图像/细胞encoder，以及细胞词汇和空间组合是否改善少量点击定义的组织分割，重点是WSI远端检出与误报。推理输入为H&E和用户支持提示；组织像素结果不能退化为仅对核实例分类。

目标完成需要：可复现方法实现与权重；清楚的连续细胞/量化/空间组合机制结论；公平的本图和support-query比较；至少一个已审计WSI队列的质量与效率证据；独立确认及多seed；可追溯的论文方法/实验材料。投稿录用不是可承诺的完成条件，实际投稿另按用户指令。训练成功不等于候选有效，科研负结果也可以使某阶段完成，但不能据此宣称主目标达成。

硬边界：脂肪正常监督；保留图像细节支路处理稀细胞组织；保存失败和所有固定样本；空间块split、最大上下文/细胞crop/图邻域隔离、病例来源披露；不强加患者互斥。v4和历史仓库只读；新代码v5，aligner，时间戳NFS产物。训练/归一化/码本仅用train，query GT仅用于训练loss或评价，不能进入推理/候选选择。

## 2. 顺序、资源边界和决策规则

执行顺序：P0 → P1I/P1C → P2 → P3 → P4 → P5 → P6。P1I/P1C逻辑独立，但默认一个GPU训练任务串行，避免共享资源争用；CPU独立接受可另行运行。不自动启动多个agent。物理GPU0/2禁用，优先检查GPU3；只选择实际空闲且允许的卡，不停止他人任务。首次门控CPU2，后续线程数和GPU预算在实测后登记。

每个实验启动前必须有run contract：假设、唯一主变化、初始化/数据/提示SHA、明确train/dev/confirm划分、训练消费数/更新数、优化器、评价/选模点、主指标、停止条件、GPU/CPU/目录。预算或数据未冻结时只能preparing，不能直接正式训练。

v1探索上限：图像encoder首轮最多3种（含当前对照）；细胞特征首轮最多3种（含当前XCell）；词汇首轮3臂，K先固定128，K64/256仅在主要结果成立后做敏感性。获取不到某权重须记录availability问题并重新登记候选，不静默替换。

训练pilot默认上限1000更新×4任务/臂、一个固定seed、固定末步评价。若任务/显存不适配该预算，应在见质量结果前写revision并修改所有匹配臂；步数不是训练收敛保证。cell线性probe可用单独的固定迭代合同，必须同输入和训练方式。先2域×真实样本门控，至少验证实际梯度、参数变化、checkpoint完整重载、mask指标复算。每轮只运行预登记的臂，不根据dev差分自动增加超参。

同一假设最多两次实质pilot（第一次和一个有证据支持的修订）；均无收益则标为not_promising并转入已登记备选，禁止第三轮盲扫。数值/工程故障另计failed，先定位再新目录修复，不自动重试/恢复。训练吞吐决定时间估算；无实测不承诺小时数。

推进门槛分两层：
- 工程接受：身份/坐标/梯度/重载/指标/泄漏检查全通过；失败则质量分数不可采纳。
- 研究决策：试验前指定一个主指标和代价边界；v1下游默认相对匹配对照macroDice至少+1个百分点、BF1不下降超过1点、缺失目标FPA不增加超过1点、预定小目标/脂肪分层Dice不下降超过2点，第二seed方向一致后才全量。类别样本很小时保留CI与逐例结果，不以噪声硬声称优势。

词汇也可走效率路线，但必须提前声明：例如存储至少减半，同时Dice下降不超过0.5点、FPA不恶化超过1点；词表、位置、残差、索引和其它缓存全部计入，不能只数ID。以上门槛是资源决策标准，不等于统计显著性；具体主任务指标在P0冻结，修改须留痕，不能看测试后降门槛。

## 3. 阶段合同

### P0 数据、历史暴露与任务合同

当前状态complete（开发合同限定接受），见当前registry的P0 acceptance及运行记录。原P0交付定义保留如下，下一阶段P1 preparing。

交付物：
1. 两套轻量manifest：细胞表征（实例ID、核/细胞定义、物理crop、mask/坐标、cell label/marker及置信度）和组织分割（空间块、类、GT完整性、支持/查询、物理视野）。
2. 拟合、开发、最终确认的空间域及历史权重暴露台账；候选基座预训练来源另记。旧开发集已反复看过，只用于开发。若无未暴露确认域，记录缺口，不改称blind test。
3. 固定小样本门控集：从每个可用域按不依赖模型分数的规则取代表实例，涵盖边缘、稀细胞、混合组织、ignore/空目标；完整train/dev清单随后冻结，不按分数删图。
4. 固定local 3+2主预算及1+1/5+1次预算；remote使用相同支持预算且query无点击，现有标注有效域与缺失目标规则明确；阈值>=0.5，BF1@2µm沿用已核验规则。
5. 来源与配置SHA、重复/最大footprint检查、配准不确定区处理、可访问权重清单、可用GPU与真实单批耗时。

接受：所有选定实例能够真实解码、覆盖/坐标一致、无防止得了的跨split输入重叠；细胞label与组织label不混用，spot/连续切片不冒充逐细胞真值。数量不足时缩小声明而非制造配对。只允许继续P1门控，不能自动开始全WSI缓存。

### P1I 组织图像encoder筛选

候选：现基线、一个可获取病理预训练空间encoder、SAM空间encoder。固定相同decoder/适配器规则比较特征；SAM原生预训练decoder另作完整系统强基线，不能混作纯encoder因果消融。输入物理范围、分辨率和额外上下文必须分别记账。

先冻结encoder比较，再只对最佳候选做一次有限联合适配对照；最多3个候选，不轮番追逐所有最新模型。输出image-only局部与小规模remote结果、按面积/类别分层、有效trainable参数、提取/缓存成本。

接受：选出一个有明确质量/成本理由的图像底座，并保留对照。若无人改善，保留原底座推进细胞假设，不能把“encoder必须升级”当硬目标。这个阶段不改变细胞检测器。

### P1C 细胞encoder筛选

候选：原XCell、LEMON、一个病理encoder的中心空间特征。相同实例集合，中心crop的真实µm尺寸和额外上下文显式披露。复查0907 Phikon、RNA teacher失败，不原样重复。LEMON专用输入规范按已核验官方模型卡；改变输入需显式对照。

指标：细胞检索的同类precision@k、macro-F1/balanced accuracy、稀有类及跨空间块稳定性、染色敏感性与cells/s；检索库只用train。cell数不是独立WSI样本数。不仅用UMAP挑模型。特征/label打乱负对照检查管线是否利用泄漏。

接受：冻结一个候选及其输入规范；细胞probe即使提高也必须进入相同图像底座下的连续细胞下游对照，不能直接宣称分割提升。若所有可靠细胞probe都接近shuffle，先查crop/配准/本体；本阶段允许一次有证据的输入修订，仍失败则缩小到可靠形态监督，不盲扩百万细胞。

### P2 细胞词汇是否必要

同一cell encoder、图像底座、融合decoder、训练样本和预算：A连续特征+同容量adapter；B train-only k-means固定词表；C可学习词汇，首轮K128。记录是否保留连续残差及维度，并保证容量/计算差异有对照。正样本采用同实例合理增强和可靠标签/层级关系，不能将所有不同实例都当不同生物类型负例。

同轮检查重建/量化误差、有效码数/频率、稀有模式、跨增强和跨空间域稳定性；观察码是否只编码染色/来源。必须跑到组织mask，而不是止于cell分类。固定图像encoder避免收益被换backbone掩盖。

分支决策：质量路线通过→保留词汇；仅效率路线通过→如实定位压缩收益；两者均不通过→否定本次离散化假设，保留连续cell token继续P3，不强行包装tokenizer贡献。两次pilot均无收益停止该码本配方。

### P3 空间组合与提示迁移

先固定P2表示，比较不带空间的组成汇总与局部稀疏空间聚合；再单独比较local-only训练与包含remote/absent的训练。不能同一实验同时换表示、邻域、损失和任务。组学监督为可选后续，未证实单细胞对应前不纳入主路线。

用户正负点生成有符号多原型支持表示；query热图为零，图像特征提供完整组织边界和稀细胞组织证据。合理SAM特征/迁移桥和可训练基线同样获得匹配的remote任务机会；桥与SAM原生本图解码分表。

控制：保持细胞位置/数量而打乱形态；连续表示与量化表示在相同空间模块下比较；重新训练image-only与原XCell对照。单纯推理置零是敏感性分析，不能替代训练消融。目标是相同标签/提示预算下更好组织检出，不能剪掉未含点击的真实远端目标。

接受：至少一个可解释模块效应进入下一seed复验；若空间关系无效保留简单融合，不自动增加全局图/第二级niche码本。不同任务的效果权衡明确，不用局部表替代WSI证据。

### P4 WSI扩展与效率

在P0数据范围内冻结整片/有效区域集合、支持选择、查询域与GT缺失规则后扩展。旧15WSI可复用但不是必须用满的旧任务债务；其8895位置/26685视野已执行准备、独立接受未完成，复用前核验身份/完整性，不重新训练码本到query。

先2张不按候选分数选择的工程门控（含细胞稀疏与密集场景），通过后才对固定完整队列运行。实现实例去重、局部聚合/分层索引、分窗密集解码，避免全WSI百万细胞全连接attention。

交付：逐WSI/类质量、远端present Dice、absent FPA（无合格样本时NA）、非目标像素误报、点击预算、首片准备/特征缓存/冷启动/缓存后点击/输出IO、内存/显存/存储。声明实际覆盖域；只有固定域全预测和独立计数/BF1接受后才complete。

### P5 独立确认与统计

先冻结候选和主张，再进行三训练seed及P0隔离的确认空间块/外部数据。保留病例来源，空间来源聚类不确定性与seed方差分开。对照SAM/WSI-SAM按当前任务充分适配；新增标签、预训练、视野、计算和调参预算披露，禁止把retained-J5比较称同总监督。

不得在确认集继续挑K、阈值、checkpoint或删除失败类；确认失败记录为失败/不稳定，并将该集合标记已暴露，不循环当新的盲测。负结果进入论文范围界定。超过SAM的主张仅在对应任务/预算的完整配对证据支持时使用。

### P6 方法与论文证据包

输出最终模型配置/权重/源码版本、环境、manifest/hash、可复现命令、图表原始行、失败台账、贡献与先例对照、数据/预训练说明及方法/实验稿。先重写最终真实方法，不能把新架构称旧稿笔误。投稿日程和最终投稿操作另核实，不以本路线文件代替提交。

## 4. 防跑偏机制

1. 每个任务必须属于当前阶段，有单一问题、对照和下游联系。研究台账记录理由；没有阶段归属的工作不启动。
2. 每完成一个阶段更新goal当前动作、新registry状态和acceptance路径、当前run记录、IMPLEMENTATION_STATUS；下一动作来自这些证据，不来自旧聊天中的待办。
3. 所有失败进入`failed_hypotheses`，写清不同数据/结构/预算下的适用范围；再提同方案必须引用旧失败并说明新差异。
4. 不因新文献不断加模型；新候选替换现有名额并解释理由。RNA、第二级niche码本、大规模自监督预训练均为deferred，直到主要机制有效。
5. 每次简报只回答：当前阶段、已接受证据、仍未知、真实运行及下一步。报告planned/preparing/running/failed/complete，另列quality_outcome，不混淆执行完成与改善。
6. 连续两次无效pilot触发机制复盘而不是扩训练；保留连续token和简单融合等明确备选。重大研究问题改变须用户决定；正常实现/调试/已登记分支可自主推进。
7. 旧AAAI registry仅历史索引，不作为排队入口，不自动启动未完成的旧消融/留出/审稿回复。旧缓存只按新实验的数据合同复用。
