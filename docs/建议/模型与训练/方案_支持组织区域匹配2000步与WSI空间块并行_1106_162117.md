# 支持组织区域匹配及WSI空间块试验合同

2026-11-06T16:21:17.766370+08:00 用户授权两方向并行，沿FewClick核心目标少量支持点击→查询零人工点，不恢复旧AAAI或旧seed队列。输入/初始化/损失/冻结策略/空间split/评估沿接受的2000预算，具体源/公共权重/数据SHA在/nfs-medical3/zyh/fewclick_v2/cvpr_research/support_region_study_1106_162117/study.json。新产物全时间戳，旧模型和数据只读。

## P3唯一模型变化

control精确原SignedMatcher；region相同参数/头，仅改变点击描述向量：对每正负点计算与支持投影64维网格的cos相似度，温度0.1 softmax后分别乘支持基底预测p或1-p，归一化加权得到对应组织描述。与原点单位向量各0.5融合再归一化，用原max/mean正负7通道matcher和零初始化输出残差。每个点一个描述，非额外类别词表。支持预测来自同图基底decoder并detach权重，不用完整support GT，不读query GT，不另加loss/阈值/encoder/细胞/RGB/presence；原图像三视野与全部loss保持。原基底已具区域token/attention，不称首次增加区域上下文。

先真实6任务（2域×local/present/absent）验证两臂参数/初始state完全相同、初始query/support logits精确相同；随后两臂各独立256更新×4（32固定train循环）功能门控，原Dice>=.2、absentFPA<=.1、std>=.02、swap>=.001，fresh optimizer继续和32mask独立接受；smoke2step/12mask独立通过后正式2000×4。同seed20261103同8000任务字节顺序，AdamW LR/WD1e-4，固定末步/0.5/BF1@2µm。各3711完整mask独立重算/fresh12，monitor0/250/500/1000/2000。

最终控制臂checkpoint state及3711行必须精确重现原已接受2000基线；不一致则先查工程、不能抢报质量。主remote宏至少+1pp、原10质量/代价门槛全部通过才候选；local/remote分表，全类别/脂肪保留。若强调小组织机制另看>=5pp增益，不能只凭总体涨分称已解决。一个开发seed候选须第二seed确认，本轮不自动追加。

## P4起步：3WSI空间块工程验证

WSI队列沿已审计原CRC同源数据；在至少2个val索引且有既有remote支持任务的切片中按source identity SHA选3，不按模型分数选择。每片固定一个现有允许支持任务/组织目标；对其所有已索引val位置推理，排除与support最大4x输入重叠。query最大4x上下文与同片全部当前train输入footprint逐一检查，保留来源/空间块/病例，不改患者互斥。支持/target以既有episode SHA选定，不用queryGT调候选/阈值。只用GPU1已接受2000基线，0训练更新；生成真实WSI缩略图、验证块GT/预测/支持点可视化及逐任务指标，独立mask复算。

明确范围：全片缩略图加验证空间块预测，尚非连续全片扫描，不能量化未标注全片Dice/接缝或当P4完成。此pilot核对真实WSI读图、可用标注、单支持跨位置与空间隔离；连续栅格拼接/大面积缓存/完整计时作为之后阶段，不能冒称已经验证。

## 并行资源与停止

GPU0 control、GPU2 region、GPU1 WSI，CPU2/worker；用户全部六卡授权，本轮最多两个独立训练worker+一个只读推理worker。每stagefree>=12288MiB，显存够可共享，绝不终止他人任务。WSI独立于训练，与preflight及两臂可并行；两臂preflight通过后同时功能门控→各自smoke→正式→独立接受，比较等待两组完整接受。失败停止该依赖链，记录EXIT_CODE，不自动重试或重复活动任务。新源码冻结，不在运行中改。
