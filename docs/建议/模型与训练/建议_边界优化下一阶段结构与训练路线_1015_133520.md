# 边界优化下一阶段：结构与训练路线

- 问题：已有稠密分支BF1=0.557040、点细化目标调整最后轮0.559498之后，哪些方向比继续调小点头更值得验证？本记录是建议，不启动新训练。
- 依据：系统诊断184115、同96k预算对照221710、像素细化负结果122728、目标调整125213正式报告、目录迁移132345；已核查当前DensePromptDecoder、PointBoundaryDetail及Phase2 backbone接入代码。
- 本地事实：同1024val原J5/3k8轮dense128/3k32轮dense128 BF1=0.329043/0.523092/0.557040。12k8轮=0.555609，和3k32轮同96k更新差异区间跨0。恢复边界监督相对点头原损失有效，但global最后轮相对coarse仅+0.002458，未过+0.01门槛。不能据此否定所有更大数据量或所有点细化。

## 第一优先：完整多层特征稠密解码器

- 当前layer1特征256通道被固定分组均值成32通道，dense128融合后主要依靠双线性插值恢复512输出；新RGB点头只有12905个参数，尚未验证完整预训练多层特征解码。
- 候选：保留提示/任务条件及现有语义上下文，读取未经固定平均的原生浅层、中层和深层特征，使用可学习通道投影与FPN/UNet式逐级融合，增加128/256像素特征上的预测与深监督。需要测实际backbone输出尺寸，不能假定当前空洞卷积ResNet就是普通32倍降采样金字塔；256分支可考虑stem特征，配置待实测。
- 它改变语义与细节融合及像素预测能力，不等于把输出尺寸从512变大。先分别验证原生浅层投影、增加中层融合、增加256分支，避免把所有因素混为一项提升。
- 推荐先冻结encoder做结构对照，再决定有限解冻；仍缓存图像特征，点击时只运行提示与解码器。新cache必须单独版本，测容量/ROI时延，不每次点击重跑WSI encoder。
- 预期：相比两层RGB小头，更有机会改善组织语义边界；这是工程判断，尚无本任务收益证据。风险：缓存/显存增长、细节分支追随核纹理、训练预算不足或过拟合。

## 第二优先：在较强稠密解码器上有限联合训练

- 之前layer4解冻相对匹配head控制最后轮BF1额外+0.005587，支持单独验证特征适配；该实验从早期3k8轮版本开始，没有证明在当前最佳候选上收益相同。
- 对照冻结encoder vs layer4+head，必要时再单独layer3+4；同起点/数据/更新/优化器重置策略，冻结BN统计，小学习率。训练必须重新计算更新的deep/semantic特征，不能复用冻结cache假装解冻；输出新encoder/checkpoint/cache版本。
- 风险：耗时和显存增加、历史特征忘却。先完成结构对照，再组合，便于解释贡献。

## 第三优先：训练样本组织、监督与推理分布

- 现有point训练采样与应用选区仍不同；新增整幅推理mask辅助loss没有改变原4096点balanced BCE采样。可保持模型和loss，独立比较训练点从推理选区抽取与原策略，保留双侧支持并记录实际点数/计算量。
- 只用train做难边界/高曲率/易混类别难例重采样，同时保留普通图块，报告是否改善特定类别而非仅平均值。不是单纯增加随机patch。
- 现有12类semantic head仅作训练期辅助分支/蒸馏的备选，不把已知query类别ID直接输入交互推理；原闭集semantic对照不是提示模型的可比上界。该方向须单独验证，不和结构一起默认加入。
- 风险：难例噪声放大、采样点Dice统计偏差、只改善开发集；任何learned weights/阈值由train确定。

## 较高成本备选

- 真正20x图像的同物理视野细节：先审计WSI分辨率/GT对齐与组织标注精度，再比较10x512与20x1024。直接插值10x图像不新增信息；若GT边界粗糙，收益可能受限。
- 独立交互模型对照：SimpleClick等在同图像/同提示下适配比较，另报连续点击效率。其点击进入backbone，缓存/延迟契约会改变，不能视作当前head的无成本替换。
- 边界方向场/SegFix或完整PointRend迭代细分可作后续结构备选；当前实现仅借鉴不确定点选择，不是完整PointRend。组织边界的内部预测未必总可靠，先验证假设。

## 建议执行与验收

- 下一轮首选：固定3k/1024，缓存真实多层特征并做真实smoke；以dense128为控制，分开加原生浅层特征投影和逐级融合。先核查预算/初始化可比性，记录相同更新点、实际GPU时间与缓存成本；若从新头随机初始化，不把8轮新头与32轮旧头差异全部归因于结构。正式预算与配置在smoke实测后记录，不在本建议中暗定。
- 若有望超过coarse，再在同一路线上有限解冻和难例训练；不并行混改结构/数据量/损失/学习率来宣称单因素收益。
- 同提示/固定1024val，参考门槛仍为相对coarse BF1+0.01、macro/micro Dice≥coarse−0.002、可信提示违约不增；报告各类、107空间块配对、最后轮与最佳轮，并对更强global点头作附加比较。通过后第二种子及真实连续点击/未暴露空间区域评估。
- 当前开发val有选模和历史encoder暴露，不能视为独立泛化。用户允许同病例跨split，保留空间分块，不恢复病例分组。
- 暂不优先延长当前小点头训练或直接扩37k；不是断言这些方向永远无效。无新训练/部署动作。

## 本次检索的一手依据

- [DeepLabv3+](https://arxiv.org/abs/1802.02611)：结合多尺度上下文和逐步恢复空间细节的decoder，论文在自然图像数据上验证边界改善；为设计动机，不保证本病理任务收益。
- [PointRend](https://arxiv.org/abs/1912.08193)：基于迭代细分，在自适应位置进行点预测；当前一次性选点小头不等价于完整方法。
- [SegFix](https://arxiv.org/abs/2007.04269)：预测边界到内部的方向，用内部预测修复边界；作为替代机制的依据。
- [SimpleClick](https://arxiv.org/abs/2210.11006)：点击编码进入ViT backbone，适合独立交互结构对照，同时意味着现有离线缓存策略需要重新评估。
