## 假设和唯一变化

旧模型已有逐点region prompt attention，不宣称其仅有单一task token。新假设是：绕过区域汇总，对fine图像embedding进行多正负支持点击的直接空间匹配，能改善远端前景选择。保留Phikon三视野、冻结backbone、原区域/graph路径与原loss；新增共享256→64点卷积，真实支持坐标确定性双线性采样，归一化后逐点击与query空间余弦相似，正负各max/mean、max差、原概率/不确定性共7通道，1×1 MLP输出logit残差。输出层零初始化。不是RGB细节头，不引入query提示或GT，不是新encoder因果对照；Phikon原生32网格插值64限制仍在。原图路径已有效的单点机制不能冒充新贡献。

control为当前image-only区域模型包装；match只增加上述模块。支持mask仅来自原训练损失，不作为推理输入；不读类别ID。local直接匹配同图点击，remote仅采样support点击，query无人工坐标。包含无目标query。细胞输入清零且扰动不影响预测。负点击至少1点，沿现1+1/3+2/5+1协议。

## 固定预算与验收

两臂从公共fresh初始化开始，各1000更新×4任务，AdamW lr/wd=1e-4，无新增预热/选模/阈值调整；使用原8000固定消费文件前4000行（一次4000任务），同点击/顺序/监督，含remote支持mask损失0.25等原episode objective，不承接功能checkpoint。0/250/500/1000记录32固定train监控。旧2000步结果只参考，不能当匹配控制。

工程六组local/present/absent×CRC/TIGER，初始化logit等价、control两次更新精确复现旧I、fresh optimizer继续、cell扰动无效、remote query maps=0、匹配投影梯度、支持描述敏感、支持顺序不变及bypass检查；各20次真实更新/100推理测吞吐。随后每臂固定32train任务256×4功能学习，六组Dice≥0.2、spatial std≥0.02、swap≥0.001；absent FPA≤0.1，全部32fresh重放和独立mask验收。通过后双2step/12mask smoke及独立接受，再自动双1000正式小试和各3711评估/独立mask接受、统一比较。任何失败停止，不静默重试或降低门槛。功能学习有限子集不是泛化。

主指标remote类别宏Dice≥+1pp；原BF1/FPA/small/fat和域内FPA等完整10项守门不变。本图是重要次目标，最终希望公平超过SAM。单seed/已暴露开发集，条件区间不等于独立确认；无自动seed2/WSI/新encoder。成功仅构成后续正式预算/复验候选。此轮不运行SAM基线；SAM桥完整重评仍为后续计划，不冒充已完成或用70%本图替代remote。
