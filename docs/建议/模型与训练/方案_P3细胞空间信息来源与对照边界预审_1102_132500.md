## 问题与证据范围

路线要求比较不带细胞空间定位的组成证据与局部空间组合。但当前三视野模型已有细胞定位、图像区域空间图和跨尺度关系，不能将它称为“无空间基线”，也不能把已有机制写成新增贡献。

## 已有机制

| 路径 | 实际行为 | 对照解释的限制 |
|---|---|---|
| 细胞输入 | P2仅变换后64维；前10维保留x/y、面积、未知核类one-hot。`CellToRegionAttention(256,74,128)`对全部74维做LayerNorm/MLP | 直接对完整cell输入平均也可能包含坐标，不能自动称为无定位表示 |
| 区域分配先验 | 在真实cell x/y上采样soft assignment，`log(mass)`进入区域到细胞attention | 现有cell-to-region已利用空间对应关系 |
| 区域密度 | sampled mass分配保留细胞数量，再按真实总数/保留数缩放，作为log密度进入融合 | 移除定位时，密度也必须明确改为全局一致规则，不能保留空间密度后声称无定位 |
| XCell64 | native loader关闭large ViT；small transformer只接768维crop特征和valid mask，当前forward未添加细胞间坐标/位置embedding，CLS提供全视野集合上下文 | 按源码推导，eval时cell集合路径应置换等变，但尚未做本次权重数值门控；64维也不是独立无上下文的单细胞描述 |
| 原生crop | 32µm mask-attended crop仍有局部RGB、形态及周围图像上下文 | XCell未接细胞间坐标不等于特征不含任何空间形态信息 |
| 图像与层级 | 三视野区域assignment、物理对齐overlap边、hierarchy和区域几何保持 | 移除细胞定位不意味着整个系统无空间信息 |
| 区域图 | 各尺度区域kNN（当前k=6）与跨尺度边约束decoder消息 | 新cell邻域与现有region图必须分开命名与消融 |
| 提示迁移 | remote query的prompt maps为零，但support prompt geometry进入提示token及task编码，query有自己的区域geometry；当前Dense=False，local/remote maps仅返回审计，不喂入graph预测 | query热图为零不意味着任务token没有support坐标信息，也不能据此宣称完全位置不变；当前实际提示路径是support token，这不是query GT输入 |

## 候选对照设计：拆开两种细胞定位渠道

建议在P3机器合同中先考虑下列2×2，避免同时改变已有位置输入、区域定位和新增邻域后归因。它是待P2结束后审查的候选设计，尚未固定为四臂训练合同或新增pilot预算。

| cell MLP坐标渠道 | 区域mass/密度渠道 | 含义 |
|---|---|---|
| 常数坐标 | uniform mass | 全视野无显式细胞定位的content attention组成参考 |
| 真实坐标 | uniform mass | 在上述参考上单独提供cell坐标 |
| 常数坐标 | sampled mass | 单独提供cell-to-region对应及分区密度 |
| 真实坐标 | sampled mass | 当前cell定位机制的匹配重训参考 |

“常数坐标”仅作用于送入cell MLP的副本，候选常数为预先固定(.5,.5)，不得覆盖原几何或改变sampling所需的真实坐标；uniform mass为每cell每region 1/K，对应region count=total/K。region query仍能按内容检索整个cell bank，因此该行叫“无显式cell定位的content attention”，不叫单一均值向量或整个模型无空间。

四种设置可保留相同cell MLP/query/key/value/fuse参数；全部使用同输入视野、真实数量、valid/cap、图像/层级/region图、支持提示及loss。常数坐标会影响joint LayerNorm输入分布，这一限制必须披露，不能把它等同于纯粹数学删除一个独立位置通道。需要匹配从头训练及形态重排控制支持解释，不能只把已训练模型坐标置零。

路线已要求的image-only重训和保持metadata10/位置/数量、只在视野内打乱后64维形态的控制仍保留；形态重排保留原XCell集合上下文，不能称重新提取了独立细胞特征。P3正式合同需统一安排这些控制的预算，不能因本预审追加无上限训练。连续/量化表示只有在同一空间配置下才能比较。

## 后续执行顺序与接受边界

1. 等待P2的三臂完整mask接受、固定六守门与表示分支，必要的seed/效率证据齐备后固定表示；不为使tokenizer成立而保留失败词表。
2. 在P3实际合同里固定最终对照、预算、共同初始化及源码；P2末步仅作描述参考，不能与不同预算的新头训练混成等监督胜负。
3. 先真实input/model/loss/checkpoint/optimizer继续和功能学习门控；核对常数MLP坐标不意外影响定位mass，uniform density恒定、空细胞场景有限、query GT不进forward。无数值/功能证据不得全量。
4. 空间对照先保持同一mixed local/remote/absent任务，再独立研究local-only与mixed训练；不同时换表示、邻域、任务、loss。新的细胞kNN/radius模块只有在明确假设和现有预算内登记后才实施，不能把region kNN重命名成新细胞图。
5. 使用既有local/remote分表、稀有/小目标/脂肪代价和原六守门；有解释性效应才进入下一seed。若空间效应不可靠，保留简单融合；不自动扩全局图/第二级词表。support坐标影响若要研究，应作为另一独立因素，不与首轮cell空间变化混改。

本次没有修改v4、旧FewClick、当前v5训练源或任何权重；没有增加GPU作业。预期收益是避免空间机制与提示迁移的归因混淆，实际分割收益仍未验证。
