# 方案二：HG-mix 收益归因与最小补充消融

日期：2026-11-12。状态：**planned，不启动新增训练**。HG-mix 按用户决定固定；消融用于解释收益，不自动替换固定方法，不增加 seed。

## 需要回答的问题

1. H 的稠密对应关系在融合特征下是否仍有效？
2. 子块细节与整幅上下文分别贡献什么，二者是否互补？
3. 原区域表示和跨尺度上下文在新的稠密分支加入后是否仍有必要？
4. 哪些类别、尺寸、覆盖/边界或误报变化解释当前领先？

## 已有证据的复用范围

以下五个独立从公共初始化训练的模型使用同9500/2375、seed20261103及同11000评价；可直接复用其接受证据，形成机制对照。

| fine 特征方式 | 不加 H 稠密分支 | 加 H 稠密分支 |
|---|---|---|
| 原整幅 fine | 原始受控 FewClick：39.19 /73.81 /6.71 | H：39.97 /76.51 /8.10 |
| 四子块 fine | G：40.16 /74.63 /5.74 | HG：40.87 /76.84 /7.04 |
| 整幅与四子块等权融合 | **M：待补一组** | HG-mix：42.11 /78.49 /7.75 |

表中数字依次为整体 Dice /大目标 Dice /absent FPA，单位%。这里的“原始受控 FewClick”是当前公共 Phikon 初始化的受控实现，不是 AAAI 旧 J5 checkpoint。

这张 2×3 表已经有5格，补 M 即可完整回答：H 在三种特征条件中的收益、融合相对子块或整幅的收益，以及两因素是否存在数值交互。单 seed 下报告观察到的差异与条件区间，不将其包装为跨训练随机性的证明。

## 必做新增训练：两臂优先

### A1：M——融合特征，不加 H

- 与 HG-mix 相同的 frozen Phikon、整幅/四子块 `.5/.5` 融合、三物理视野、区域/跨尺度图、SignedMatcher及原完整损失。
- 仅移除 H DenseHierarchy 修正分支；从公共初始化正式训练9500/2375，不在已训练 HG-mix 上直接关分支冒充训练消融。
- 每图仍7次 encoder，支持点击不变；列明减少的 H 参数和训练成本。
- M vs HG-mix 测量“在相同融合特征下加 H 的收益”；原/G/M 与 H/HG/HG-mix 分别检验细节、整幅与融合。

### A2：HG-mix 无跨尺度区域消息交互

- 继续提供 fine/2x/4x 三幅输入，继续7次编码与相同融合，区域头、prompt、SignedMatcher和 H 保留。
- 仅将原区域图的跨尺度 bottom-up/top-down 消息路径替换为 identity；保留区域数、维度和其余路径。实现前核对实际 forward，避免把多尺度输入、尺度映射和 H 内部粗细关联一起去掉。
- 从公共初始化同预算重训；这组检验原层级区域上下文是否仍对最终方法有贡献。
- 它不能替代“只看 fine 单视野”的信息量消融；如后续确有必要，单视野另列，不能混用名称。

## 条件补充，不默认全开

| 消融 | 触发条件 | 解释范围 |
|---|---|---|
| signed set encoder→正负均值原型 | 论文把学习的提示集合编码列为核心贡献 | 同输出维度、相同支持点和下游预算重训；明确容量变化 |
| HG-mix 无额外点击锚定/粗层先验 | 需要判断是否能简化最终方法 | 可先固定权重诊断；正式结论需同预算重训。当前固定方法继续保留两项 |
| 无 SignedMatcher 残差 | 论文声称原点相似度路径和 H 两者必要 | 只关 SignedMatcher 的预测残差，保留 H 所需共享 projection；不能误删 H 输入特征 |
| 细胞分支重新加入 | 出现新的独立机制和 train-only 证据 | 当前主线无此需求，不为了沿用旧论文贡献而自动重启 |

先完成 A1/A2，最多再按论文主张选择一个必要补充，不扫融合权重、不扩展 encoder 搜索。原始模型/H/G/HG/HG-mix 的完整矩阵比重复低价值训练更优先。

## 已完成 H 拆解如何使用

`h_component_diagnostic_1112_122744` 已接受11000×4预测。H关闭额外点击锚定及粗层先验后，大目标76.51→76.72、FPA8.10→8.27，整体仅39.97→39.99。

这是固定权重下的推理敏感性，其他点击路径、粗层传输通道和整个 H 分支仍在。它没有证明 H 无效，也没有证明这两项在训练时必然无用；目前不支持把这两项单列为已证实的主要 Dice 贡献。结果放入机制诊断/附录，不能代替 A1，也不能称去掉所有点击或整个层级结构。

此前旧队列的 no_match/no_negative、细胞/P2词表、旧细节分支等研究作为历史探索证据保留；未在当前9500/最终结构下重训的行不放入最终方法的严格消融表。旧全片效率/稳健性也不能直接赋给 HG-mix。

## 不需新增训练的分析，优先并行

1. HG-mix、HG、H、G、原受控 FewClick、SANSA：复用已保存完整预测，统一逐类/面积分层/Dice/BF1@2µm/precision/recall/absent FPA。记录样本数，重点解释正常间质、上皮、脂肪及稀有类别，不只列优势类别。
2. 同任务、同 WSI 的配对差值和 WSI 聚类 bootstrap；大目标阈值固定20%，全体结果完整保留。检查是否只由一两个 WSI 或稀有组织驱动。
3. 支持区域面积和组织异质性分层，查看融合是否缓解子块丢失整幅语境的问题。这是关联解释，不能单凭分层证明因果。
4. 固定 SHA/几何规则选择成功与失败案例，显示支持图与点击、query HE/GT/完整预测、差异图。病例选择不用于推理、阈值或模型更新，图注明确选择规则。
5. 训练 monitor0/250/500/1000/2000/2375 对比；训练拟合与评估差距分别讨论，不从末步训练 Dice 判定泛化。

## 最终 HG-mix 需要补的系统证据

用户追加的整片一次点击实验为必做：[整片WSI方案](../数据与评估/方案_HGmix整片WSI一次点击分割与评价_1112_165407.md)。它实际累计全片唯一像素的TP/FP/FN，包含整片与remote-only两种范围。优先比较固定HG-mix与当前SANSA，再将A1/A2必要消融带入相同的小规模WSI子集；先解释完整模型，不默认每个可选消融都跑全部15片。

- 缓存：按实际新模型测特征准备、区域编码、缓存体积、首次预测及重复点更新；HG-mix 每图7次编码，不能复用旧模型3次编码的准备速度结论。
- 点击稳健性：冻结当前权重，复用/重新核定共同点击预算和扰动清单；保持 query 人工点0，比较支持点击变化。若执行会产生新的 GPU 推理，需作为单独planned任务登记，不混称已完成。
- 完整 WSI 演示/质量：可复用旧任务的几何和采样清单，必须用新权重重新推理；评价只在允许的空间留出有效区域，支持及训练footprint排除。全片部署耗时与留出区质量分别记账。

上述系统证据与 A1/A2 可以并行，但本轮只规划。旧历史确认集的暴露问题如实标注为同队列/空间确认，不强加新的患者互斥或独立数据收集。

## 训练门控、成本与接受

A1/A2 均同9500任务/2375更新×4/seed20261103，公共初始化、同监督/优化器/末checkpoint/阈值.5，同11000任务；不继承 HG-mix 已训练权重。train32/256 gate、fresh optimizer继续、真实分支使用、冻结状态、fresh4/训练消费SHA、6task evalgate、两5500分片和磁盘重评分全部执行。局部交互与远端迁移分开。消融不能靠未收敛或空预测制造大降幅。

本轮实测 HG 类正式训练约1.8–2小时，双分片完整评价约1.7–2小时；新臂以其真实 gate 的吞吐和实测峰值重新估算，资源共享会改变用时。A1/A2 可独立并行，和方案一共用建议的最多3训练/总最多6GPU worker调度。有效消融的接受是“设计正确且全流程完整”，无论涨跌均保留，不要求必须掉分。
