# 原生SAM2候选失效后的备选顺序

状态：条件建议planned，未启动新实验，不终止当前F评价。用户问F若被排除是否还有路线。依据当前goal/registry/current run、BCD逐类分析和此前路线；2026-11-12复核SSP与HDMNet原文摘要。

当前F同时改变encoder和接入冻结native decoder，并固定native+coarse融合。单个F负结果只否定该具体组合，不等于否定SAM2所有适配方式。先完成11k，再对coarse/native/fused作机制拆解；不得按val挑最优输出冒充新正式模型。基线原Few大目标73.8085/SANSA77.2201，FPA6.7115/14.7866。

优先E：原Phikon FewClick+支持锚定query自适应。第一次预测后，收集query高可信目标/非目标特征，保留支持正负证据，以一次修正补足同类外观差异。仅train定可靠度/阈值/一次迭代规则，训练推理一致；无query GT、无新增query点击、无跨评估patch伪标签积累；无可靠目标证据时禁用自增强。目标召回和Dice提升同时控制absent FPA，不能将普遍扩大预测当改善。此机制尚未跑，不是已证实收益。SSP研究利用高置信query原型，支持动机而不保证病理少点击迁移有效：https://arxiv.org/abs/2207.11549 。

第二路线：原Phikon+区域引导的层级稠密匹配。保留软区域与多尺度上下文作候选区域先验，在连续support/query特征间保留更细对应，再产生任务条件分割；支持证据必须由点击/模型预测产生，不可推理读support完整GT。区别于A固定4x4池化和B单层压缩token attention：主要改动为保存细粒度对应、粗到细匹配，不是再堆同样小attention头。HDMNet提供层级dense correspondence及跨分辨率相关性传递参考：https://arxiv.org/abs/2303.14652 。标准mask-support论文设定不同，需重新验证少点击和absent行为，计算/缓存成本须实测。只有E无收益或证据指向支持区域压缩损失时再考虑，不同时多臂全开。

第三路线有条件：真实高分辨率Phikon特征。只在粗匹配正确而轮廓/局部遗漏主导时，在同fine物理footprint内2x2子块编码拼接，2x/4xcontext保持；可缓存，fine编码次数4倍。多层特征仍原32网格，不能称原生分辨率提高；当前C浅层RGB细化失败也不等于真实高分辨率失败。代价为WSI准备吞吐/存储增加，不以此默认解决语义混淆。若小目标已作为局限，避免挤占大目标主线预算。

不优先重复B/D配方、仅换backbone、最后一层解冻（旧协议已阴性）、更多相同seed或无目的加步数；细胞词表无新机制证据不重启。不承诺任何路线能超过SANSA。条件顺序：F完整评估及拆解 → 若停用F，回原Few单独检验E → 根据失败模式决定层级匹配或真实细节；每轮固定9500/2375和完整11k、阈值/空间拆分/支持点击不变，原有全类别与误报完整报告。此前多次暴露开发集，单seed小涨点不代表稳定优势。
