# Panel1 图块内细胞交叉注意力试验

- 问题：现有 128/256 单细胞特征头只看目标细胞及周边像素，不能直接比较同图块其他细胞的形态和空间关系；少数类识别仍弱。
- 证据：既有 Panel1 多尺度 MLP 在补充均衡测试集低于线性基线；14,984 细胞缓存保留 patch、HE 核中心及空间 split。全量三病例特征正在提取，但尚未经过区域配准筛选。
- 推荐：冻结图像编码器；以目标细胞的128像素特征作 query，同一512像素图块其他细胞的128像素特征作 key/value，附加相对坐标与距离；softmax 注意力聚合后以门控残差融合目标特征，再分类。周边像素信息已在128像素编码中；可增设256像素目标视野作独立对照。
- 对照：相同特征、划分、训练参数下训练 target-only 与 cross-attention 两臂；同一图块最多16个邻居，不输入邻居标签。以原 val 选 checkpoint，只一次报告原 test 与补充均衡 test。
- 预期收益：血管/淋巴内皮和间质细胞可利用群体形态、密度与相对位置；跨癌种可沿用无器官类别词表的图块编码结构。
- 风险：旧缓存只包含抽样细胞，补充测试集每图块多数只有少量细胞，无法充分评价上下文；全量新缓存要独立复核配准，并固定空间组划分后再复测。注意力模型参数更多，可能过拟合。
- 验收：校验无跨 split 的同图块输入，保留零邻居目标可推理；核对特征形状/有限值，报告每类 precision/recall/F1、macro-F1、accuracy 与邻居数分布；仅在原 test 和补充 test 均有可复现提升时考虑替换。
- 状态：待实现和运行。

## 试验回填

- 128注意力与同条件target-only比较：原test三种子均值0.349 vs 0.355；补充test 0.247 vs 0.222。
- 加入256目标视野后：原test 0.382 vs 0.395；补充test 0.213 vs 0.194。
- 决策：保留为可选模型，待全量三病例候选缓存配准审计和完整图块邻居清单后复测；当前结果不支持默认替换。
