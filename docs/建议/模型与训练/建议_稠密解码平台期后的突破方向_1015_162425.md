# 稠密解码平台期后的突破方向

日期：2026-10-15。状态：已完成历史复核、文献检索和64例只读诊断；本记录提出下一阶段实验，不代表新模型已实现或新长训练已启动。

## 问题与结论

问题：在原始J5→dense取得大幅收益、多层特征仅增加约0.003 BF1之后，还有什么机制可能带来大幅提升？

优先验证“像素级提示匹配 + 动态纠错任务”，其次验证视觉与提示表示的有限联合训练，并以成熟交互模型作独立对照。进一步堆浅层分辨率、延长相同小头或单纯随机扩图块的优先级下降。现有证据不能保证任何候选提升幅度；将BF1@2相对0.557040提高0.05作为大幅提升目标，不作预测。

本地依据：组织边界系统诊断184115、下一阶段路线133520、多层实验最终记录133617、固定预算数据对照221710、点细化目标调整125213；当前dense_prompt_decoder.py、multiscale_dense_decoder.py、train_multiscale_dense.py、v4 Phase5 PromptSetPool；0920可扩展原型方案和0923迭代纠错方案。保持用户定义的提示驱动二元输出和可扩展任务，不改成只能选择12个类别。

## 新增64例诊断

产物：`/nfs-medical3/zyh/fewclick_v2/boundary_refinement/remaining_bottleneck_1015_162425/`。运行记录：[稠密解码剩余瓶颈诊断](../../运行记录/模型实验/运行记录_稠密解码剩余瓶颈诊断_1015_162425.md)。固定既有64例回归子集，使用同图像、同提示、同有效区域；没有训练或读取test。

| 路径 | BF1@2 | macroDice | 解释 |
|---|---:|---:|---|
| J5 region | 0.378112 | 0.746599 | 原始提示模型 |
| dense matched96k | 0.610027 | 0.832119 | 当前保留基准 |
| native 最后轮 | 0.620449 | 0.833508 | 完整浅层分支 |
| full256 最后轮 | 0.615442 | 0.831993 | 多层完整分支 |
| semantic + 已知目标类别 | 0.640550 | 0.879368 | 使用query类别身份，只是闭集诊断 |
| semantic + 点击推断类别 | 0.513821 | 0.655269 | 无GT类别输入，简单闭集选类，47/64类别选对 |

- 64例数值不能与1024例BF1=0.557040直接比较。缓存semantic先64网格再插值，与旧诊断直接使用原始semantic logits路径不同，旧0.64873不能解释为本次模型退化。
- dense错误距GT边界≤2/4/8/16/32像素占24.60%/33.15%/44.22%/56.23%/68.19%。这支持检查较大区域的漏分/误分和目标语义；并非证明所有远边界错误都由提示引起。距离统计是像素加权，不是病例统计，也不是可修正比例上界。
- 用点处语义概率简单选择12类中的一个，类别正确率只有73.44%，整体分割退步。否定的是这条简单硬选类规则，不能由此量化现有prompt encoder的错误率。
- 原region错误中p<0.01或p>0.99的高置信错误只占1.79%；这类错误残留仅占dense总错误1.73%。因此“原logit极端饱和拖住所有修正”暂不作为主因。稠密残差没有硬幅度界，本来就能跨region分割；不能再次把它误称为64个区域系数的硬约束。

## 优先方向与可证伪实验

### A. 像素级提示交互与语义监督，优先级最高

现有Phase5先把正负提示各自汇聚成一个向量，再生成task token；dense使用task FiLM和两张点击热图。它没有直接对每个像素保留所有点击位置的图像内容。卷积接热图已有空间提示能力，不能说它完全看不到点击；待检验的是逐点内容及全局匹配能否补足现有表达。

候选结构：从缓存的深层/浅层特征在点击处采样视觉token，保留逐点正负符号；由稠密query对这些token做交互，同时保留region/cell上下文。旧task与region概率继续作输入参考。先增加一个零初始化的交互残差分支，从相同coarse状态出发，避免把随机新头与已训练32轮旧头直接比较。

第一轮仅改变提示交互，固定3k训练图、1024验证图、同更新预算/损失/点击；第二个独立消融加入训练期12类语义辅助监督或蒸馏。GT类别只用于构造训练目标，推理函数只接图像特征与提示。已有语义logits已是dense输入，因此“多拼一个语义特征”不算新的主方案。蒸馏只在train，不能将val已知类别直接喂给部署模型；教师有错误时仍以人工GT为主，不强迫复制全部教师预测。

预期机制是减少目标漏选、同形组织混淆和远端误分；这比继续添加同类浅层卷积更可能产生较大改进，属于基于证据的研究判断。风险是点特征被背景或混合组织污染，额外attention增加交互成本，以及12类监督造成闭集依赖。需单列提示有效性、不同提示位置和未知/留出类别能力。

### B. 连续纠错训练与任务多样性，优先级最高

现有3k缓存每张图固定一个目标/提示episode，训练多轮只换样本顺序；更新prompt_maps而不重算task/base会产生不一致。现有0923迭代模块是较早的独立小规模探索，没有与本轮最佳稠密结构完成大规模联合验证。

候选：训练中随机化同一已标注目标的有效内部正负点，接入上一轮mask；从当前训练预测的FP/FN中生成新增点击，学习纠错并保护原来正确区域。先做“固定 vs 每轮重采样”，再做“动态提示 vs 加上一轮mask”，保持模型/图像数量和实际前向预算可比，避免把额外三次前向当作同预算。保留无新增点、错误很小和目标缺失任务，规则来自train。新增task/base必须随提示更新，或显式定义只依赖缓存图像的新版提示路径。

报告两种协议：固定提示重放（静态质量）和各模型自身误差驱动的1/3/5次新增纠错曲线（交互效率）。两者不能混报，额外点击的收益不等于同点击预算的结构收益。报告NoC、未达阈值比例、误删原正确面积和可信提示违约。几何变换需同步GT/提示/region几何；简单旋转缓存特征不等价于重算旋转图像的编码特征，必须单独标注。

文献支持：RITM使用前轮mask和迭代训练；FocalClick关注纠错时保留正确区域；ScribblePrompt展示多样任务及模拟交互的重要性。它们不能提供本组织任务的保证增益。

### C. 有限联合训练，优先级中高

之前早期dense解冻layer4相对同预算head控制额外BF1约+0.005587，已有小幅正证据，但未在当前matched96k/新提示结构上验证。

推荐在A/B结果明确后，单独比较冻结encoder、解冻layer4、必要时layer3+4；Phase5后段适配单独消融，不能与图像解冻同时改动再归因。冻结BN统计，小学习率，记录真实梯度/权重差异与固定最后轮。

如果共享图像encoder更新，旧region/task/semantic缓存不能默认为仍与新encoder一致。明确二选一实验契约：完整重算受影响路径，或保留旧冻结region路径作teacher/先验、仅在线更新dense图像路径，后者是双路径模型而不是全链路端到端。新权重需要新cache版本，并测首张切片准备时间及点击时延。

收益更可能是稳步改善，不把旧+0.0056外推成大幅提升。冻结特征的多层融合负结果不能证明可训练的完整UNet/FPN也无效。

### D. 独立交互范式与更强特征，较高潜力、成本也高

| 候选 | 与本任务相关的机制 | 当前建议 |
|---|---|---|
| SegNext / InterFormer | 密集提示融合；图像计算与点击更新分开 | 首选独立交互对照，保留可缓存设计；先核验代码/权重和本任务适配 |
| Inter2Former（ICCV2025） | 利用前轮mask对边界与非边界分配不同计算 | 值得做现成权重诊断；官方仓库目前称训练代码后续发布，不能承诺立即完整训练复现 |
| SimpleClick | 点击进入强ViT骨干 | 质量对照；每次点击的图像计算成本需另算 |
| MultiverSeg（ICCV2025） | 已标注图像-mask作为上下文，降低后续图像交互量 | 更贴近“一处标注、迁移到其他图块”；support/query空间分离，人工确认mask才加入上下文，不把自动预测当真值回灌 |
| SAM3 | 文本/图像样例定义概念，再分割匹配实例 | 作为概念/样例对照，不预设优于组织语义分割；点提示、样例、文本三种预算分开。官方环境与当前aligner不同，需隔离环境及权重访问 |
| 病理预训练编码器 + 密集头 | 改善组织表示，配合像素提示匹配 | 使用空间token，不能拿单个patch全局向量直接做边界；先固定同一decoder比较特征，再验证有限适配 |

SAM-Path说明病理语义适配值得研究，但它使用训练类别提示、任务与任意交互不同；WSI-SAM报告的是乳腺相关任务，不可直接迁移论文涨幅。原项目已有SAM系列对照记录，后续应先匹配其任务/提示/权重设置，避免重复零样本比较。

### E. 数据、真实分辨率和标签，按误差分布推进

- 扩量已有12k×8 vs3k×32同96k更新几乎持平；不能再将随机扩图块视为已经证明有效的大幅提升路线，也不能断言全量训练无效。
- 先增加“有效任务多样性”：同图不同提示/目标、跨patch支持、目标缺失、train内易混组织及困难边界覆盖。明确独立图块数、任务数和更新步数是不同量。
- 训练内难例重采样保持普通图块覆盖，混淆类别和阈值由train决定。外部val误差用于提出机制假设，不逐例加入train。
- 真正20x同物理视野、低倍上下文与高倍局部联合仍未验证；但当前56%的错误离边界超过8像素，单独提高细节分辨率不是首选。先核查WSI原生MPP、标注精度和坐标，不用插值假装新增图像信息。
- 对存疑组织交界做小规模标注复核，未发现确证前不宣称标签噪声已是性能上限。当前BF1@2是像素容差；不能在MPP未核实前解释成固定物理距离。

## 下一轮最小实验顺序

1. A0：保留dense基准；A1：逐点视觉token→稠密交互，其他因素相同；真实4 train/2 val smoke验证GT独立、提示重算、checkpoint及像素对齐后，进入3k/1024的匹配预算pilot。
2. A1有效后，分别加入训练期语义辅助监督和B动态纠错；如果A1无增益，先做SegNext/InterFormer同提示基线，避免连续堆叠尚无效模块。
3. 在较强路径上做C有限解冻；之后才扩12k/全量，并重新做匹配更新预算对照。
4. 通过BF1+0.01、macro/micro Dice下降不超过0.002、可信提示违约不增的初筛后复验第二种子。大幅提升目标BF1+0.05（0.607040），还需类别分层、空间块区间与交互曲线支持。若只多点交互进步，就报告交互收益，不冒充固定提示性能提升。

全程保留region/cell语义及离线缓存的产品目标，静态图块与WSI拼接问题分开评估。开发val已反复使用且存在历史encoder暴露；进入正式效果主张前，审计未暴露空间块或采用同空间split重训对照，用户允许同病例跨split的规则不变。尚无新长训练耗时承诺，须先用真实smoke测吞吐和显存。
