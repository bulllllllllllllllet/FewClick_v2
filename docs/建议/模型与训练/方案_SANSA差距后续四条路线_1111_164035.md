# SANSA差距：B/C之后的四条路线

状态planned，用户要求分析，不新增训练。B/C继续原已授权流水线，当前无最终结果。依据当前goal/registry/run、A完整负结果、128train诊断及代码，结合以下原文：
- SANSA https://arxiv.org/html/2505.21795v2 ：adapter保留SAM2原生分割能力；§4.4小容量适配/层位置消融。附录F也探索语义负提示，因此不能把负点能力本身声称独有。
- HDMNet https://arxiv.org/abs/2303.14652 ：层级dense correlation，不等于当前单层37token attention；原完整mask监督设定不能直接照搬到少点协议。
- Self-Support https://arxiv.org/abs/2207.11549 ：由高置信query预测形成query自身原型；直接启发自适应外观，不能保证病理提升。

## 目前证据

9500同队列：原Few大目标73.8085、SANSA77.2201（差3.4116pp）；整体39.1935/41.5429；FPA6.7115/14.7866。A大目标73.4130/整体38.8760/FPA9.0527，不晋升。目标是同协议提高Dice并保留误报优势，不能把低FPA等同Dice胜出，亦不以只报有利类别/大小制造反超。

当前Phikon接口image_interface.py取最后层1024个token=32x32，双线性插值64x64，再固定复制通道进入既有头；增加输出分辨率不是增加原生空间采样。它是潜在限制，不是Dice上界，也不证明所有错分都源自分辨率。当前B只有一层64D四头注意力，支持4x4区域descriptor+原点；C用128网格浅层RGB/匹配上下文修正，不等于完整预训练SAM2解码器。

旧最后block23联合训练在旧共享decoder协议：remote macro36.5425→36.5038，未通过；不能再把解冻最后层当未试的新方案。旧SAM2 encoder-only替换未晋升，不能据此否定保留SAM2原生decoder的完整系统。两类旧实验不同任务/架构，不能和新9500直接比较分数。

128train诊断只有30remote_present、39remote_absent；旁路匹配Dice0说明当前协同训练路径依赖，不证明region机制完全无用。小支持23例assignment目标占比10.33%是空间纯度，不是token语义含量。GT支持池化仍差不能证明准确支持mask没价值，冻结模型输入分布变化未受训练。历史脚本82/128评分不精确一致，但本次额外复算可评Dice差绝对均值1.4538e-5、最大2.3777e-4（即0.00145/0.02378pp）；原因尚未严格隔离，当前所有比较为同上下文full/cached精确对照。

## D：直接训练匹配特征的组织区分（优先，轻量）

目的：正常间质/腺体、浆膜/肌肉的错误若是语义混淆，单加decoder容量未必有效。先保持Phikon冻结，仅对当前64维匹配投影增加train-only像素配对约束：相同目标的support/query拉近，相似非目标像素拉远。用现有二值episode标签定义正负，不把所有背景类别强行拉成一个类；困难负像素从同9500训练样本中按当前预测误报选取，不增加或改变任务/点击配额，不使用验证GT选负例。

首个对照原Few+单一匹配约束，不叠加A/B/C；先固定小训练probe看正负分离与跨patch对应，再完整同预算训练。损失变化要披露，参数/监督资源/更新量分别记账。若projection仍不足，再单独登记低容量adapter，不能同时换loss和encoder、也不直接全解冻。stop：只改善train类别区分，完整Dice未涨/FPA恶化，或支持交换后仍按固定类预测。

## E：支持锚定的query自适应（优先，面向漏覆盖）

先从support得到初始query概率，再从query自己的高可信预测区域收集外观原型，与原support正负证据共同进行一次修正。输出仍为同一模型，不额外query点击、不读query GT。目的为补足支持样本没覆盖的同类纹理，重点脂肪漏覆盖及大组织内部遗漏。

必须保留support锚定、负证据和低可信时零修正；不能把query初始错分当新真值无限循环放大。可靠度规则/阈值只能train设定且首轮固定一次迭代；逐query独立，不跨评估patch累计伪标签，以免混入额外transductive协议。训练与推理使用相同迭代路径；不是临时改测试阈值。stop：召回增长仅来自无差别扩大预测，absent FPA/脂肪背景误报升高。文献提供机制可行性，不提供本项目保证。

## F：保留SAM2原生mask decoder的FewClick系统（较大改动）

若B/C无整体收益，继续从头补小像素头的投资回报可能低。候选保留SAM2高分辨率特征与原生mask decoder，将FewClick的组织上下文、正负匹配证据以自动dense prompt或记忆输入送入原生头。优先单共享backbone、一套模型流程，避免必须长期跑Phikon+SAM2两个大encoder；若改为双encoder，明确计算成本和输入先验。

区别于历史encoder-only替换：原生解码预训练也保留，且远端提示完全由支持信息与query图像自动产生。不能从query GT取点/框/挑mask。它是新的FewClick衍生架构，不冒充旧论文结构；同SAM2公共权重/同9500适配/同支持点与SANSA做系统对照。若用SANSA Universal初始化则应命名SANSA-based extension，不能隐藏基线权重来源。提升独立性须来自有效组织上下文、signed retrieval/absence机制及WSI效率消融，而不是复现SANSA后换名。

本路线可能更直接利用强分割先验，是工程判断，不保证超过SANSA。先做少量真实adapter/decoder接口门控；不引入已冻结WSI-SAM额外训练。

## G：真实细节恢复与多层特征（有条件）

若匹配位置基本正确但query细节不足，先提取同一次Phikon forward的中间层，构建多层解码特征；中间层仍32x32，不能称提高原生空间分辨率。若须提高采样，则同一512视野分为2x2子块分别放大编码后拼接，保持物理footprint相同但fine编码次数增加4倍，消融resize/重叠/拼接/位置编码影响。先只改变fine视野，2x/4x context不动。与现有C的128浅层RGB分支分别比较，避免重复历史无收益像素头。

即使离线缓存可缓解点击开销，准备时间、存储与WSI吞吐也增加，必须实测；不作为语义混淆的默认解法。

## 决策与公平性

先等待已启动B/C。B改善则围绕matching继续精简并考虑D/E；B无效且C仅修轮廓则优先D或F，停止堆同类小头；C整体质量改善才考虑G是否有增量。新路线每次一个主假设，功能门控与全11000评价均不能省略，不无界扫loss/阈值/seed。

已有500 absent保留；不会擅自改成更多负任务。额外presence head可研究，但主要改善FPA，不能单靠它声称目标存在Dice超越。细胞/词表已有负结果，无新证据暂后置。

任何路线都只是假设。逐类看正常间质/脂肪/浆膜及腺体上皮，同时完整11类与小目标/FPA/BF1保留。已多次暴露空间开发集，单seed小涨点不足论文优势；用户不要求再加seed，当前不自动追加，保留统计局限。文献的自然图像mIoU不能换算成病理Dice预期增益。
