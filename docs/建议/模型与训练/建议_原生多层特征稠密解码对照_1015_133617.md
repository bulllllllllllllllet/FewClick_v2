# 原生多层特征稠密解码对照

- 用户授权实现下一阶段第一优先项，依据下一阶段建议133520、正式目标调整125213、同预算控制221710及当前模型/缓存代码。本轮冻结encoder，不同时混入有限解冻、20x或新数据。
- 固定：原3000train/1024val refs、RGB/提示/GT、seed20261014、空间split；初始化matched96k epoch31（BF1=0.557040），损失balanced BCE+整图Dice+0.5 GT边界带BCE；不替换默认J5。
- 采用可继承现有权重的多尺度残差解码：所有臂的coarse头加载同一已训练状态，均以lr1e-5继续更新；新增层lr1e-4，零初始化输出使初始预测精确复现当前coarse。encoder/BN始终冻结，更新encoder的实验后续再做。
- 四臂各8轮/24k更新：control仅原稠密头；native加入未经固定平均的layer1原生特征可学习投影；middle在native基础上融入layer2中层；full256在middle基础上接stem256px特征逐级融合、增加256px残差。共同部分初始化一致，不把24k额外训练本身误当结构贡献。
- 分支：当前任务条件fusion48通道作语义上下文，原生layer1 256→32投影；中层layer2 512→32在较粗尺度融合，再恢复128；stem64→16与128上采样特征融合，在256上预测修正。所有预测最终恢复512后在logit上相加。此次不额外加入深监督loss，保持四组目标一致；深监督可后续单独对照。
- 实际backbone尺度先由真实smoke测量，预期stem64×256²、layer1 256×128²、layer2 512×64²、deep256×64²，不能假定普通ResNet32倍下采样。缓存保留原完整通道并FP16存储，原coarse缓存字段直接复用，不重算改写原特征。
- 缓存为独立版本，原4k图块约新增80–110GB，当前NFS余量11TB，主机可用内存约423GiB；最终以实测字节/耗时为准。原RGB仅用于冻结encoder提取，新的训练cache不重复保存RGB。每ROI encoder只离线执行，点击解码独立；smoke测解码时延、训练显存及cache容量。
- 预期：更完整的预训练语义/细节特征改善轮廓；是待验证假设，不保证BF1幅度。风险：IO/缓存增长、细胞纹理干扰、有限数据过拟合、实际反向FLOPs不同。按相同更新量比较并披露时间/参数/显存，不称严格同算力。
- 验证：相关单测；真实4train/2val缓存→四臂1轮训练→严格重载→自动配对报告。检查原deep/shallow与重算特征一致性、GT独立推理、四臂零残差初始化、cache/split身份、梯度有限非零。
- 正式门槛：固定1024val/107空间块，相对coarse BF1≥+0.01、macro/micro Dice≥coarse−0.002、可信提示违约不增；同时看相邻臂固定最后轮比较和既有global点头最后轮。保留最佳轮诊断、逐类、固定64回归；历史encoder暴露/开发val限制保留。
