# 超越 SAM 的可验证路线与失败实验复盘

日期：2026-10-29。状态：研究与只读复算完成；候选均为 planned，未启动新训练、未替换原模型。用户问题：是否存在有希望超过当前 SAM-FT 的 FewClick 改进方案？

## 判断

有值得验证的路线，但现在没有“已能超过 SAM”的候选。若允许新架构，我优先推荐以成熟提示分割预训练为底座，增加 FewClick 的组织上下文/支持记忆，再检验细胞信息的独立收益；若要求原论文架构不变，优先验证训练目标与全链路适配，不能承诺补齐约13个百分点。主15张WSI继续用原冻结模型闭环，不等待候选试验，也不把WSI任务改变当成局部反超。

本建议结合当前源码、全部近期诊断、历史逐点交互负结果及一手文献。文献上的提高不等于当前CRC/TIGER同协议提高；下面的优先级是研究判断，不是成功概率估计。

## 1. 事实决定改什么

- 已接受三seed：SAM-FT Dice70.2063%，FewClick-XCell57.2902%。首seed302对×5点组：SAM70.1859%，FewClick57.2893%；120个<5%目标51.2122%/29.0867%。小目标贡献约68.17%的算术总差距，并非68.17%的因果解释。
- 新算术复核：只将小目标替换为SAM同层分数，其余保持FewClick现值，总体仅66.0809%。若只改小目标，其均值须达到61.5432%才能与SAM总体持平。这是敏感性计算，不是已实现结果或性能上界。
- 原始Dense已包含256×64²深特征、32×128²浅特征、点击热图和task条件化；原区域路径已有逐点有符号attention。不能把“加Dense”“支持正负点击”或“突破64个硬区域”当作新方案。
- 近期固定困难负区域惩罚无效；完整4733任务Dense-only单遍继续训练/轻RGB增强也无效。它们不排除全链路训练的收益，但不支持继续盲扫这些小头方案。
- 本次复算最新正式结果的同类窄面积14对：原始训练/验证Dice53.5430/15.8844%，继续原loss51.6498/12.7637%，颜色增强50.3610/11.8319%。训练样本也下降，不能把这次恶化单独归因于训练越来越好而验证越来越差。已有泛化差距仍在；样本是极端面积配对，不代表全训练集。
- 旧J5缓存上的逐点视觉交互已经失败：1015实验per_click Dice80.0589%，控制80.1317%，原基准80.3416%；BF1也无增益。旧任务/预训练与现协议不同，分数不可直接并表；但足以降低“冻结旧特征再加相同残差attention”的优先级。

证据复算：`benchmarks/v5/fair_comparison/research_sam_routes.py`，aligner CPU worker及源码/输入SHA见工件。重新校验993行TP/FP/FN的Dice、三臂身份/GT计数、302全体/120小目标/61大目标与原独立接受一致，再按原29配对连接最新训练/验证结果。未重新推理或重新独立读取993个mask；沿用原独立mask接受。

## 2. 保留原架构：先检验损失与全链路训练

源码 `multidomain_training/losses.py` 的BCE将正、负两类各赋一半总权重：

`L_BCE = 0.5 mean_positive(softplus(-z)) + 0.5 mean_negative(softplus(z))`。

当目标面积f=0.1%时，单个正像素的系数约为负像素的999倍；f=5%时约19倍。这是设计上的类别平衡，**不是代码错误**。另有Dice、边界和点损失，因此不能直接推导最终概率校准或宣布它是唯一根因。SAM也用相同mask损失并表现更好，证明其不足以独立解释模型差距。它与小目标召回高、精度低、继续训练扩大预测的现象一致，值得有限单因素验证。

最小候选A：保留全部架构/输入和原权重，针对主mask BCE做一个事先固定的温和混合：`0.5 原balanced BCE + 0.5 全valid像素BCE`，Dice/边界/点击项不变。这是待验证配方，0.5不是从验证集选出的最优值；不做多系数网格搜索，不改变推理阈值。

第一轮先在训练区内部留出的空间块做两臂：继续原loss、混合loss；使用原正式联合训练可训练层（encoder layer3/4、region/prompt/graph/cell/Dense等），两臂完全相同。区别于刚失败的Dense-only试验：这里允许上游一起适配，不能缓存旧task/base冒充联合训练。两臂同初始权重、原实际40k任务序列的同一固定前缀、点、更新数、优化器与最后一次评价。建议pilot每臂1000更新×4任务，早期只检查数值/梯度，不根据开发分数多次换配方；正式预算必须在真实吞吐门控后固定。

内部分块仅用于未来候选筛选；原G3模型已见这些训练块，须明确它们不是从未暴露的盲测。若要得到独立最终结论，需要完整输入footprint未训练/未调参的空间块，或从干净初始化按新隔离清单重训；保持用户允许同病例跨split的规则。

若两臂都提高而差异不明显，归因于联合训练/预算，不归因于混合loss。若候选仅压低召回、整体Dice/BF1仍不升，就停止这一配方。无需继续改阈值美化小目标precision。若有效才扩原协议/三seed，并给SAM与WSI-SAM同等目标数据、调参机会和新增预算，另表披露额外训练。

预期收益：改善误检与训练目标适配，成本相对低；风险：小组织漏检增加、旧能力遗忘。当前证据不足以期待它独立补齐13点。该路线不更改网络结构，但仍是新训练配方，必须如实记录。

## 3. 允许新版本：成熟交互底座 + FewClick 上下文

我更看好的局部反超研究路线是**从已有SAM提示分割能力出发，检验FewClick额外信息能否带来净收益**。保留SAM图像编码器、原提示编码器和原生mask decoder，增加可学习的组织/细胞上下文分支；初始分支输出为零，初始预测应逐值复现相同SAM基线。

可测试的结构：fine图像仍走SAM；FewClick的2x/4x组织token经小投影与可学习门控进入mask decoder；细胞token随后独立接入。上下文是图像内容，不能伪装成人工点击或额外类别标签。切片准备时缓存图像/区域/细胞，点击时仅更新提示与轻量交互；实际准备成本、缓存占用和点击延迟都要测。不能因细胞不在在线路径就忽略其离线代价。

最小分阶段对照：

| 阶段 | 对照 | 候选 | 问题 |
|---|---|---|---|
| B1 | 同起点、同追加训练的SAM | SAM+多尺度组织上下文 | 上下文能否补充SAM？ |
| B2，仅B1有效后 | B1且无细胞 | B1+XCell；随后形态/计数控制 | 细胞是否提供独立有效信息？ |
| B3 | 最佳已固定候选 | 单独加入支持记忆训练 | 远端迁移是否改善？ |

若从当前SAM-FT权重继续，则所有臂继承同一目标暴露、共同追加同一训练预算；不能拿“多训练的候选”只比较原70.19%的旧模型。若从公共权重开始，则每臂同40k实际任务/选模规则。已有FewClick训练过的上下文模块也属于额外目标暴露，必须披露并做通用初始化对照，不能暗中算作同总监督。

支持此方向的机制先例：[HQ-SAM](https://arxiv.org/abs/2306.01567)保留SAM预训练并新增高质量输出token/多层特征融合；[WSI-SAM](https://arxiv.org/abs/2403.09257)增加多分辨率信息。这些工作只证明路线有先例；我们的已适配WSI-SAM与SAM接近，并不证明多尺度一定有效。[SegNext](https://arxiv.org/abs/2404.00741)强调密集提示融合，官方[代码/权重与训练入口](https://github.com/uncbiag/SegNext)可作成熟交互方案参考或独立对照。

这条路线改变架构和预训练依赖。应单列为FewClick新版本/扩展方法；若获益依赖SAM，结论是“FewClick上下文增强SAM”，不是“原FewClick独立超越SAM”。是否能进入当前投稿正文须结合真实提交版本和会务规则另查，不能称架构笔误或本次已经获准改稿。

风险：SAM已经忽略或不需要这些额外信号；新分支破坏原能力；预训练与新增视野/计算带来混杂；创新性需用明确的组织支持记忆/细胞作用证据与现有WSI-SAM区分。零初始化只保证初始不变，不保证训练后不退化。

## 4. 独立FewClick的中期路线与WSI路线

若不使用SAM模块，中期选项是病理预训练的空间特征+真正联合训练的提示像素decoder。保留区域/细胞支路，在稠密像素与逐点视觉内容之间建立匹配，并共同更新提示/图路径或编码器；这与旧冻结J5加小残差有实质区别。先固定decoder比较一种已核验的病理初始化，避免同时换backbone、loss和提示策略。UNI等病理基础模型是候选，需核验空间token接口、尺度和预训练来源，不能把单个全局向量插值当高分辨率特征。[UNI官方资料](https://github.com/mahmoodlab/UNI)。

[SAM-Path](https://arxiv.org/abs/2307.09570)提示病理特征可帮助分割，但使用可训练类别提示和闭集语义任务，不能照搬其得分到任意用户点提示；当前目标仍是用户指定组织，不退化成推理时输入GT类别ID的分类头。

WSI方面，当前干净G3仅local训练；G4是local适配后的support→query泛化。需要单独训练同片隔离支持/查询episode、查询无目标的负episode和多形态支持任务，在推理时查询热图为零。当前FewClick远端present Dice30.15%，SAM特征prototype桥35.33%；缺失目标FPA14.13%/33.64%，说明存在质量/误报权衡，**不是已证明整体胜出**。

较合理的跨图机制是从用户支持区得到多个有符号组织原型，学习查询区目标是否存在，再做像素匹配。选择支持或候选只能依赖用户点、支持图像/允许的支持注释和查询图像，不能用query GT排序。不能只保留含正点的连通域：组织任务可包含多个远处分离区域，裁掉它们会改变任务。

文献动机：[MultiverSeg](https://arxiv.org/abs/2412.15058)通过已标注图像上下文减少后续交互；我们已有其适配桥对照，不能忽略已有负结果或把预测支持mask称作人工真值。新增remote训练需同时提供给合理SAM桥与其他可训练基线；局部表与支持查询表保持分离。主15现有固定数据继续闭环，未来新训练不得污染其查询区域。

动态纠错可作为后续单因素：训练从当前预测FP/FN生成下一点击、输入上一mask，参考[RITM](https://arxiv.org/abs/2102.06583)、[FocalClick](https://openaccess.thecvf.com/content/CVPR2022/html/Chen_FocalClick_Towards_Practical_Interactive_Image_Segmentation_CVPR_2022_paper.html)、[ScribblePrompt](https://arxiv.org/abs/2312.07381)。当前静态随机点覆盖不等于误差驱动纠错，但额外点/额外前向必须计费；固定点Dice与各模型自适应交互曲线分表，不能把更多交互的收益当同3+2胜出。

## 5. 通过标准与执行顺序

1. **主线不变**：先完成原15WSI的接受/质量/时延证据；本研究未核验当前细胞进度或修改后台。
2. **原架构短试验**：A两臂联合适配，先真实CRC/TIGER输入、loss、梯度、checkpoint、同点评价门控，再固定预算pilot；本记录未启动。
3. **新版本首选**：B1只有SAM控制和上下文候选两臂，B1有效才做B2；不同时堆全部模块。吞吐与开发时长须真实门控估计，不由刚完成的47分钟Dense-only推算全链路时间。
4. 筛选阈值在训练前冻结：例如总体Dice提升至少1个百分点、小目标Dice/precision与BF1方向一致、召回和大目标Dice下降不超过1个百分点，作为资源投入门槛而非显著性结论；此门槛是新提议，不是原协议规定。
5. 最终“超过”要求：原固定类/样本/提示/阈值/指标下，与同预算充分适配SAM配对比较；多seed与来源空间块不确定性分开报告；所有失败与完整类别保留。反复看过的开发集只能说明开发改善，还需未参与拟合/选择的空间区域或真正外部确认。
6. 推理禁止query GT、GT类别ID、oracle mask选择和按验证分数调阈值；脂肪继续正常监督，不删难目标、不撤SAM-FT。XCell内部数据预训练单独记账，retained-J5禁止冒充同总目标监督。

研究产物：`/nfs-medical3/zyh/fewclick_v2/fair_comparison/sam_routes_research_1029_224158/evidence.json`。本建议以机制和预算止损安排实验，不将“必须胜过”作为筛选/删除结果的理由。
