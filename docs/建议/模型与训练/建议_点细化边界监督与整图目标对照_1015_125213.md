# 点细化边界监督与整图目标对照

- 问题：恢复边界监督、把点Dice换回整图Dice，能否减少点细化的净错误翻转？用户已授权调整，依据诊断122728及优先级建议123014。
- 固定：原PointBoundaryDetail结构/coarse checkpoint/3k train与1024 val/RGB缓存/seed20261014/顺序/8轮/AdamW1e-4/4096 uncertain训练点/65536推理点。默认模型不替换，v4不改。
- 三臂逐项对照：control=原采样点balanced BCE+点Dice；boundary=control+0.5整幅推理合成mask的GT边界带BCE；global=boundary中仅把点Dice换成整图Dice。boundary vs control隔离边界项，global vs boundary隔离Dice范围。
- 实现：每次一次性预测旧4096训练点与GT独立的65536推理选点；前4096用于原采样loss，后65536合成与实际推理一致的全图mask用于辅助监督。带外保持coarse原概率。所有臂均计算同一批69632点，计算量增加须披露；不同loss反向开销仍可能不同。不能把相对旧4096点实验的变化全部归因于目标。control重跑提供同前向点数、同更新量的参照。
- 使用完整推理选区计算新loss，避免仅把4096点散回整图造成边界/Dice梯度极度稀释。没有改原训练点采样策略，BCE仍保持原4096点的正负平衡；完整采样策略匹配仍是后续独立问题。
- 预期：目标更接近实际输出与边界指标；风险：65536点的激活/反向增加开销，冻结coarse的带外错误不可修改，整图Dice梯度可能不足，loss变化未必有效。
- 替代：训练采样策略匹配、coarse保持约束、完整预训练多尺度FPN；本轮不混入。
- 验证：合成loss验证GT边界/ignore/梯度作用域；4train/2val/1轮三臂真实smoke，保存严格重载、GT独立推理、带外精确不变、梯度与loss有限；通过后正式3k/1024×8轮三臂。
- 门槛：相对当前coarse BF1@2≥+0.01，macro/micro Dice≥coarse−0.002，可信提示违约不增加；同1024val/107空间块，逐类、固定最后轮与诊断最佳轮均记录，两项相邻臂配对报告。开发val已选模且历史encoder暴露，最终仍需真实交互和未暴露区域验收。
