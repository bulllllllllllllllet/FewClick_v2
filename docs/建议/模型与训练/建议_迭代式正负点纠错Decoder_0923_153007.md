# 迭代式正负点纠错 Decoder 设计建议

时间：2026-09-23 15:30:07。状态：设计建议，尚未实现或验证。

## 问题与目标

用户在已有预测上补负点，期望该点所指的误检被删除、全图相似误检一起减少，同时原来正确的正区域尽量保留；补正点则期望点击处漏检被补上、全图相似漏检一起恢复，同时原来正确的负区域尽量保持排除。当前模型把完整正负提示集合重新编码成当前任务，再预测一次 mask；它没有显式的上一轮状态和定向纠错目标。因此概率变化不能保证点击处按符号修正，也不能保证全图相似错误同步修正。

本建议面向**同一目标、同一张 WSI、连续点击**。新增负点表示当前目标的排除证据；新增正点表示当前目标的补充证据。两者都应基于上一轮结果定向纠错。撤销、重做和目标切换也需有明确状态语义。

## 查阅依据与现状

- `benchmarks/v4/phase_5_prompt_encoder/src/model.py`：`PromptSetPool`把每组提示压为一个 `q_positive/q_negative`；`match_regions`只对这两个向量做 region attention，输出初始 region logits。原始逐点身份在此丢失。
- `benchmarks/v4/phase_6_mask_decoder/src/model.py`：KNN 几何邻接、两层局部图 attention、受限 `raw_delta`、对全部 active region 的均值中心化，然后 `logits=prompt["logits"]+delta`。输入 logits 是**本轮 Phase 5**输出，未接收上一轮预测。像素概率由 soft assignment 加权 region sigmoid 得到。
- `benchmarks/v4/phase_6_mask_decoder/src/joint_model.py` 与 `src/joint_losses.py`：已有在线 prompt 重映射、正负 slot 冲突检测和 `signed_prompt_loss`，但没有逐轮状态、正负点前后定向单调约束或像素点击位置的硬保证。
- `docs/建议/模型与训练/方案_可扩展原型与组学监督_0920_210632.md`：允许继续纠正与模拟点击；“不做全图预测回灌”针对伪标签/原型自训练。本方案只把上一轮预测作为**本次解码状态**，不把其当真值构造原型或训练标签；这一边界须在实验中保留。

## 推荐结构：带纠错记忆的 Phase 5/6 分支

离线 Phase 2/3（可选 Phase 4）缓存保持既有路径。新结构放在 `benchmarks/v5/`，v4 checkpoint 和接口保持只读基线。先做同 patch/区域缓存的逐轮模型，再接整张 WSI 的跨 patch 状态传递。

### 1. 逐点提示仍可汇总，但不能只留下汇总

Phase 5 输出 `prompt_tokens [B,P,D]`、正负符号、坐标、有效位、点击顺序及 `task_token [B,D]`。逐点 token 经 set self-attention 编码后保留；原有正负 pooled 向量继续用于全局任务语义和旧权重初始化。每个候选 region 对全部有效 prompt token 做带符号的 cross-attention，并计算单点相似度 `[B,N,P]`。注意力需按符号隔离或加入明确 sign bias，避免任何一侧已有提示淹没新点击。不得用单点最大相似度无条件扩张或删除全图同形组织。

记录新增点击 `new_prompt_index`、`new_prompt_sign` 与点击前已有集合。正负点都以**实际像素坐标**映射到 soft assignment；同时保留当前在线 slot ID、点击处 assignment 权重和冲突标志。已有 centroid prompt 只有近似映射，不能当作点击处像素保证的验证证据。

### 2. 上一轮状态与两条更新支路

第 0 轮沿用冻结基线输出 `L_0`（region logits）和 `M_0`（pixel probability）。第 t 轮输入上一轮 `L_{t-1}`、可选低分辨率 `M_{t-1}`、新点击和完整提示历史；上一轮状态 `detach` 后输入当前轮，初版只训练单步纠错，后续再测试多步展开。全图状态应带 slide/cache/geometry 版本和目标 ID；任一版本变化时必须重新建立状态，不能错误复用另一张图或另一目标的 logits。

将更新分成：

1. **相似误检抑制支路**：以新增负点 token 和其局部区域特征为 query，在视觉 region token 上做归一化相似度匹配；结合 `sigmoid(L_{t-1})`、空间上下文及正点相似度预测每个 region 的非负抑制量 `s_i^-`。前一轮高概率作软门控，使其主要处理已有误检；已确认正点和不确定的异质组织抑制要小。
2. **相似漏检扩张支路**：以新增正点 token 和其局部区域特征为 query，同样在全图视觉 region token 上匹配；结合 `1-sigmoid(L_{t-1})`、负点相似度与上下文预测非负增益 `s_i^+`。前一轮低概率作软门控，使其主要补充已有漏检；已确认负点和视觉相似但实际上是背景的区域不能随之扩张。两支路均按有效点击数归一化；跨 patch 匹配只读离线缓存，不通过局部 KNN 跨 patch 传消息。
3. **局部边界修复支路**：保留现有 KNN graph block，输入当前特征、`L_{t-1}`、本轮 Phase 5 logits、逐点交互特征和双侧匹配证据，输出有界 `d_i`。图分支负责边界/邻域细化，但不是点击符号的最终裁决者。

候选输出为 `L*_t = L_{t-1} + d_i + s_i^+ - s_i^-`（也可学习门控融合本轮 Phase 5 logits）。由新增点击符号激活对应支路，但完整提示历史始终参与冲突判别和保护门控。新增参数零初始化，保证接入时第 0 轮与原基线严格等价。训练和验收必须同时覆盖新增正点与新增负点。

### 3. 点击约束放在 KNN 与中心化之后

现有全 active region 均值中心化会把局部负增量变成其他 region 的正向位移，也会把局部正增量变成其他 region 的负向位移，可能抵消新增点击。新纠错分支不沿用这一步；如需控制全局偏移，改用远离提示且低置信的背景 region 统计，并做消融。所有图更新、门控和归一化完成后才施加点击约束，避免 KNN 下一步重新抬高负点或压低正点。

对新增负点像素 `x-` 施加 `M_t(x-) <= min(M_{t-1}(x-)-epsilon, tau_neg)`；对新增正点像素 `x+` 施加 `M_t(x+) >= max(M_{t-1}(x+)+epsilon, tau_pos)`，两侧目标都裁到 `[0,1]`。单调幅度仅在新增点击确为前一轮误检/漏检时启用；已满足阈值的点击只要求保持符号正确。`tau_pos/tau_neg/epsilon`从验证集选定。先对覆盖点击像素的 region logits 做最小幅度可微投影/迭代校正，再重新计算 soft assignment 像素概率并验收；不能只 clamp 最近 centroid slot。若两个不同像素共用不可分的 soft region，应加局部像素残差层保障两处点击，记录 region 层冲突与最终像素冲突各自的数量；同一像素收到相反符号则返回可诊断冲突状态，不伪称同时满足。

硬约束只保证点击像素，不能保证整块错误区域及远端相似区域都被纠正；这些依赖双侧匹配支路及训练目标。点击附近的连通错误区域可施加软监督，但边界仍由图像证据决定，避免单点抹掉正确组织或填满背景。

### 4. 双侧已正确区域保持与数值稳定

对所有已有正点施加 `M_t(x+) >= tau_pos`，对所有已有负点施加 `M_t(x-) <= tau_neg`。新增负点时保护上一轮正确正区域；新增正点时保护上一轮正确负区域。训练时用 GT 判别哪些旧预测确实正确，分别加非下降/非上升一致性损失；推理时仅用已有点击与高置信稳定区域作保守门控，不能读取 GT。允许纠错引起必要的边界变化，不要求全图逐像素单调不变。记录每轮双侧 click consistency、增益/抑制量、正确区域变化和全图概率质量；检查 BF16 下投影有限且不会因极端 logit 溢出。

## 训练任务与损失

从训练 split 的已标注图像构造顺序 episode：先给初始提示得到 `M_{t-1}`，再分别在最大**假阳性连通区域**选新增负点、最大**假阴性连通区域**选新增正点，交替或按错误面积选点，预测 `M_t`。两侧都要补充随机困难点、远端同类错误，以及视觉相似但 GT 符号相反的 hard counterexample；也要覆盖没有对应错误可点的退出情形。多轮 episode 必须使用模型自身上一轮预测，不能拿 GT mask 伪装成历史状态；GT 只用于训练目标与模拟选点。验证中的 oracle 点选择须明确标注，另做人类点击验收。

建议损失：

`L = L_seg + λ_click L_click + λ_mono(L_neg_mono+L_pos_mono) + λ_sim(L_remote_FP+L_remote_FN) + λ_keep(L_pos_keep+L_neg_keep) + λ_delta L_update`。

- `L_seg`：每轮有效像素 BCE/Dice 与既有边界损失。
- `L_click`：新增及已有负点最终像素概率超阈值、新增及已有正点低于阈值的惩罚；硬投影后的双侧违规率仍作为独立门禁。
- `L_neg_mono`：在新增负点覆盖的**真实假阳性**局部区域，惩罚 `relu(M_t-M_{t-1}+epsilon)`；不把负点相似度直接当 GT 扩成整张图。
- `L_pos_mono`：在新增正点覆盖的**真实假阴性**局部区域，惩罚 `relu(M_{t-1}-M_t+epsilon)`；不把正点相似度直接当 GT 扩成整张图。
- `L_remote_FP`：对远端真实假阳性且与点击错误区域相似的训练区域，要求概率下降；对视觉相似但 GT 为正的区域同时惩罚错误下降，以免一键抹掉全部同形组织。
- `L_remote_FN`：对远端真实假阴性且与点击漏检区域相似的训练区域，要求概率上升；对视觉相似但 GT 为负的区域同时惩罚错误上升，以免一键填满同形背景。
- `L_pos_keep`：已有正点及上一轮正确预测的 GT 正区域发生大幅下降时惩罚；前一轮假阳性不受此项保护。
- `L_neg_keep`：已有负点及上一轮正确预测的 GT 负区域发生大幅上升时惩罚；前一轮假阴性不受此项保护。
- `L_update`：约束无关区域不必要的变化，并限制逐轮更新幅度；只作为软正则，不能压过纠错损失。

分阶段训练：A. 固定 Phase 2/3、旧 Phase 5/6，训练逐点交互、正负双侧匹配和状态分支；B. 解冻新 Phase 6 图层及 Phase 5 后段，以较低学习率联合微调；C. 在质量门禁通过后再考虑有限视觉层适配。每阶段对照同样的训练 episode、点击规则和计算预算。v4 基线及无状态多点击重推理保留为配对对照。

## 验证协议与通过标准

固定空间组划分，先 split 再生成 episode；同一源区域的多轮序列不能跨 split。报告第 0/1/2/3 次纠错的逐轮指标，并按新增点击符号、初始 FP/FN 面积、远端相似错误数量、目标面积、prompt slot 冲突分层。

| 目标 | 必报指标 | 建议门禁 |
| --- | --- | --- |
| 点击处删除 | 新增负点像素 `M_t(x-)`、点击负点违规率、局部 FP Dice/面积 | 有效非冲突点的硬约束违规率为 0；冲突单列 |
| 点击处补全 | 新增正点像素 `M_t(x+)`、点击正点违规率、局部 FN Dice/面积 | 有效非冲突点的硬约束违规率为 0；冲突单列 |
| 同类误检同步排除 | 远端匹配 FP 的概率/面积下降、FP recall、相似真阳性误删率 | 远端 FP 明显优于基线，同时真阳性误删不显著增加 |
| 同类漏检同步补全 | 远端匹配 FN 的概率/面积上升、FN recall、相似真阴性误加率 | 远端 FN 明显优于基线，同时真阴性误加不显著增加 |
| 原正区域保持 | 旧正点违规率、GT 正区 Dice/recall 变化、全图 Dice | 旧正点硬约束违规率为 0；正区下降设验证集上限 |
| 原负区域保持 | 旧负点违规率、GT 负区 specificity/FP 面积变化、全图 Dice | 旧负点硬约束违规率为 0；负区误加设验证集上限 |
| 交互效率 | NoC@0.8/0.9、每次点击推理延迟、缓存内存 | 与 v4 多点击重推理在同一点击策略下配对比较 |

先做单图真实数据 smoke：提示映射、soft assignment 点击投影、冲突、有限梯度、状态版本校验，以及各一次正点/负点后的局部与远端变化。随后做固定验证集配对消融：逐点 token、上一轮状态、正负匹配支路、双侧单调损失、KNN 后约束逐项加入。只有看到双侧点击处通过、远端 FP/FN 改善且原有正负区域保持可接受，才进入 WSI 人工操作验证。阈值和两侧允许变化幅度须在正式验证前定稿；此处不虚构数值收益。

## 备选、收益与风险

最小备选是现有 Phase 5/6 每次把全部点重新推理，并在输出像素处按符号强制修正；实现快，但不会学习全图相似错误，也可能留下局部洞或孤立亮点。仅增加单调损失而不保留逐点 token/历史状态，难以辨别新增点击与旧点击；仅加上一轮 mask 而不做最终点击约束，仍可能被 KNN 或 soft projection 抵消。推荐结构把**点击确定性**和**相似区域泛化**分开处理。

主要风险：soft region 分辨率使相邻正负点不可分；远端视觉相似不等于同一错误类别；正点扩张与负点抑制互相抵消；错误的历史预测被当作特征后自我强化；逐点 attention 随点击数增长增加延迟；不同 patch/WSI 的 assignment 版本导致状态错配。通过冲突显式返回、GT 监督下的两侧相似反例、状态 detach 与版本校验、prompt 数量预算及固定验证消融控制。若分辨率冲突成为主瓶颈，应先改进像素局部残差头或 regionization，不能单靠 region logit 约束声称像素可分。

## 实现反馈（2026-09-23）

v5 实现位于 `benchmarks/v5/phase_6_mask_decoder/`。真实图块对照发现，默认在 soft region 层硬投影全部正负点会引起大量不可分冲突，并在新增负点后显著压低正确正区域。因此最终点击保证交由图更新后的局部像素残差；region 硬投影只保留作消融。自由符号的图 `delta` 同样会伤害已正确区域，改为图上下文调节**非负幅度**、由新增点击符号决定增减方向，并用对向提示的视觉相似度作证据门控。这些是实验后对初始候选式 `L*_t` 的修订，不能将早期公式视为最终实现。训练与评价仍为开发性空间组实验；旧 v4 初始化对部分新 val patch 有历史暴露。
