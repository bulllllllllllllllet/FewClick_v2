# 组织边界系统诊断与扩量路线

时间：2026-10-14；阶段：先核查历史训练与表达能力，再排序结构/数据方案。

- 问题：组织语义交界不准，是否能通过模型结构或扩大训练获得明显收益？当前证据不能保证具体提升幅度。
- 依据：v4 Phase2/Phase6 的真实 metadata、逐 epoch metrics、选模记录；10-14 像素细化失败对照；9-22 空间划分；冻结模型与数据加载代码。旧文档的患者独立划分条款由用户后来确认的空间划分策略取代。
- 先做诊断：在上轮固定 64 val episode 上重放 J5，计算固定 assignment 的真值辅助有界最小二乘拟合、真值降采样/上采样、局部可修正误差比例、距组织边界/图块边缘误差分布。所有真值辅助结果明确为 oracle 诊断，不是可部署模型，不用于训练或独立泛化结论。
- 理由：区分 64 区域基函数限制、8 倍下采样、区域判别错误和局部门控限制，避免仅凭模型形状判断因果。
- 候选：高分辨率 FPN/UNet 像素解码器接区域语义和提示；区域数/空间先验及 assignment 联训；固定结构下扩大独立空间图块覆盖与边界采样；多分辨率/SAM 系列作为独立对照。
- 预期：定位更有机会产生较大收益的因素；风险包括 GT 边界噪声、缓存几何漂移、历史初始化暴露、较小验证集、在线显存/时延增加。
- 诊断验收：冻结模型重放与既有预测一致；投影重建一致；最小二乘目标不劣于原预测；不修改模型权重；只读 val、不读 test 图像/标签；保存逐项结果和源码哈希。
- 最终训练方案及推进标准在诊断完成后补充，不把候选效果写成已证实结果。

## 历史训练事实与解释

完整审计表见本次产物 `historical_runs.json` / `historical_epochs.csv`，共108个Phase6运行目录、230条epoch记录；包含smoke、resume、消融，不能当成108次独立正式实验。以下编号是实验名称，J5/J10不能自动解释成5/10次点击。

| 阶段/目录尾缀 | 实际预算 | 更新模块 | 主要结果 |
|---|---|---|---|
| Phase2 `20260717_161240` | 20,000采样/轮×30轮，4,000 val | backbone及区域/语义头 | region oracle Dice约0.451→0.512；此处是多类硬区域多数票，不可与Phase6二分类Dice混比 |
| Phase6 joint `20260721_172701` | 20,000 episode/轮×30轮，4,000 val | decoder、embedding、assignment | BF1 0.24779→0.29179；epoch24选中Dice 0.74133 |
| J5 `20260722_142455` | 20,000×5轮，4,000 val | 仅ResNet layer4，初始lr=1e-6 | BF1 0.29746→0.31424，Dice 0.73763→0.74133 |
| J10 `20260722_154210` | 20,000×5轮，4,000 val | parent context | 最终BF1 0.31433，几乎无变化；该旧注入路径已退役 |
| 跨尺度 `20260725_124846` 等 | 每个20,000×5轮 | cross-scale | 最终BF1约0.3123，Dice约0.7379，未通过非劣/提升选模 |
| 9-23 iterative final | 256 train/64 val，3轮 | 新迭代decoder | 主要检验正负点纠错；未建立大规模边界提升结论 |
| 10-14 RGB refinement | 128 train episode、实际127独立patch；64 val，4轮 | 小RGB残差头 | BF1 0.37811→0.38343，增益不稳定，门禁未通过 |

原joint并非只做过小样本训练，30轮已约60万次episode呈现；J5是后续有限微调。原joint最后10轮BF1仅约+0.0011，但余弦学习率也衰减至0，因此不能由曲线断言“更多训练绝对无效”。其epoch时长合计约2.86小时（原6 GPU）；J5约1.09小时（原2 GPU），只是历史配置耗时，不能直接当新模型预算。

需要纠正的解释：7-26 `105600` 是去掉cell分支的消融，`150700` 是固定SLIC消融；它们的性能下降不能证明正常结构解冻decoder会失败。当前任务不需要重启细胞探索。

指标有三种口径：Phase2对全部区域边界做精确像素匹配、无容差；Phase6对目标二值mask计算BF1@2；10-14还排除ignore邻域并将单侧无边界计0。历史不同口径数值不能拼成一条提升曲线。

## 本次64例诊断

与10-14相同64个episode/64个patch、相同图像和提示、相同J5权重。最终可复现产物：`/nfs-medical3/zyh/fewclick_v2/boundary_refinement/audit_verified_1014_185010/`。

| 路径 | Macro Dice | BF1@2px | 含义 |
|---|---:|---:|---|
| 原J5 | 0.74660 | 0.37811 | 可运行的原交互路径 |
| 固定assignment，GT辅助拟合64个[0,1]区域系数 | 0.80502 | 0.41614 | 每个query直接使用GT做有界最小二乘；不是训练结果，也不是最大Dice/BF1上界 |
| 已有12类semantic head直接输出目标类 | 0.88041 | 0.64873 | 没有新训练，但用已知类别ID；不具备任意新概念/用户意图的提示能力，不能作为交互模型直接提升 |
| GT压到64×64再放大 | 0.96122 | 0.90748 | 真值诊断，说明仅8倍采样本身不能解释当前全部误差 |
| GT压到128×128再放大 | 0.98540 | 0.97666 | 细节分辨率还有改善空间；不是模型预测 |

当前像素输出是 `p(x)=sum_k A_k(x)*q_k`，512×512上只有64个区域概率系数可调。assignment来自64×64特征、插值至512；semantic head也来自低分辨率特征，但输出具有独立空间自由度。综合证据优先指向区域到像素的表示限制，以及提示条件判别损失；更高分辨率是第二个变量。固定assignment的最小二乘只优化MSE，不能声称0.416是理论最佳BF1；固定类别头的优势也混入已知类别身份，不能把全部差距归因于投影。

错误像素中，距GT边界≤2/4/8/16/32px的比例分别为29.0%/39.9%/52.6%/66.4%/77.6%。旧局部门控覆盖73.3%的错误，仍遗漏26.7%；即使在门内完美修正且保持±2 logit限制，真值辅助BF1可到0.7673，但这只表示门内仍有可修正空间，实际小头没有学到。不能归因于门控一个因素。

图块外缘16px错误率11.62%，内部10.34%，两者都存在错误。这次不是相邻图块接缝实验，不能据此排除整张WSI拼接问题；仍应另做邻接重叠一致性诊断。

## 优先路线：先释放像素输出，再强化细节

1. **提示条件稠密解码器，第一优先。** 保留region/cell/跨尺度语义和可缓存路径，增加独立像素输出。先从已有64×64 embedding/ASPP特征接task token、正负提示图、上一轮mask，输出目标二值mask；不把结果限制为64个区域常数的混合。以原semantic head作固定类别对照或训练期辅助监督，用户提示仍决定输出目标。先验证相同64×64分辨率下去掉投影限制能带来多少收益。
2. **高分辨率FPN/UNet式融合，第二步。** 在同一稠密解码器上接浅层128×128特征，必要时256×256，融合区域上下文后逐级恢复轮廓；再加PointRend式不确定点细化作为独立消融。形态学核边缘不等于组织交界，因此不能只输入RGB。先用10x已有GT验证，再测试同物理视野20x/1024输入；直接把10x图像插值到1024不会新增信息。
3. **区域表示改造，作为对照。** K=64→144/256、自适应区域细分、空间先验温度、assignment与像素监督联训。更细区域可能减少混合，但assignment内存和缓存成本增加，提示路由/质心/细胞聚合必须同步重建；不能仅改K并复用旧region ID。固定SLIC旧消融不是更大K learned assignment的证据。
4. **较大交互模型，作为独立比较。** SimpleClick/RITM、HQ-SAM/WSI-SAM值得做同数据同提示适配对照，但没有证据保证它们超过当前任务。它们能回答是否应替换交互解码范式；先完成现有语义特征的稠密输出对照，成本与解释性更好。

离线新增缓存图像金字塔/压缩语义特征，线上仅更新提示与像素解码器。不要每次点击重跑整个WSI encoder；先测cache容量、单ROI时延和显存。64通道128×128的FP16单层约2MiB/512px图块，整张切片应按需加载或压缩，不无限堆到GPU。

## 数据量与训练路线

本地空间train已有37,230个独立patch、167张WSI，315,690条提示组合；val为8,071 patch/87 WSI。提示组合不是独立图像。当前没有必要先寻找更多无组织GT的细胞/RNA数据。

建议采用嵌套的3,000→12,000→37,230独立train patch规模，固定1,024个分层val patch（保留旧64例作为回归子集）。同时保存类别、边界复杂度、空间块覆盖；淋巴聚集与blood的train eligible patch只有1,938和2,163，不能只靠多数类随机采样。原sampler已有类别/区域组平衡，新方案应落实到独立空间图块及目标边界，而不是假设原来完全没有平衡采样。

| 对照 | 结构 | 数据 | 用途 |
|---|---|---|---|
| A | J5冻结及J5有限微调 | 固定同清单 | 原始质量、单纯继续训练的收益 |
| B | 64×64提示条件稠密头 | 3k，然后12k/全量 | 分离64区域投影限制与数据规模 |
| C | B+128×128浅层融合 | 与B相同 | 分离高分辨率贡献 |
| D | C+边界重点采样/边界监督 | 与C相同 | 分离数据组织与loss贡献 |

先3k/1,024 val的8轮pilot，网络新头可用AdamW 1e-4起步；旧backbone先冻结，再仅解冻layer3/4，学习率低10倍作为单独对照。扩大时10–20轮为预算上限、按固定验证节点评估和早停；具体batch/吞吐以真实smoke测量。至少两种子，候选稳定后再多GPU。以上数值是建议起点，尚未启动训练。

扩量需同时报告两组学习曲线：固定更新步数改变独立图块数，以及固定数据增加更新步数。这样才能区分数据多样性与计算预算。所有几何增强必须同步变换H&E/GT/点坐标/区域几何/细胞坐标；当前joint loader没有随机翻转旋转增强，不能只翻RGB。染色/亮度增强先单独验证，新增难例挖掘仅用train。

损失仍以BCE/Dice为主体，辅以目标边界带监督或距离类loss；细/中/粗分辨率深监督与正负点一致性另作消融。原模型已用pixel_boundary=0.1，不应把再加一个boundary loss当成全新解决方案。真实点击要在标注有效内部生成；旧region质心可能落在region外，不能把质心违约代理直接当人工点击失败率。

## 验收与风险

- 开发性较大收益目标：同提示、同清单BF1@2至少+0.05绝对值，macro/micro Dice下降均不超过0.005；希望Dice同时+0.02，但不能预先保证。关键类不能出现系统退化，报告各类样本数、空间块配对区间、两个种子和失败例。
- 固定prompt replay衡量模型差异；另做各自误差驱动的交互曲线、点击数/失败率，不能混淆两种协议。新模型可能改变错误位置，模拟点本身可能不同。
- 同时报告BF1@1/2/4、规范Boundary IoU、Dice及边界距离；旧的双侧边界带IoU继续作为单独命名指标。原索引target_mpp全部为空，尚不能把2px直接换算成微米，应先读取WSI尺度元数据并核查标注精度。
- 空间val中5,782/8,071 patch源于旧train。J5/Phase2初始化已可能见过这些区域，当前全部结果只能作开发证据。最终正式比较需按同一个空间split训练两个模型，使用未见该split的初始化，或另建并审计全链条未暴露空间块；同病例允许跨split，不能改回病例独立为先决条件。
- 细化会受到人工组织标注精度的约束。对难分界、细碎结构、RGB图像与GT范围做人工复核，再定义物理容差；目前只发现需要审计，未证实数据普遍错标。

## 方法依据（2026-10-14检索）

- [PointRend，CVPR 2020](https://arxiv.org/abs/1912.08193)：使用细粒度特征与粗预测，在自适应选择位置进行像素预测。支持最后一级细化的设计动机，不提供本任务收益保证。
- [HQ-SAM，NeurIPS 2023](https://arxiv.org/abs/2306.01567)：结合高质量token和多层特征提高mask细节。可借鉴特征融合，不能直接把自然图像成绩转成组织边界效果。
- [WSI-SAM，2024](https://arxiv.org/abs/2403.09257)：多分辨率token及双mask解码器，在病理区域任务验证；其乳腺DCIS/CAMELYON16任务与本项目12类结直肠组织不同。
- [SimpleClick，ICCV 2023](https://openaccess.thecvf.com/content/ICCV2023/html/Liu_SimpleClick_Interactive_Image_Segmentation_with_Simple_Vision_Transformers_ICCV_2023_paper.html)：ViT与特征金字塔交互分割，适合作为独立结构对照；其点击进入backbone，直接替换会改变现有离线缓存成本。
- [RITM](https://arxiv.org/abs/2102.06583)：前轮mask与迭代点击训练；论文还展示训练数据选择的重要性，但自然图像数据不能直接替代组织GT。
- [病理交互SAM评估与解码器改进](https://arxiv.org/abs/2310.10493)：指出SAM在病理区域交互中的局部修正/提示稳定性问题，说明通用大模型不是自动胜出。
- [Boundary IoU，CVPR 2021](https://openaccess.thecvf.com/content/CVPR2021/html/Cheng_Boundary_IoU_Improving_Object-Centric_Image_Segmentation_Evaluation_CVPR_2021_paper.html)：边界敏感评价；与当前双侧膨胀边界带IoU不是同一实现。

优先决定：下一轮实现B/C/D消融与3k规模训练；本轮只完成日志审计、真实诊断和可执行研究设计，没有把新架构或大规模训练写成已经完成。
