# 冻结跨 cohort gate 失败诊断

## 问题

中规模五 cohort、2,266-cell frozen H&E gate 的 paired H&E macro-F1 未超过 shuffled control。需要区分数据/实现错误、平台差异、癌种差异、标签本体差异与“冻结视觉特征对单细胞类型本就不够”的可能性。

## 已确认的非错误项

- 五个 feature-cache shard 均 `complete`，合计 2,266 个 cell；每个 256px/384px feature 均 finite。
- 每 shard 的 `cell_id` 与 feature 顺序经过严格一致性检查；新 gate 读取 cache 后得到 finite `[2266,2048]` 输入。
- leave-one-cohort-out split 每 fold 的 held-out cohort 不出现在训练集；RNA 未读入模型。
- adapter 的 train loss 约 `3e-4` 至 `7e-4`，说明训练路径可拟合训练 cohort，失败不是 loss 不收敛或特征 NaN。

## 诊断计划

从已保存的 30 个 checkpoint 重放 held-out prediction，输出：每 held-out cohort 的 paired-vs-shuffled 差异、每 broad class F1/recall、聚合混淆矩阵和训练/test class coverage。该分析不更新任何模型参数。

## 判读原则

- 如果各 cohort 均接近 shuffled，首要问题是 H&E-only frozen feature 对该细胞任务缺乏稳定信号或 crop 不够 cell-specific。
- 如果只在某平台失败，优先排查平台/染色/坐标域；如果同癌种的 Xenium 与 CosMx 方向相反，不能简单归因为癌种。
- broad ontology 仅合并了上游 `annotation`；其跨数据集语义仍需以后做 marker/RNA 一致性核验。

结果与推荐将在 checkpoint 诊断完成后追加。

## checkpoint 诊断结果

- 30 个 checkpoint 已重放；所有 cache identity、feature 有限值和 held-out cohort split 均通过。因此没有发现 cell-feature 错配、NaN、RNA 泄漏或 cohort 泄漏。
- paired 对 shuffled 的 macro-F1 差异：CosMx COAD `-0.0202`、CosMx HCC `-0.0263`、Xenium COAD `-0.0304`、Xenium HCC `-0.0097`、Xenium OV `+0.0003`。只有 Xenium OV 接近持平；没有一个 cohort 给出稳定 macro-F1 正增益。
- 每类平均 paired F1 均很低：b/plasma `0.047`、T cell `0.082`、innate lymphoid `0.037`；myeloid 为 `0.162`、granulocyte/mast 为 `0.148`。T、B/plasma、innate 的 paired F1 还低于 shuffled，表明主要困难集中于形态相近的免疫谱系。
- 各 checkpoint 的 training loss 约 `0.0003–0.0007`，包括 shuffled arm；而 held-out macro-F1 约 `0.08–0.12`。当前 `2048→512→256→8` adapter 参数量相对每 fold 约 1,800 个训练 cell 过大，能记忆随机 H&E-label 对应。因此该 MLP gate 的失败是有效警报，但不能单独证明 frozen feature 完全无信号。

## 原因判断

1. **不是 cache/坐标读取错误。** 五 shard 都通过 cell ID、feature shape、finite 和 held-out 检查；CosMx 的结论仍限于 raster-level crop 对齐，不扩展为边界级配准声明。
2. **冻结 patch backbone 与单细胞类别任务不匹配。** Phikon 看的是 256/384px 组织上下文；当前 feature cache 仅用细胞中心 crop，没有将真实 cell boundary/mask 注入视觉 token。免疫细胞的 H&E 细胞形态弱，crop 很容易主要编码周围组织、染色和扫描域。
3. **域差异很强且独立样本太少。** 每 cohort 当前仅一个 section，且有 Xenium/CosMx、COAD/HCC/OV 的平台和组织差异；leave-one-cohort-out 同时改变癌种、平台、染色和 annotation 域，无法将某一因素单独归因。
4. **本体覆盖不完全一致。** 部分 held-out cohort 没有某个 broad class（例如 COAD 无 innate lymphoid、HCC 无 fibroblast），因此 sklearn 已提示预测类别不在该 test truth 中。8-class macro-F1 跨 fold 可比较性有限，必须同时报告 supported-class macro-F1 和每类 support。

## 推荐的下一步

先做一个**正则化线性 probe**（logistic/linear head），固定相同 cache 与 cohort split、只调节训练集内的正则强度；它没有能力记忆随机配对，是判断 frozen Phikon 特征是否有小但真实跨 cohort 信号的必要对照。之后再分别做同平台跨癌种和同癌种跨平台 split，才讨论 LoRA、边界感知 crop 或 RNA teacher。不要在当前高容量 MLP 的负结果上直接启动全量 LoRA。
