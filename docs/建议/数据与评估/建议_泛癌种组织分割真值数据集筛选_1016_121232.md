# 泛癌种、本片提示—查询的组织分割真值数据集筛选

日期：2026-10-16。用户目标：新WSI、新癌种上给本片少量正负示例，再在同片其他区域检索/分割。此次工作为一手来源检索、标注与获取方式核查、服务器有限深度只读审计；没有下载大规模图像、提交申请、发送邮件或采用新数据训练。提示—查询正式CRC诊断保持运行。

## 结论与优先级

可以找到真实组织区域分割答案，建议组合使用，而不是等待一个所有癌种、所有组织、整片穷尽标注的统一数据集：

1. **OCELOT**：跨六器官的癌区/非癌区像素mask，用于低成本多域初筛；组织粒度粗，不能证明任意组织概念能力。
2. **TIGER WSIROIS、BCSS/PanopTILs**：乳腺多类组织；TIGER提供WSI和ROI位置，更接近整片流程；BCSS/PanopTILs便于快速多组织实验。三者有来源重叠，不能当作三个独立外部域。
3. **IGNITE**：NSCLC多类H&E组织分割，用作肺癌主要外部候选，具有原发/转移、中心/扫描器变化。
4. **PUMA**：黑色素瘤组织及核共同标注，可作形态差异较大的补充域；标注范围较小，不优先用其证明整片远端召回。
5. **PAIP2019**：肝癌整片肿瘤/存活肿瘤mask候选；需申请，组织目标较少，适合补充整片规模任务。

这些是根据任务与数据格式作出的建议，尚未实测本模型在这些数据上的性能。首批建议选OCELOT、一个乳腺来源与IGNITE，各自保留不参与模型调整的评测区域；后续按结果加入PUMA/PAIP。

## 如何构造成我们的任务

数据集不需要预先提供交互提示。对每张带mask的新图像/切片：指定一个本数据集已标注组织作为任务，在支持区域从mask生成少量正负示例；将源支持视觉信息与查询图像输入模型；查询mask仅用于评分。正式人工示例与GT模拟示例分别报告。

- 用source WSI ID/坐标找到空间分离的支持、查询ROI；核验真实物理视野、上下文范围及buffer。支持不足就skip，不能复制同一组织区域或上下文泄漏伪装远端迁移。
- 大ROI可构造局部支持与未提示区域评分，但这只能叫ROI内交互。不能把PUMA的一张1024²标注ROI拆开后声称已验证整张WSI远端检索；其外圈context未标注部分仍是未知。
- 未标注/Unknown/outside ROI为ignore，不能当作“目标不存在”负例。目标缺失任务必须在有充分真值的query内确认目标缺失。
- 每个数据集使用本地任务标签构造二元GT，不要求跨癌种先统一成一套12类。只在作跨数据集同概念比较时明确tumor/stroma/immune等映射与不一致定义；模型API不接收query真值类别ID。
- OCELOT主要是癌区与非癌区，适合检验跨器官；多组织概念能力需要IGNITE/BCSS/TIGER/PUMA补充。
- 保留当前用户允许同病例跨split、按空间划分的规则；来源重复、相邻上下文与BCSS/TIGER/PanopTILs共享图像仍应统一分组。另保留外部癌种用于评估新域，不把所有外部数据先用于适配再叫未见癌种。
- 本模型74维XCell输入依赖核实例/类别，外部组织GT并不自动提供同合同核输入。OCELOT是细胞点，不是核实例；IGNITE IHC核点不等于HE核图。需单独准备图像推断核图与类别映射，或作明确、重新训练的输入消融，不能悄悄置零细胞分支后算同模型泛化。

## 后续采用顺序、风险与验收

建议先核验OCELOT小包和一个多组织域（优先IGNITE或乳腺来源），每个选数个具有可用目标与非目标的ROI核查图像/GT/MPP/ID。需要真实整片吞吐与远端检索时优先TIGER，PAIP作为申请型补充；PUMA用于新形态域和细胞—组织共同输入探索。

验收至少包括：确定版本与文件校验、图像mask尺寸/坐标对齐、ignore代码、可评分区域、真实slide ID、同片支持—查询可配对数量、每个目标的存在/缺失任务覆盖、细胞输入的获取和标注来源。通过这些数据检查后才进入冻结模型试验，并记录新增人工提示预算。没有通过本轮就绪性核验的候选不直接启动大训练。

替代选择：WSSS4LUAD/LUAD-HistoSeg可作肺癌补充，但训练部分常仅图像级标签、像素GT集中在验证/测试；小224²图块及来源追踪约束也较大，优先级低于IGNITE。纯核实例数据如PanNuke/MoNuSeg不能直接替代组织区域GT，分类图块数据也不能当分割答案。
