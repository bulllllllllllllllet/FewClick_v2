## 1. 建议与依据

主线是验证投稿方法在匹配训练、提示和评分条件下的表现；扩展线是验证增加 Dense 后的边界收益、远端能力与误报代价。两条线分别命名和报告。不能把现有 v2 多域重训成绩改名为原版＋Dense。

预期收益：公平训练对照回答两位审稿人的共同核心质疑；严格类别留出与 TLS 对照回答 user-specified 的适用范围；完整 WSI 与远端组件评测直接检验论文主张；Dense 为边界局限提供明确扩展。

替代方案：只展示 v2 更高 Dice，实施快但同时改变数据、表示、解码与点击，不能回答原方法贡献；只加 Dense 可以回答边界问题，但不能解决训练不公平或未见概念验证。故均不作为主方案。

验收标准：每个评审问题有可追溯的协议、结果或诚实的限制说明；每个数值能对应 checkpoint、输入和聚合方式；不预设提升或录用结论。统计结果不支持某项主张时，收缩主张，而不是另选测试子集。

## 2. 优先处理的三项证据问题（E0）

### 2.1 TLS 的 0.70 可能是指标误写

本地 submission.pdf 和主文写“approximately 0.70 Dice”。本地补充材料 PDF/TeX 的 30 WSI 汇总实际列为：

| 指标 | 本地补充材料值 | 统计单位 |
|---|---:|---|
| 全 TLS union Dice | 0.5229 ± 0.2270 | 每张 WSI 等权 |
| 全 TLS precision / recall | 0.4484 / 0.7882 | 每张 WSI 等权 |
| 排除已提示 TLS 区域后的 Dice | 0.3955 ± 0.2319 | 每张 WSI 等权 |
| 未提示 TLS 多边形 macro recall | 0.6968 ± 0.1479 | 先片内聚合，再 WSI 等权 |
| 全 TLS pixel-pooled Dice | 0.2785 | 跨片像素池化 |

30 张片、578 个多边形、279 个用作正提示、299 个保留评价，是补充材料陈述的历史规模。每片约半数 TLS 提供一点，外加 3 个负点；不是所有片都只用 1 正 1 负。

行动：将实际上传 PDF/补充材料、原预测和汇总脚本绑定；核对上述数字是否属于同一版本。若确认误写，应明确改正 metric 名称，报告 Dice 和 precision 的局限。不能把 recall 继续称 Dice，也不能选择 WSI macro 而隐藏 pooled 与片间异质性。

### 2.2 原论文多尺度叙述与 J5 路径需要追溯

主文描述三尺度层级图，并称 fine-only 消融降低 macro Dice 0.1029；当前 v4 WSI README 与 10 月审计将实际 J5 路径描述为 fine_only、未启用被否决的 parent-context 分支。可能是不同 checkpoint/阶段，也可能存在叙述与实现不一致，现阶段不能定性。

行动：逐张表记录代码 revision、配置、checkpoint SHA、运行 metadata、数据 manifest 和真实 forward 模块。查明 patch、WSI、TLS、消融是否共用同一路径。若某结果来自 fine-only，按实际配置命名；不能临时开启多尺度后声称复现原结果。若不能找到多尺度消融的来源，该结论标“未证实”，不能继续写“层级图贡献已验证”。

### 2.3 输入信息与数据暴露

原细胞向量包含核类别 one-hot；必须核实它来自人工核标注还是图像预测，以及测试时是否需要额外标注。XCellFormer 的 H&E–mIF 预训练来源、重叠、归一化拟合范围也须查清。H&E 推理不需要 mIF，不等于从未使用额外监督。

建立 information ledger：每个模型列图像/核实例/核类别/细胞 embedding/组织标签/支持 mask/GT 框/外部预训练的来源与使用阶段。若测试核类型来自人工，应标为额外输入，并增加 H&E-only 条件；不能默认它是免费可用的图像特征。

E0 交付：`submission_provenance`、`model_manifest`、`data_exposure_matrix`、`metric_reconciliation` 四张表。无需先重训。当前方案的 F0 是待 E0 绑定的投稿模型，而非未经核对即指定任意 J5。

## 3. 模型版本与统一协议

### 3.1 实验版本

| 代号 | 定义 | 作用 |
|---|---|---|
| F0 | 投稿结果对应的原代码、原权重、原点击解释与区域投影 | 原文复现与主要证据 |
| F0-R | 原方法按共同训练协议重训；不加 Dense、不加新域 | 训练预算/初始化/种子受控对照 |
| F0-CT | 从 F0 继续训练，额外预算与 Dense 分支对照相同 | 区分增加 Dense 与仅继续训练；不等同 F0-R |
| F0-D | F0 参数和 BN 状态冻结，只训练新增 Dense；同原训练数据 | 隔离新增稠密分支贡献 |
| F0-DJ | 与 F0-D 相同起点，再做有限联合微调 | 可选扩展；与等额外预算 F0-CT 比较 |

现有 v2/C3/清晰原图重训版本另称 V2，不进入“只加 Dense”的因果对照。不能从 V2 权重去掉 Dense 后冒充 F0。当前多域 soft 点击接口下的原始 J5 与投稿原生点击解释也分开。

F0-D 若必须增加像素位置软读取或新的点击热图接口，增加两行：F0＋同接口无 Dense；F0＋同接口＋Dense。这样可区分读点方式和稠密头收益。远端 query 不复制支持图的坐标热图。

### 3.2 数据划分与暴露边界

- 原论文主对照复用历史 140/30/30 WSI 清单，不迁入 v2 新空间划分；这是复现已提交实验，不是重新要求后续研究按病例划分。历史 patient/WSI 独立性需按 ID 核实，不能根据文字直接认定。
- 新设计数据采用当前允许的空间分块隔离；同病例可跨 split。重复原图、重扫描、相邻上下文、跨模态同源区域放同组，核验输入 footprint/buffer。保留病例 ID 用于来源审计和相关性统计，不据此强制重新切分。
- 训练、验证、测试先冻结；阈值、超参、checkpoint 仅由训练/验证确定。先前用于选模或调协议的集合称开发集；历史“sealed”不自动等于当前仍未看过。
- 跨域数据按版本暴露区别：IGNITE/TIGER 可是 F0 的外部域，却已用于 V2 的训练或开发。对于已经看过的 external development，不能重新命名为盲测。PUMA 仅在全链路暴露审计通过后作为新的未见域候选。
- 未标注像素 ignore，不是背景。测试支持点是允许输入；query GT 不进入 forward、原型构建、阈值或候选选择。

### 3.3 两条提示协议

P-original：精确复现论文的 (1+1)、(3+1)、(5+1) 与其原生解释；回放历史成绩。

P-matched：统一物理点击坐标与点数；初始正点位于预先规定的目标内部，负点位于可确认的非目标组织。所有模型相同，规则在看模型结果前固定。采用 5 套固定初始提示（建议值），报告所有重复均值与方差，不选 best-of-five。点数曲线用同一共同可评任务集合和嵌套正点前缀；不随预算换测试样本。

额外纠错曲线单列：统一模拟器按各模型自己的误差选下一点，因此位置可不同；报告固定预算 Dice、达到 Dice 0.80/0.90 的点击数、预算内未达标率。未达标任务按右删失/失败率报告，不能只平均成功案例。GT 模拟点不称真实人类交互。

### 3.4 指标与统计

- Patch：每任务 Dice、macro IoU、pixel-pooled micro Dice、BF1@2px（历史）、BF1@2µm（有可靠 MPP 时）、precision/recall。定义清楚 episode macro、class macro、WSI macro，禁止统称一个 macro。
- 主任务是组织前景；12 类语义基线包含背景类别，但不把背景正目标混入主要组织检索平均。原表如纳入背景则原样回放，另列统一组织口径，不能静默删类提高分数。
- 有目标与无目标分别统计。空 query 用 FPA=预测前景有效面积/总有效面积，并报告 FPA 超 1% 与 5% 的任务比例；Dice 双空为 NA，不用赋 1 抬高均值。
- 主阈值复现 0.5；各基线必要的官方阈值策略明确披露，允许仅在共同 val 调优，测试阈值固定。均衡阈值与 PR 曲线可作附加分析，不按 test 最优点排名。
- 以 WSI 为主要聚合/配对单位；同病例多个 WSI 时作病例聚类敏感性分析。空间分块数据报告块聚类与来源 WSI/病例相关性的限制。不能把几千 patch 当几千独立病人。
- 主效应是配对 ΔDice、ΔBF1、ΔFPA，报告 95% 配对 cluster bootstrap CI（建议 2,000 次）；训练随机性目标 3 seeds。资源不足只做 1 seed 必须如实说明，不能把 5 套点击算 5 个训练种子。
- 失败、OOM、提示冲突均保留分母。报告完成率及已完成任务条件质量；另给失败按零质量计的完整任务集敏感性分析，不伪造失败样本像素 mask。

## 5. E1：匹配训练的主对照（最高优先级）

问题：在相同目标数据监督下，F0 的优势是否仍存在？

最小核心方法：F0、F0-R（受控重训）、F0-D、SAM-public、SAM-FT、WSI-SAM-public、WSI-SAM-FT、DeepLabV3-ResNet50-12class。SAM-Med2D 原历史行保留；预算允许才增加其适配行。SimpleClick 作为通用交互训练对照优先候选；近期方法见 E7。

训练合同：

1. 固定原 140 张训练 WSI 和相同可用组织 mask；相同 patch/任务采样池、增强、输入物理 FOV、点击分布与验证集。内部网络分辨率按官方实现，记录重采样，不强行改成失真的低分辨率模型。
2. SAM/WSI-SAM 先按官方接口做 decoder/adapter 适配；另提供允许部分 encoder 适配的候选，以共同 val 选择。不能只训练一个明显不足的头然后称强适配对照。
3. 各模型给予相同超参数搜索次数上限和可比较的训练样本暴露预算，报告实际优化步数、算力与参数量。epochs 相同不代表数据/计算相同。预算前置固定，跑满预算仍未收敛则披露而不宣称架构落后。
4. 受控 F0-R 从同等允许的基础预训练开始；沿用已经看过全部目标数据的 F0 做继续训练，只能回答继续训练控制，不能当从头公平预算。列出所有上游组织/细胞预训练阶段，不能只数末段 epochs。
5. 12 类分割模型输出完整语义图，再取任务指定类别的通道；它获得类别 ID，这比点语义更明确，标为 closed-set supervised reference。另可由正负点选通道作交互选择版本。它用于已知组织任务，不能被要求输出未学过的新类而把失败当优势。

测试：P-original 回放；主要新增对照用 P-matched 的 (1+1)，再做共同任务集的 (3+1)/(5+1)。所有主表标训练来源、附加监督、参数、提示类型与时间。

表 T1：方法／目标数据适配／细胞来源／Dice／BF1／precision／recall／每点击耗时。历史零样本行和同域适配行分组。

结论规则：F0 相对最强匹配适配对照的配对 CI 若跨 0，不能声称稳定架构优势；若优势缩小，承认域适配贡献；F0-D 优于对手仅支持增强版本。不能用 no-cell 0.5885 与未适配 SAM 0.4649 跨协议差额证明框架贡献。

## 6. E2：Dense 的独立贡献与代价（用户关心的扩展）

主假设：冻结原表示时，Dense 能改善边界恢复；是否影响远端检索与空目标拒识需单独验证。

最小矩阵：

| 行 | 原模型参数 | Dense | 数据/读点接口 |
|---|---|---|---|
| D0 | 原 F0 不更新 | 无 | 原协议 |
| D1 | 原 F0 不更新 | 无 | 若 Dense 需新读点接口，则启用该接口作控制 |
| D2 | 原 F0 冻结 | 仅训练 Dense | 与 D1 相同；若接口不变，直接与 D0 配对 |
| D3 | F0-CT，原方法等预算继续训练 | 无 | 与 D2 同任务/损失可比部分，检验额外训练 |
| D4（可选） | 联合更新 | 有 | 与 D3 同额外预算 |

训练数据只用原训练划分。历史 dense 若曾看过现有测试区域，不直接用作正式 F0-D，应从干净起点重训；已有高分保留为开发依据。

主测：Dice、BF1、区域边界内外分层误差、细小组织、不同目标面积、无目标 FPA、远端未提示组织召回、首点/增量时间和显存。至少输出原图、GT、F0、F0-D、差异/错误图，提示坐标一致；代表图由固定随机或预定分层抽取，不按最高 Dice 选图。

现有开发证据（不是新实验结果）：统一表在 CRC 同图协议中 F0 0.7512、历史 J5＋Dense 0.8237；三源有目标 Dice 0.4323→0.4537，同时空目标 FPA 11.90%→14.02%。这支持开展边界扩展，也提示不能只报 Dice。该表使用更新读点、开发数据与特定输入合同，不可直接替换投稿表。

可增加区域表示能力诊断：在 val 上用 GT 优化区域系数，估计固定 assignment 的可表达性；明确这是 oracle 诊断，不是可部署结果，也不把有限优化取得的值称严格数学上界。Dense 是否突破区域表示限制需结合其像素残差而非仅比较总分。

WSI Dense 接入需另验收：支持 tile 的局部热图仅留本 tile，远端 tile 使用全局 task 与自己的像素特征；重叠区域先融合概率再阈值；检查拼接缝、缓存身份和远端正负更新。未通过则 Dense 仅报告 patch，不以旧 v4 WSI 推理结果代表 Dense。

## 7. E3：细胞监督与框架贡献拆分

先做同一原框架的 C0–C3 四臂；每臂按各自表示重训下游，不能只在推理时清零。

| 臂 | 细胞信息 | 回答的问题 |
|---|---|---|
| C0 | 不使用任何细胞分支 | 框架无细胞时的表现 |
| C1 | 相同核检测的计数/面积/空间形态；核类别仅在可同等获得时加入 | 廉价细胞结构先验是否足够 |
| C2 | C1＋通用 H&E 细胞 embedding，不用 XCell 分子对齐训练 | 额外视觉细胞表征的贡献 |
| C3 | C1＋XCell embedding，其他输入一致 | XCell 表征的增量收益 |

严格将 C2/C3 称“表征替换对照”；要单独归因分子监督，需相同网络、相同 H&E 训练样本和预算，仅去掉/置乱分子对齐目标的预训练对照。跨训练源、跨网络的差异不能全部算到分子监督。

核类型若来源人工，追加 C3-predicted 与 C3-annotated，明确额外测试监督；H&E-only 检测/类型估计器只在训练允许数据上训练。检测器替换须保持两个框架相同输入，不把 Cellpose→InstanSeg 的变化与 Dense 混在一起。

框架归因：用同一 backbone/区域/细胞特征增加简单正负原型相似度＋区域投影对照，并与 Set Encoder＋graph decoder 比较；细胞缺失/存在各做一行，尽量形成 2×2。若只重训下游，结论限定为原表示条件下 decoder 贡献；完整结构贡献需相同起点重训。

可选形态分层 cell shuffle：在预先确定的局部/片内分层内置乱 cell–region 对应，控制参数容量。推理置乱是敏感性诊断，不冒充重训消融。

表 T3：C0–C3 与结构控制的同任务质量；另给全部预训练数据重叠审计。若预训练见过测试来源且无法排除，给无该预训练的对照或承认污染，不能写“完全独立”。

## 8. E4：严格的未见组织概念实验

把三种证据分开：新 slide 同类别、新域同概念、新标签/新概念。二元输出本身不证明任意组织泛化。

建议从可用标签中预先选 3 个形态不同的组织做 leave-one-class-out（按训练数据覆盖率和标注质量选，不能看 test 表现再挑；具体名称经 E0 本体审计锁定）。优先完整 3 folds，预算不足明确仅有 1 fold pilot。

每个 fold：

1. 从 tissue-supervised encoder、12 类语义辅助头、区域 purity/classification、episode 正负监督、Dense 等所有任务监督中排除该类；排除新类作为显式负样本，不能只取消正 target。
2. 保留其图像但将相关监督 ignore，只能称“无该类标签监督”，不称完全没见过形态；严格版再排除包含该类及输入上下文覆盖的训练区域。两版明确区分，目标不存在的“严格”训练池若过小则报告不可行。
3. 重新从不含该类目标监督的基础权重训练；原完整 12 类 J5 不可作为未见类模型初始化。基础通用预训练可能包含同类视觉外观，披露其已知/未知覆盖。
4. 在非留出类别验证集确定超参；测试给留出类的支持点，query 不见类别 ID 或 GT；模型间匹配同一 fold 训练数据与提示。
5. 用与 F0 同合同的 SAM-FT/WSI-SAM-FT、原型检索作为对照；保留已知类结果作为泛化代价。12 类闭集模型不作为新类失败基线。

TLS 专门做 lymphoid aggregate 相关监督的留出：L+ 为原训练，L− 为所有组织监督阶段排除 lymphoid aggregate（严格形态排除另列），并检查 XCell 的来源；不能只去掉名称。即使 L− 成功也不能证明无限概念泛化，只能支持该受控任务。

表 T4：每个 held-out 类的目标覆盖、提示数、F0 方法重训与对手 Dice/BF1/远端召回；同时列 seen/unseen gap。

## 9. E5：TLS 完整对照与语义近邻辨别

先复用并复核历史 30 张、578 个 polygon 的既有结果；主文/补充指标按 E0 更正。5 张主队列 WSI 测试与 30 张外部 TLS 是两套数据，不能用 TLS 30 张充当主队列 30 张。

两个互不混报的提示协议：

- T-historical：原279/299提示—留出划分、原每片提示数，复核所有模型在相同输入信息下的结果。
- T-budget：固定 (1+1)、(3+1)、(5+1)，每片 5 套预定提示，正点跨组件覆盖策略前置固定；目标不足时保留明确 eligibility，不按得分剔除。报告所有符合条件 WSI 及不符合原因。

对手：F0、合规 F0-D、SAM/WSI-SAM 目标队列适配版、原型检索；近期 reference-based 方法只有在支持信息预算可匹配时进入主比较。

TLS GT 核查：未标注组织不自动当负例。确认标注穷尽性、可评分 tissue 范围；若不穷尽，负点从确认非 TLS 区域选，precision/FPA 只在确认区域算，不能把未标区域全部当假阳性。

TLS 与 lymphoid aggregate 的 challenge 需要独立病理复核：定义 TLS 的标注标准，抽取既有标签中的困难非 TLS 淋巴聚集区域；专家在不知道模型预测的情况下核验。比较 TLS-positive、近邻非 TLS-negative 的差异。没有这些可靠标签，就承认该实验只能说明 TLS-like 结构检索，不能证明精确概念区分。

主报告：全 TLS union Dice/precision/recall；prompt-censored Dice/precision/recall；未提示 polygon 的面积召回；组件检出率（面积召回≥0.5，附 0.1 敏感性）；FPA；各片点数。逐 polygon recall 不等于 Dice，单 polygon precision 不应把其他正确 TLS 计假阳性。

统计：以 WSI 为单位，polygon 嵌套其中；不把 299 个 polygon 当 299 个独立病例。图 F2 展示固定随机、失败案例和完整分布，保留低 precision 事实。

## 10. E6：完整 WSI、非连通检索与基线部署协议

### 10.1 覆盖范围

优先评估历史测试集全部 30 张 WSI 的所有预定可评组织任务。各片实际有效类别可能不同，不机械声称 30×12 都有目标。若资源不足，先在训练/验证规模信息上确定分层随机子集，冻结 ID 并披露；不能从 30 张结果中选 5 张展示总体优势。

原 5 张选择机制必须追溯；无法恢复就明确“选择依据未完整记录”，不能事后编理由。表 T5 同时给原5、剩余25、全30结果及失败清单，不以已知测试表现选 checkpoint。

### 10.2 三种比较轨道

W-local：同一 patch/ROI、同样点击，比较局部可分割能力。这是 E1 最强公平训练对照。

W-global：全片总预算固定，点击只在少量支持区域，query 不给额外 GT 框/点。F0 原生 slide task；原型匹配可以遍历整片。局部 SAM 若无原生跨 tile 语义传递，必须说明能力范围；若加自动 proposal/传播包装器，单独命名并在 val 固定，自动提示不得读 query GT。不能仅因局部基线远端没输入点击就将其失败解释为架构质量差。

W-oracle：复现原文基线逐 patch GT 定位/提示协议，保留其实际点数和 GT 权限，明确标 oracle localization，不与全片少量人工点称完全同预算。提供部署式结果和 oracle 辅助结果两栏。

12 类模型可全片铺图，按 target ID 取通道；标为固定类监督参考，跨片提示预算不适用。所有滑窗参数、stride、MPP、重叠权重、概率/阈值顺序、无组织 tile 过滤、组件后处理都写进表。

### 10.3 直接检验 disconnected retrieval

由 GT 连通组件定义 prompted/unprompted。主评价域移除所有已提示组件，预测/GT同时裁到剩余有效组织域，仍保留其中非目标组织，不能只在 GT 阳性像素算 Dice。

报告未提示区域 Dice/precision/recall、unprompted component macro recall、组件检出率；按距最近正点的物理距离分层。建议距离层 <1mm、1–5mm、>5mm，使用 val 预检覆盖后在正式 test 前锁定，稀疏层标 NA 不临时调阈值。

增加 source-tile 外评测，剔除支持 tile 与其输入上下文/重叠足迹，检验真正远端检索。跨支持/查询 ROI 输入覆盖相交的样本单列；不能只看 tile ID 不同就称远端。

图 F3：距离—召回与 precision 曲线；图 F4：固定同片坐标的支持区/远端区/错误区。全组织预测可以有高 recall，故不允许仅报 recall。

## 11. E7：外部数据与近期方法

### 11.1 外部数据方案

固定原模型，不做外部域调参。主选 IGNITE（肺）、TIGER（乳腺）、PUMA（黑色素瘤候选盲测）。TLS 自成一组；OCELOT 癌区任务作为可选粗粒度外部补充，不用它替代多组织验证。

- IGNITE/TIGER：复用已验收的数据处理资产，但根据 F0/F0-D/V2 各自训练与开发接触划分。ROI GT 只支持标注 ROI 内评分；有 WSI 不代表全片穷尽 GT。
- PUMA：本地下载记录为 205 对 ROI/组织标注，不是整个挑战规模。仅在确认本方案候选模型未用其标签选模之后，锁定公开可评范围做一次外部检验；不把公开开发数据当挑战官方隐藏测试。MPP、栅格化与模型细胞输入须实际核验。
- 各数据按自己的组织定义建立二元任务，不把同名 tumor 强行视作跨癌种完全相同概念。未标注/ignore 保留。
- 数量由全部合格数据实际清单决定；每个目标至少列来源 WSI/病例/空间块数量，不能为了凑每域固定大量 episodes 重复少数 ROI 而声称大样本。

表 T6：每域/组织、模型、支持点预算、是否参与训练/开发、Dice/BF1/FPA；固定模型与少量适配另分表。Dense 若只在 CRC 训练，可测试跨域；V2 在该域训练过的结果不得放在 zero-shot 列。

### 11.2 方法选择与输入公平

- **Clore，2026**：病理交互与局部细化方向直接相关，是近期候选。[作者论文](https://arxiv.org/abs/2603.27625)、[EMBC 2026 官方程序](https://cmsworkshops.com/EMBC2026/view_paper.php?PaperNum=2338&SessionID=1127&bare=1)。此次只确认论文存在与任务方向，代码/权重、复现成本尚未验收；不预先承诺一周内完成。
- **MultiverSeg，ICCV 2025**：有作者项目与代码入口，适合交互/上下文迁移比较。[作者项目](https://multiverseg.csail.mit.edu/)。先核实无 context 的点击模式是否可用；使用额外完整 image–mask context 的条件单独报告支持 mask 数与标注成本，不能当两点输入。
- **Segment Any Tissue，MedIA 2025**：reference-guided 组织迁移候选，[论文](https://doi.org/10.1016/j.media.2025.103550)、[作者代码](https://github.com/XueyuLiu/Segment-Any-Tissue)。它是 2025 年工作，不冒称最近12个月；参考图/标注成本依原方法核验，放 reference-based 轨道。
- **SimpleClick / SegNext**：可补交互方法对照；SegNext 先复用既有实验资产并审计匹配性，不默认重启用户此前停止的开发路线。已有开发分数不直接搬入投稿对照。

优先完成一个可复现的近期交互基线。代码缺失只做相关工作讨论，并将数值比较标为未完成，不能以随意简化实现冒充官方方法。核实例模型与组织区域任务不同，不仅因年份新就列主要 tissue segmentation 对手。

## 12. E8：效率、显存与规模

模型：F0、F0-D、最强适配交互对手、12 类模型。固定同一 GPU 型号、CPU线程、精度、输入、输出范围；分别记录 cold/warm I/O，CUDA 同步后计时。

分解：读取/组织检测→细胞检测与表征→图像/区域编码与缓存→首个提示编码/解码→增量点击→概率拼接与完整 mask 写盘。离线缓存是可摊销成本，必须报告；不以仅 decoder 的毫秒数称端到端整片耗时。

至少选预定小/中/大组织面积的代表片，每种 3 张（不足如实报告），每片 3 次冷准备测量；warm 交互建议 5 次预热＋30 次计时。长任务受 I/O 成本限制时减少重复并注明，不能给未经实测的完成时长。

统计 P50/P95 点击延迟、每片准备时间、显存峰值、CPU内存、缓存磁盘、tile/region/cell 数、MPix/s。Dense 缓存像素特征可能增大成本，单列。

摊销公式：T_total(K)=T_prepare+Σ T_click(k)+T_export；对 K=1、5、20 报真实/明确推算成本，推算注明固定条件。画组织面积/区域数与耗时关系；5 张测量不能声称复杂度已普遍证明。
