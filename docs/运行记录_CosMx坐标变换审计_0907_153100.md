# CosMx global 坐标到 H&E 像素坐标审计

## 目的

验证 CosMx COAD/HCC 的 polygon `x_global_px/y_global_px` 是否可由可重放的仿射关系映射到 H&E TIFF 像素坐标，从而决定能否将其加入 H&E-only cell encoder 的 crop smoke。

## 现有证据与候选变换

- 数据目录在 CSV 中列为 SPATCH 配对 H&E/DAPI 的 COAD、HCC CosMx cohort；边界 global 坐标的完整范围与 DAPI/morphology raster 范围一致，而非 H&E raster 范围。
- 两 cohort 中 `DAPI_width / HE_width` 与 `DAPI_height / HE_height` 均约为 `1.835`；polygon global y 最小值均约为 `-4255px`。因此候选关系为：

```text
x_HE = (x_global - min_global_x) / (DAPI_width / HE_width)
y_HE = (y_global - min_global_y) / (DAPI_height / HE_height)
```

这仍是待审计的候选变换，不是默认缩放；不会在未通过下列门禁时用于训练。

## 输入、输出与验收

- 输入 manifest：`/nfs-medical3/zyh/fewclick_v2/multisection_cell_manifest/multisection_cell_manifest_0907_145854/`
- 读取数据：`/nfs-medical3/fyx/PKU_DATA/CosMx/{COAD,HCC}`（只读）
- 输出：`/nfs-medical3/zyh/fewclick_v2/cosmx_coordinate_audit/cosmx_he_transform_0907_153100/`
- CPU 运行，libvips 临时文件显式写入同一 NFS output root，避免本机 `/tmp` 空间不足。
- 门禁：polygon global span 相对 DAPI raster 的 x/y 误差不超过 1%；manifest 的全部 112 个 CosMx sampled centers 映射后均位于 H&E 内；输出 H&E/DAPI 低分辨率组织轮廓 overlay 供人工核验。轮廓分数仅作辅助证据，不能单独证明配准。

完成后将记录指标和人工可见图的位置；通过后才启动小规模 CosMx H&E crop smoke。

## 审计结果与后续 smoke 计划

- 自动门禁通过：COAD/HCC global span 对 DAPI raster 的 x/y 相对误差均约 `0.01%`；56+56 个 manifest sampled cell 在候选变换后均落入 H&E 范围。
- 人工查看 `CosMx_COAD_tissue_mask_overlay.png` 与 `CosMx_HCC_tissue_mask_overlay.png`：组织的整体轮廓、方向和主要空白区域没有镜像、旋转或大范围平移。H&E/DAPI 二值 tissue mask 的 Dice 为 `0.318/0.360`，仅作跨模态轮廓辅助量，不能解释为细胞级精确配准分数。
- 决定：将此变换用于 **H&E crop smoke**，并在新 manifest 中标记为 `ready_for_he_crop_smoke_affine_audited`。后续若需要细胞边界级 mask/routing，还要做局部细胞/核级可视化核验；本次不声称已通过该门禁。

下一步命令将使用新 manifest 运行五 cohort 的真实 H&E 双视野 Phikon crop smoke，输出路径为 `/nfs-medical3/zyh/fewclick_v2/multisection_cell_smoke/`，NFS 临时目录显式设置以避免本机 `/tmp` 满。

## 五 cohort crop smoke 最终状态

- 新 manifest：`/nfs-medical3/zyh/fewclick_v2/multisection_cell_manifest/multisection_cell_manifest_0907_154620/`；288 个 cell 均为 crop-smoke eligible。
- 真实 H&E 双视野 Phikon smoke 完成，`EXIT_CODE=0`：CosMx COAD 56、CosMx HCC 56、Xenium COAD 56、Xenium HCC 56、Xenium OV 64 个 cell 的 256px/384px feature 全部为 finite `[N,1024]`；五 cohort 均无 crop edge shift。
- 结论：CosMx COAD/HCC 可加入 **H&E crop/feature 预训练候选**。该结论严格限于 global-to-H&E raster transform、中心 crop 和 encoder 特征提取；细胞边界级 routing/掩膜使用前仍须局部可视化验证。

最终审计：`/nfs-medical3/zyh/fewclick_v2/cosmx_coordinate_audit/cosmx_he_transform_0907_153100/`；smoke：`/nfs-medical3/zyh/fewclick_v2/multisection_cell_smoke/multisection_cell_smoke_0907_154620/`。
