# 真实细胞类型分类验证建议

## 问题

前一轮 RNA 实验的目标是从未输入的一组 RNA 基因自动聚出的分子簇。COAD Xenium 转录组是否含有可用于更直接验证的细胞类型注释，以及 RNA 是否仍能改善该真实注释的分类？

## 依据

- `/nfs-medical3/fyx/PKU_DATA/Xenium/COAD/transcriptome/adata.h5ad` 的 `obs` 含有 `annotation` 分类字段；类别包括 B、CD4T、CD8T、Endothelial、Epithelial、Fibroblast、Macrophage、Mast、Monocyte、Neutrophil、Plasma、SMC、Tprolif、cDC2、mregDC、pDC。
- 已完成的 XCell artifact 中 1,020 个细胞有 1,005 个可映射到该字段。按四个空间区域计数，`Epithelial`（786）、`Fibroblast`（67）、`Macrophage`（48）、`CD4T`（40）在每个区域均有样本；其他类别至少一个区域为零或总数过小。
- `docs/运行记录_XCell视觉基线_0831_111806.md`：这些细胞已有冻结 v4 XCell `reg-64` 特征和同一细胞的 RNA 输入视图。

## 建议

以这四个数据提供方的 `annotation` 作为目标标签，保留原有四块空间留出交叉验证，比较 XCell 视觉、XCell+正确 RNA、XCell+打乱 RNA。输出应明确称为“数据提供方细胞类型注释”，不把它表述为逐细胞人工病理金标准。

## 备选方案与风险

- 纳入全部 16 类：覆盖更广，但稀有类在空间折中无训练例，会造成不稳定或不可解释的 macro-F1。
- 只使用 RNA 聚类标签：无需数据提供方注释，但不能直接回答真实类型问题。
- 风险：标签来源和注释流程仍需在 SPATCH 原始数据说明中进一步核查；本实验只验证当前局部窗口，不能外推到整张切片或最终 FewClick 分割。

## 验收

四类均在每个空间块存在；特征、标签和细胞 ID 一一对应；正确 RNA 相对打乱 RNA 的 macro-F1 与 balanced accuracy 增益均至少 `0.10`。
