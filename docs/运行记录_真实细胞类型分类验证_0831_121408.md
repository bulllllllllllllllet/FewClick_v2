# 真实细胞类型分类验证运行记录

- 时间戳：`0831_121408`
- 目标：基于 COAD Xenium 数据提供方的 `annotation`，验证 RNA 对真实细胞类型分类的增益。
- 输入：冻结 XCell artifact `xenium_xcell_baseline_0831_111806` 的 `cell_summary.csv` 与 `xcell_reg64.npy`；`transcriptome/adata.h5ad` 的 `obs/annotation`；配对转录本 parquet。
- 输出：`/nfs-medical3/zyh/fewclick_v2/rna_pilot/xenium_celltype_pilot_0831_121408/`。
- 计算：注释导出使用 `muf-clust`（提供 HDF5 读取）；评估使用 `aligner`（RNA 与 sklearn 依赖）。无需 GPU，因为复用已经提取的 XCell 特征。
- 验收：保留四类在四空间块均有样本；标签 ID 对齐；报告 XCell、XCell+RNA、XCell+打乱 RNA 的空间 CV 指标。
- 最终状态：完成 — passed。

## 结果

- 从冻结 XCell artifact 的 1,020 个细胞中映射到 `annotation` 的有 1,005 个；按预设的四空间块可用性筛出 941 个。
- 使用的四类数据提供方注释：`CD4T`（40）、`Epithelial`（786）、`Fibroblast`（67）、`Macrophage`（48）。它们均在每个空间块至少出现一次。
- XCell `reg-64` 视觉：macro-F1 `0.1758`，balanced accuracy `0.3036`。
- XCell + 正确 RNA：macro-F1 `0.8725`，balanced accuracy `0.9023`；相对视觉增加 `+0.6967` / `+0.5987`。
- XCell + 打乱 RNA：macro-F1 `0.1699`，balanced accuracy `0.2863`；正确 RNA 相对打乱 RNA 增加 `+0.7026` / `+0.6160`。

验收通过。强烈类别不均衡（上皮细胞占 786/941）使单纯 accuracy 容易误导，因此以 macro-F1 与 balanced accuracy 为主。仍需将其理解为这个局部窗口上的细胞类型注释分类证据，不是全数据集泛化结果，也不是 FewClick 分割指标。
