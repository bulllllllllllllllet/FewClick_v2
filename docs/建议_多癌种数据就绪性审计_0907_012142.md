# 多癌种训练的数据就绪性审计

## 问题

FewClick_v2 是否已有足以启动多癌种训练的数据？需要分别回答细胞 H&E-RNA 表征预训练与像素级组织交互分割，因为两者对标签和样本量的要求不同。

## 盘点范围与证据

依据 `docs/数据集情况/【7】基因-病理-疾病相关数据.csv`，并对其 NFS 路径作只读抽查。

### 尚不能计入当前可训练集的项目

- HEST-1k、TCGA/CPTAC 等目录在 CSV 中记录了来源和大样本量，但当前目录字段为空或未验证，不能当作本地已就绪数据。
- Visium/Stereo-seq/Visium HD 数据多为 spot/bin 级，适合作 region/patch 监督或验证，不能直接给每个细胞提供单细胞身份监督。
- 胰腺 12 例与其他外部数据虽列出路径，但尚未逐文件核查 H&E、坐标、细胞/spot 标签和授权，暂不纳入。

## 单癌种与多癌种训练的区别

| 维度 | 单癌种 | 多癌种 |
| --- | --- | --- |
| 学习目标 | 优先拟合一种器官/肿瘤的形态与微环境 | 学习跨器官稳定的细胞/组织概念，同时保留癌种特异性 |
| 数据划分 | patient/donor 隔离 | 除 patient/donor 隔离外，必须有 held-out cancer/center 验证；不能把相邻切片分到不同 split |
| 标签 | 同一平台的标签通常一致 | 需建立版本化 cell-type ontology；不同 panel/注释不能直接视为同一个类别 |
| 采样 | 按类别平衡 | 同时按癌种、平台、中心、细胞类、染色/扫描条件平衡，避免乳腺或上皮细胞压倒其他域 |
| 评价 | 同癌种独立病例 | 同癌种 test + leave-one-cancer-out/held-out-center；分别报告每癌种与宏平均 |
| 主要风险 | 对该癌种外推弱 | domain shift、标签不一致、癌种/平台捷径、独立样本数虚高 |

## 结论与推荐

1. **细胞 H&E-RNA/蛋白表征预训练：够启动“多癌种 v1”。** 已有 COAD、HCC、OV、肺、乳腺、肾、前列腺等至少七种癌种/器官的候选，且大量目录有细胞边界、H&E 与表达矩阵。第一版应先选 4–5 个实际可解析、坐标/细胞 ID 可对齐的 cohort，保留 1 个癌种完全不参与训练，作为跨癌种 gate。
2. **泛癌种细胞基础模型：尚不足以作强结论。** 当前很可能只有少量公开切片/供体，百万级细胞高度相关；不能把 300 万细胞当成 300 万独立样本。必须先统计每个目录的 `sample_id`/donor 数、切片数、annotation 覆盖率和细胞类别分布。
3. **多癌种 FewClick 组织分割主训练：当前不够。** 现有可复现的像素 GT 主基准是 GDPH 的 COAD 12 类组织分割。空间组学目录没有被验证为具有与 GDPH 兼容的统一像素组织 GT；不能把它们直接混进同一 12 类 segmentation loss。
4. **最稳妥路线：双层训练。** 先用多癌种 paired spatial cohorts 预训练 H&E-only cell encoder，再在 GDPH 组织分割任务中接入该 cell embedding；随后收集/标注跨癌种统一组织 GT，才扩展 Phase 1/2/6 的主分割训练。

## 下一步数据审计门禁

对每个拟纳入的 cohort 生成只读 manifest，记录：`cohort_id`、癌种、平台、sample/donor/section ID、H&E 路径、RNA/蛋白路径、细胞边界、坐标变换、可用 annotation、基因 panel、细胞数量、许可证、split。验收条件为：至少 4 个训练癌种和 1 个完全 held-out 癌种；每一癌种至少两个独立 donor/section（优先 donor）；所有 H&E-cell-RNA 映射可由稳定 ID 重放；细胞类型本体映射经人工复核。
