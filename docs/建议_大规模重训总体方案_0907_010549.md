# FewClick_v2 大规模完整重训总体方案

## 问题

在已经验证“正确配对的空间 RNA 能显著提升细胞类型注释分类”后，如何把该证据变成可复现、可扩展的 FewClick_v2 大规模训练，而不是直接在现有小窗口结果上进行一次高风险的端到端训练？

## 已核查的旧版训练事实

- `benchmarks/v4/phase_1_multiscale/README.md`：旧版先审计 WSI/GT、构建坐标索引、过拟合 16 个 patch、1 epoch smoke，再训练 10x 12 类组织分割基线。
- v4 `phase1_10x_baseline.yaml`：GDPH 任务为 12 类组织分割，配置曾使用 200 WSI 开发队列、每 epoch 20,000 train/4,000 validation samples。
- `train_phase2.py`、`train_phase3.py`：Phase 2 先学习 region assignment/token；Phase 3 从冻结 Phase 2 checkpoint 开始，读取预计算或路由后的 cell feature。
- `build_multiscale_token_cache.py`、`train_phase4.py`、`train_phase5.py`、`train_joint_pixel.py`：Phase 2/3 冻结后先缓存三尺度 token，再训练跨尺度、prompt 和像素 decoder；旧版最后只有限解冻部分视觉 backbone，未从零开始六模块联合训练。
- `docs/运行记录_真实细胞类型分类验证_0831_121408.md`：COAD Xenium 局部窗口中，数据提供方 `annotation` 的四类细胞上，XCell+正确 RNA macro-F1 为 `0.8725`，打乱 RNA 为 `0.1699`；该结果是证据型局部实验，不能替代跨样本的训练/测试。
- `docs/数据集情况/【7】基因-病理-疾病相关数据.csv`：本地有 H&E+空间 RNA/蛋白数据目录以及 GDPH 组织分割数据索引；目录条目仍须逐数据集审计后才可进入正式训练。

## 核心推荐

保留 v4 的“分阶段训练、冻结、缓存、最后有限联调”结构；在 Phase 3 前新增一个 **H&E 细胞表征预训练阶段**。RNA/蛋白只作为离线训练监督，产物是从 H&E 细胞 crop 预测的、可在任何新 WSI 上提取的 cell embedding。线上交互仍只读取缓存 region token，经过 Phase 5/6，不读取 RNA、蛋白或细胞统计。

```text
训练监督：H&E cell crop + paired RNA/protein/annotation
                    -> cell encoder (student) -> H&E-only cell embedding
新 WSI 离线：H&E -> cell encoder -> Phase 2/3 -> region-token cache
在线点击：cache -> Phase 5 prompt encoder -> Phase 6 decoder
```

## 阶段与每阶段门禁

| 阶段 | 主要输入/产物 | 必须先通过的门禁 |
| --- | --- | --- |
| 0. 研究与数据契约 | 固定任务、癌种/器官范围、类目本体、病例级 split、数据许可证与 manifest | 每个样本的 H&E、坐标、RNA/蛋白、annotation、组织 GT 能否配对均有审计报告；train/val/test 按 donor/patient 隔离 |
| 1. 组织视觉基线 | 全量 GDPH（或最终指定的组织分割队列）多尺度 patch manifest；Phase 1 checkpoint | 坐标/GT overlay 人工抽查；16-patch overfit；1 epoch smoke；冻结独立 val，不读 test |
| 2. RNA 监督的 cell encoder | 多个配对 Xenium/CosMx/其他可用细胞级 cohort；统一后的细胞类型/分子 program 标签；H&E-only student checkpoint | 跨 donor/cancer 的 cell-level test；与 visual-only、RNA-shuffle、无细胞 branch 对照；特征在新 H&E 上可独立提取 |
| 3. Deep Region Encoder | Phase 1 + Phase 2；soft region assignment/token | assignment 不塌缩，边界/语义损失有限，region oracle 指标优于固定 SLIC 对照或至少达到预设非劣门槛 |
| 4. Cell-to-region 融合 | 冻结 Phase 2 + 阶段 2 的 H&E cell embedding；Phase 3 checkpoint | cell routing/cache 与 patch ID 严格对应；cell/no-cell/RNA-pretrained-cell 三臂消融；病例级 val 增益 |
| 5. 跨尺度与 prompt | 三尺度 token cache、region label、prompt eligibility；Phase 4/5 checkpoint | cache 内容、尺度父子边、prompt 正负关系通过完整性检查；只用 train/val 构建训练 episode |
| 6. Mask decoder 联调 | Phase 2–5 checkpoints；Phase 6 checkpoint | 单例梯度、BF16 smoke、DDP、resume 全过；冻结大部分 encoder，先训练 decoder，再逐项有限解冻 |
| 7. 冻结评测与部署验证 | 一次性 test、point budget 曲线、WSI cache 和在线点击服务 | Dice/mIoU/Boundary F1、按类/癌种/中心分层结果、负对照、端到端首次预处理时间和单次点击延迟全部报告 |

## 数据与标签策略

1. **组织分割主任务**：先用有像素级 GT 的 GDPH 队列维持 12 类组织分割主监督；扩展癌种前，每个新队列必须有兼容的组织 GT 或独立的弱监督研究问题，不能仅因有 RNA 就混入同一分割 loss。
2. **细胞表征任务**：优先采用 H&E 与空间 RNA/蛋白严格配对、带 cell ID/边界/坐标的 cohort。把来源异构的 annotation 映射到一个版本化的 8–9 类泛病理细胞本体；无法可靠映射的细胞保留为“无监督分子 program”，不伪造类别。
3. **避免泄漏**：RNA encoder 或 RNA target 只在训练期出现。将基因划分、细胞/病例 split、normalization statistics 固定在 train 内；所有空间块、同一 donor 的相邻切片和配对模态不得跨 train/val/test。
4. **评估范围**：当前 COAD Xenium 只能作为 data-contract/pilot cohort；至少增加多个 donor 和至少一个独立癌种，才将 cell encoder 作为“大规模”预训练结果报告。

## 版本与目录建议

- 保持 `benchmarks/v4/` 完全冻结，用于回归复现。
- 在 `benchmarks/v5/` 建立独立、可运行的各阶段实现；不在旧 v4 脚本上原地修改。
- 每次正式运行使用 `/nfs-medical3/zyh/fewclick_v2/<stage>/<name>_MMDD_HHMMSS/`，保存 config snapshot、manifest hash、checkpoint、metrics、可视化与 `EXIT_CODE` 日志。
- 将数据 manifest、label ontology、split、normalization statistics、token cache index 当作 checkpoint 的一部分；任何一个变化都生成新的 run，不覆盖旧产物。

## 执行顺序

1. 先写 `v5` 的数据契约和 cohort manifest，而不是先复制/改网络。
2. 在 1–2 个配对 cohort 上完成 Phase 2 的 cell encoder 小规模跨 donor gate；若跨 donor 无增益，先处理 stain/annotation/domain shift，不进入全量训练。
3. 并行复现 v4 Phase 1–6 冻结基线到 v2 路径，得到同口径 checkpoint/指标。
4. 只替换 Phase 3 的 cell 特征源，做唯一变量的消融；增益稳定后再重建 cache 并推进 Phase 4–6。
5. 最后才进行有限端到端微调和一次性 test。不可直接从随机初始化训练六模块并把所有数据/损失一起放入。

## 关键风险与备选

- **细胞标签跨队列不一致**：先做 label ontology 和分子 program 辅助目标；备选是仅训练连续 RNA teacher embedding，不强行多类分类。
- **RNA 与 H&E 配准/分割不可靠**：将该样本降级为 region/spot 监督，不能用于单细胞监督。
- **癌种扩展没有像素 GT**：作为 cell pretraining 数据而非 Phase 1 segmentation loss 数据。
- **计算量大**：先做每阶段的小规模 gate；只有通过 checkpoint 门槛的候选才扩大到全量 cohort/多 GPU。
- **在线时延**：细胞编码和 region 融合属于首屏离线 cache；独立测量 cache build，不以删除细胞分支作为 click-latency 优化。

## 启动大规模训练前的验收清单

- 已确定第一批 cohort、每个 cohort 的病例数、样本数、可用模态、细胞/组织标签与数据权利。
- 已冻结 v5 细胞类型本体及跨数据集映射表。
- 已完成病例/供体级 train-val-test split，且由独立 manifest hash 锁定。
- 已完成 H&E/RNA/细胞边界/GT 坐标审计和 20+ 视野可视化复核。
- 已完成 cell encoder 的跨 donor 小规模 gate，包含 visual-only、正确 RNA teacher、RNA-shuffle 和无-cell 融合对照。
- 已复现 v4 的组织分割与 prompt/decoder基线，获得可比较的 val 指标。
- 已评估 cache 容量、首屏预处理吞吐和在线单点击延迟。
