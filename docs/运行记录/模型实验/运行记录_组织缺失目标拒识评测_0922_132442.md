# 组织缺失目标拒识评测

目标：保持现有多原型混合训练模型和0.5阈值，检查远处support提示的目标组织在query标注中不存在时是否触发错误阳性。不是替换阈值或改变原始算法。

support来自`paired_tissue_training_0922_130300`冻结70对中的远处support，query在同一WSI、验证split、完整三尺度上下文至少间隔512 level-0像素，且像素标签中不含support请求的目标类。若找不到合格query，明确skip而非放宽条件。仅加载mixed多原型的seed17/29/43 1000步checkpoint；不训练、不用test。

主指标：固定0.5阈值的空目标误触发率（有效像素中预测任何阳性即触发）和错误阳性面积占比。Dice不作为空目标主指标。逐pair保存预测/有效区域，报告每seed及每组织结果。GT标签不进入模型输入，只用于选择“缺失目标”query与评测。命令模块`evaluate_absent_tissue_target.py`先1对冒烟再完整运行，输出`/nfs-medical3/zyh/fewclick_v2/extensible_prompt/absent_tissue_target_<timestamp>/`。

## 完成结果

初始0922_132442冒烟因报告字典括号错误在模型运行前停止；修正后以0922_132600重新1对冒烟，EXIT_CODE=0。完整0922_133000在GPU1完成，worker2863792、EXIT_CODE=0。70个冻结support中64个找到同片、空间隔离的缺失目标query，6个明确skip；各目标query标签经读取复核不含请求类。保存64个mask和192条三seed指标，之后从保存mask重算全部一致。

固定0.5阈值下，mixed多原型总体空目标误触发率为**0.7448**，平均错误阳性面积为**0.2909**。seed17/29/43误触发率0.7500/0.7500/0.7344，错误阳性面积0.2816/0.2913/0.2999。这里的“触发”定义为有效区域任一预测阳性像素，不等同于临床诊断错误，也不以Dice评价空目标。

按请求组织：正常间质（5对）误触发1.000、FPA0.711；肿瘤上皮（4）1.000、0.511；脂肪（6）1.000、0.483；肌肉（8）0.917、0.417；背景（3）0.889、0.359；肿瘤间质（7）0.857、0.259。黏液（6）0.333、0.023，淋巴聚集（6）0.444、0.118相对较低。每类对数有限，不作类别间显著性排序。

结论：现有最佳“75% local＋25% cross混合多原型”对目标存在的区域有可用的组织匹配能力，但在无目标query中不能可靠拒识。因此“任意组织识别”的下一步不应先调整全局阈值；应构造明确的缺失目标训练episode，并与存在目标任务按固定比例混合，或增加只读取support/query匹配分数的任务级拒识头。评测保持0.5阈值，并同时报告存在目标Dice与空目标误触发/FPA，避免只改善其中一个。
