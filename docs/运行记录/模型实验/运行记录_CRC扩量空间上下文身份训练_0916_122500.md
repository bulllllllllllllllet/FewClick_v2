# CRC 扩量空间上下文身份训练

## 目的

纯`reg64`分类头的四种长尾策略均未达到五类可用门槛，尤其Treg不能兼顾precision与recall。本轮转向输入信息改造：在相同医生审核标签与H&E-only特征基础上加入细胞xy近邻、细胞面积及冻结Phase2区域token。

## 设计

- 复用已存在、已测试的`SpatialContextIdentity`：`reg64 + xy + log_area + xy-KNN(12) + frozen region token`；绝不输入mIF marker或身份标签。
- 使用当前1,553图块 pooled internal manifest，固定train/val；不使用类别权重、DRW、强制均衡采样或Balanced Softmax，以单独衡量空间上下文增益。
- GPU1，seed 20260915，最多60 epoch、patience12；先运行后以独立评估工具重算最佳checkpoint。

## 验收

必须超过当前DRW纯reg64的0.221140，并分别报告五类F1/precision/recall；Treg的非零结果需同时有合理precision。该对照仍是同病例内部图块验证，不能视作患者独立泛化或最终组织分割结果。

## 结果

首轮训练`spatial_identity_0916_122600/`因空间脚本把`count=0`的无身份监督图块错误视为失败而终止；该图块不是数据错误。修复为安全跳过无监督图块后，`identity_0916_133300/`真实1 epoch smoke通过。正式训练`spatial_identity_0916_133500/`完成37 epoch，最佳checkpoint为epoch 24；独立评估`evaluate_spatial_val_0916_134500/`完成。

patient macro-F1=`0.203774`，低于当前最佳DRW纯`reg64`的`0.221140`。空间上下文使2017 B_cell F1达到0.2429，但CD8_T和Treg在三个病例中均为0；2019仍几乎只预测Macrophage。因此该`reg64+xy+area+KNN+region token`候选拒绝，不进入fusion。结论是现有空间摘要不足以提供CD4/CD8/Treg的形态可分性；后续应考虑以细胞原始H&E视觉crop/更强细胞视觉编码器补充信息，而非继续调整同一`reg64`或邻域聚合。
