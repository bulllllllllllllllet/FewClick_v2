# CRC 扩量空间上下文身份训练

## 目的

纯`reg64`分类头的四种长尾策略均未达到五类可用门槛，尤其Treg不能兼顾precision与recall。本轮转向输入信息改造：在相同医生审核标签与H&E-only特征基础上加入细胞xy近邻、细胞面积及冻结Phase2区域token。

## 设计

- 复用已存在、已测试的`SpatialContextIdentity`：`reg64 + xy + log_area + xy-KNN(12) + frozen region token`；绝不输入mIF marker或身份标签。
- 使用当前1,553图块 pooled internal manifest，固定train/val；不使用类别权重、DRW、强制均衡采样或Balanced Softmax，以单独衡量空间上下文增益。
- GPU1，seed 20260915，最多60 epoch、patience12；先运行后以独立评估工具重算最佳checkpoint。

## 验收

必须超过当前DRW纯reg64的0.221140，并分别报告五类F1/precision/recall；Treg的非零结果需同时有合理precision。该对照仍是同病例内部图块验证，不能视作患者独立泛化或最终组织分割结果。
