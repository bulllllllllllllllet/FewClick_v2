# SAM高Dice的指标与任务条件核对

用户询问SAM Dice为什么高。本记录保持原实验协议和结果，不因排名更换任务或降低基线。证据：实际三seed SAM-FT各6040行、固定本图合同、SAM前向/训练器/metrics源码、已验收G5完整报告。数值与原行SHA存于/nfs-medical3/zyh/fewclick_v2/fair_comparison/scoring_explanation_1025_231900/audit.json。

## 算法与分母

每项是512×512图上的目标类二值分割：truth为labels==target，valid为labels!=255，prediction为概率>=.5。Dice=2TP/(2TP+FP+FN)，忽略未知255，TN不进入公式。对每个图像目标对先平均5组模拟点，再平均302对；三seed最后计算mean和ddof1样本std。212个查询视野可对应多个目标，共302对；主预算3正2负各1510行。图像目标pair宏平均不是类别宏平均、全像素micro，也不是WSI整片Dice。

首seed宏Dice .701859；若全图像像素计数汇总micro反而为.847757，报告没有采用这个更大的数。首行TP178713/FP15634/FN3558，Dice=.949041，说明具体像素代数含义；这是固定序列第一行，不是挑选的代表性精度案例。

## 会影响数字大小的已验证条件

1. .702063±.001325是SAM-FT：公共SAM ViT-B初始化后，同一CRC/TIGER训练池10k更新×4任务，前1k头预热/后9k联合，实际40k任务与FewClick一致；public零适配约.4505。两行训练条件不同，不能把.70称为原始SAM零样本表现。
2. 这是本图local：直接在待分割图上给3正2负GT模拟代表点，source=query；支持查询迁移R的query点为0、另表，不能交换结论。首seed1正1负.654306，3正2负.701859，5正1负.717850；更多提示的条件影响有实际数值证据。
3. 本图每项都含目标；无目标query的误报在R表单列。因此这个Dice没有同时考核全片找目标、未提示区召回或无目标误报。
4. 固定空间开发集用于每千步302对group0选checkpoint，最终5组仍是同一开发图像；不是独立病人盲测，五组点和三seed也不改变该事实。同病例可跨空间split是用户策略，4x视野隔离已审计，仍保留病例残余依赖。
5. 首seed CRC .663117，TIGER .805801，TIGER任务较高。不能将总体.70称每类/每域都.70。

## 正确性与归因边界

三seed所有SAM行Dice由TP/FP/FN再次重算一致；推理无class ID或query GT参数，候选按预测IoU argmax选择。GT用于训练损失、预先模拟提示和最终评分，训练IoU校准不等于测试GT挑候选。当前证据没有发现把背景准确率当Dice或GT挑最佳mask的问题，但全量预测mask没有重生/可视化，不能把计数验收扩大为全部推理零缺陷证明。

SAM与FewClick的公共预训练、容量、输入视野和可训练层不同：SAM联合更新image encoder全部参数，FewClick主干联合更新layer3/4；同40k预算不等于总预训练/计算/优化自由度完全匹配。可合理推测强先验和local任务适配帮助SAM，但未做隔离因果实验，不能单凭分数认定差距原因。应保留强基线、继续普通HE控制与远端/WSI任务验证，并可用预先声明的案例补预测可视化审计。

当前结果仅支持：在这套固定local开发任务及适配预算下SAM-FT更高，不能据此声称原始论文全部错误，也不能将.70替代原文不同数据/指标的分数。解释审计完成，不修改任何模型或已完成实验。
