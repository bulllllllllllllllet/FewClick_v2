# CRC混合病例身份训练

时间：2026-09-15 20:35:00。按项目负责人指示，不再按病例隔离，改为将三个CRC病例共同用于身份模型训练。

协议：从已完成的36图块identity contract建立确定性图块级内部划分；每个病例按稳定sample_id排序后保留2图块作val，其余10图块进入train。因此train和val均包含2017、2019、2022病例。该设置可增加五类可见训练样本，但同一病例同时出现在train/val，指标只能解释为**同队列图块级内部验证**，绝不解释为跨患者泛化或独立test性能。

输入不变：医生审核mIF转移的H&E reg64、冻结Phase2 token和v4 baseline。训练采用effective-number类别权重及稀有类图块重采样，统计仅来自该混合train图块；val不参与类别权重、抽样或梯度。

验收：manifest路径/hash唯一、每个split含全部三病例但图块不重叠；五类均在train出现；真实loader/loss/backward/checkpoint通过；报告内部val每类F1、macro-F1、Brier和ECE，并和此前病例隔离结果明确分开。

运行结果：`crc_pooled_identity_manifest_0915_203638/`生成30 train、6 val图块；每个病例分别为10/2图块。混合训练的加权重采样候选`identity_0915_203639/`最佳内部val macro-F1为0.249369；直接平均、无权重候选`identity_0915_203640/`最佳为0.253330（epoch 4），因此后者为本设置中较优候选。`evaluate_val_0915_203641/`确认三个病例内部val均只预测CD4_T和CD163_Macrophage，CD8_T/Treg/B_cell的F1仍为0；每病例macro-F1为0.179124/0.248573/0.332292。

结论：混合三个病例没有解决五类身份可辨识性，且该内部划分存在同病例泄漏，不能被视为泛化指标。它只证明“更多同队列样本”本身不够；当前单细胞H&E reg64表征无法稳定分出CD8、Treg与B_cell。该模型不进入Phase3 fusion。若继续五类任务，下一步需要改变输入任务为细胞+局部组织上下文/邻域组成，或使用与H&E配对的更大多病例身份队列，而非继续改变split或重复同一批细胞。
