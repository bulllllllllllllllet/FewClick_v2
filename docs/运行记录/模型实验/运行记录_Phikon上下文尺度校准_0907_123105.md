# Phikon H&E 上下文尺度校准

当前配准 H&E TIFF 没有可读 mpp，不能声称已经严格按 Phikon 的 20×尺度裁图。本运行用同一批 941 个 COAD Xenium 真实注释细胞，在 `64, 96, 128, 192, 256, 384` 个 H&E 像素的方形视野中分别提取冻结 Phikon CLS 特征；每种尺度均以相同空间四折训练线性分类器，并和 H&E—cell 行打乱对照比较。

输入的细胞边界与图像都经过同一局部坐标转换；attention Gaussian sigma 按视野线性缩放。尺度选择唯一依据是 paired H&E 相对 shuffled H&E 的正向、可复现增益，而不是仅挑最高单次 F1。

命令：

```bash
PYTHONPATH=/nfs-medical3/zyh/fewclick_v2/vendor/phikon-v2:$PYTHONPATH \
CUDA_VISIBLE_DEVICES=1 conda run -n aligner python \
benchmarks/v5/phase_3_cell_region/tools/calibrate_phikon_context_probe.py \
--device cuda:0 \
--output-dir /nfs-medical3/zyh/fewclick_v2/context_calibration/phikon_context_0907_123105
```

## 完成结果

有效运行产物：`/nfs-medical3/zyh/fewclick_v2/context_calibration/phikon_context_0907_123105/`。所有六种尺度均完成 941 个细胞的 `[941,1024]` 冻结 Phikon 特征提取和同一空间四折评估。

| H&E context（px） | paired macro-F1 | paired balanced accuracy | paired − shuffled macro-F1 |
| ---: | ---: | ---: | ---: |
| 64 | 0.2447 | 0.2505 | +0.0185 |
| 96 | 0.2249 | 0.2304 | -0.0216 |
| 128（旧设置） | 0.2340 | 0.2332 | +0.0030 |
| 192 | 0.2114 | 0.2104 | -0.0388 |
| **256** | **0.2691** | **0.2777** | +0.0110 |
| **384** | 0.2585 | 0.2648 | **+0.0226** |

结论：上下文尺度是实质性因素。256px 给出本轮最高 paired 分类分数；384px 给出最强的 paired-over-shuffled 证据。两者均优于旧 128px，因此后续验证应保留 **256px 与 384px** 两个候选多视野，而不是继续使用固定 128px。

限制：H&E mpp 仍未知；本表不将像素尺度误称为 20×物理尺度。并且这是一个 section、一个 shuffle seed 的筛选实验，下一步必须在多个 section、多个 shuffle seed 上复核，再决定正式 adapter 训练的视野配置。
