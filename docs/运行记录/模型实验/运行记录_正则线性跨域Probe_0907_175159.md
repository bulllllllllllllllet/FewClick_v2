# 正则线性跨域 cell probe

## 目的

重做中规模五 cohort 冻结 H&E 特征验证，避免高容量 MLP 在约 1,800 个训练细胞上记忆随机 H&E—标签配对，并避免将测试 cohort 不具备的类别计入该 fold 的主指标。

## 输入与设计

- 输入 cache：`/nfs-medical3/zyh/fewclick_v2/multisection_cell_feature_cache/multisection_cell_feature_cache_0907_162801/`，其中含 2,266 个细胞的冻结 Phikon 256px+384px、共 2,048 维 H&E-only 特征；RNA 不读取、不输入模型。
- 模型：`StandardScaler + L2 LogisticRegression(class_weight=balanced)`。每个 outer split 的真实训练配对以 train-only 方式从 `C∈{1e-4,1e-3,1e-2,1e-1,1}` 选择一次：有多个训练 cohort 时用内部 leave-one-cohort-out；仅一个训练 cohort 的跨平台 pair 用分层三折。这个 `C` 随后锁定并同时用于 paired 与 shuffled arm，避免负对照因重复调参而不公平。
- 每个 outer fold 只保留 train 与 test 都实际存在的 broad class；模型也只在这些共同类别上训练和计分。输出原始支持类别及被排除类别，不能将不同标签覆盖伪装为分类失败。
- 三种 protocol：`loco_all`（五 cohort leave-one-cohort-out）、`same_platform_cross_cancer`（仅 Xenium COAD/HCC/OV）和 `same_cancer_cross_platform`（COAD、HCC 各自 Xenium↔CosMx）。每种都有正确 H&E 配对和仅打乱训练 feature 行的负对照，各 3 个种子。

## 运行与验收

- 模块：`benchmarks/v5/phase_3_cell_region/tools/run_regularized_multisection_linear_probe.py`。
- 输出根：`/nfs-medical3/zyh/fewclick_v2/regularized_linear_cell_probe/`，本次完整运行时间戳为 `0907_180000`；CPU 运行，实时日志写入该根的 `logs/`。先前 `0907_175300_smoke` 已用真实 cache 跑通 Xenium 跨癌种的 3 个 split × 2 arms × 1 seed；`0907_175500` 在发现每 seed 重复 C 搜索造成无效计算后被主动停止，不作为结果。
- 监控：检查进程退出码、每个 split 的 cache identity、共同类别数、有限 feature、训练/测试 cohort 隔离及 metrics CSV。
- 接受条件：每个 protocol 的 paired 平均 macro-F1 和 balanced accuracy 都高于 shuffled，并报告 paired-minus-shuffled 的逐 seed 差异；否则只记录为未证明的 H&E 信号，不进入 LoRA 或大规模训练。

## 最终状态

- 完成，`tmux fewclick_linear_probe_0907_180000` 的 `EXIT_CODE=0`；所有 2,266 个 cache cell 的 ID/feature 检查、共同类别筛选、C 的 train-only 选择及 outer cohort 隔离均通过。完整 artifact：`/nfs-medical3/zyh/fewclick_v2/regularized_linear_cell_probe/regularized_linear_cell_probe_0907_180000/`。
- `loco_all`：paired macro-F1 / BA `0.1111 / 0.1361`，低于 shuffled 的 `0.1239 / 0.1473`，明确不通过。
- `same_platform_cross_cancer`（仅 Xenium）：paired `0.1243 / 0.1489`，高于 shuffled `0.1137 / 0.1344`；paired-minus-shuffled 的均值为 `+0.0106 / +0.0145`。方向上支持同平台跨癌种存在弱 H&E 信号，但只有 3 个 section，且逐 seed 波动仍大，不能据此启动大规模训练。
- `same_cancer_cross_platform`（COAD/HCC 的 Xenium↔CosMx）：paired `0.0985 / 0.1618`，shuffled `0.0981 / 0.1457`。虽然均值同时略高，但 macro-F1 差只有 `+0.0004`、12 个重复中仅 6 个为正，因此不能视为稳定跨平台泛化。
- 结论：线性 probe 排除了“高容量 MLP 记忆随机配对”这个主要混杂；冻结 H&E 特征在**同平台**时有很弱的正向迹象，但全 cohort 和跨平台均没有稳定证据。下一步不应直接扩大 LoRA/全量训练；应补充同一平台的独立 section/donor、统一细胞 annotation，再做相同共同类别线性 gate。
