# CRC空间上下文身份探针

时间：2026-09-15 21:25:01。

依据：已有`reg64`来自128像素细胞H&E crop及同组XCellFormer细胞集合交互，但XCell实际没有接收细胞xy坐标、相对距离、近邻图或Phase2 token；当前身份MLP也只读取`reg64`。因此本探针不重提取图像，而是使用现有contract的H&E-only信息补足显式空间上下文。

模型：节点输入为`reg64 + xy + log(area)`；用细胞对Phase2 64个region token的既有软归属求该细胞的区域上下文；在每个图块按xy构建K=12近邻，消息包含邻居表征、相对dx/dy和距离。标签、mIF强度、DAPI图像、marker及人工审核信息均不进入模型输入。

训练：采用用户指定的三个病例混合图块级内部划分（30 train/6 val），无类别权重作为与直接平均MLP的公平比较。验收为真实contract前向/反向/有限loss/checkpoint成功；内部val按类F1至少不再使CD8/B全部为0才保留候选。该结果不作为患者独立泛化或Phase3 fusion结论。

结果：`spatial_identity_0915_212502/`在GPU1完成24个epoch、`EXIT_CODE=0`，最佳内部val macro-F1为0.258831（epoch 11），略高于直接平均MLP的0.253330。`evaluate_spatial_val_0915_212503/`显示2019病例B_cell出现1个正确预测（F1 0.007692），但2017/2022的B_cell仍为0，CD8_T与Treg在全部内部val仍为0。因此未达到“CD8和B均非零”的候选门槛，不进入Phase3 fusion。

结论：现有`reg64`确实含有局部crop和同组细胞集合信息；显式xy近邻和冻结区域token有很小增益，但不能解决H&E单细胞对CD8/Treg/B亚型的可辨识性。下一有效尝试应是重提取包含更大组织范围的H&E视觉特征（而非继续从同一64维向量构造图），同时保留本空间结构分支作为辅助输入。
