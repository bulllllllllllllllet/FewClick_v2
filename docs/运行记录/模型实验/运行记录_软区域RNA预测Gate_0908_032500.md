# 软区域 RNA 预测 Gate

## 目的

在真实 Phase 2 soft assignment 契约已通过后，检验冻结 H&E region token 与按相同
assignment 汇聚的 H&E cell context，能否预测对应的区域 RNA program。RNA 永远不是
输入；本 gate 只决定是否值得实现 Phase 3 的 RNA auxiliary head。

## 输入、对照与边界

- 输入 cache：`/nfs-medical3/zyh/fewclick_v2/region_rna_target_smoke/region_rna_target_smoke_0908_032000/`。
- 9 个 512px H&E patch；每 patch 64 个 Phase 2 token，H&E cell context 由真实
  `assignment_at_cells` 加权汇聚。
- target：8 个固定哈希 gene-bucket program；target 的 gene membership 不从 test patch 拟合。
- `paired_rna_target`：用正确 token-RNA 对应关系训练 ridge prediction head。
- `shuffled_rna_target`：仅在每个训练折内打乱 RNA target 行；测试始终对真实 RNA target 评分。
- 以 3×3 patch 的四个空间组 GroupKFold 留出；样本只有 9 patch，结论仅限这个机制 gate，
  绝不解释为跨 section、跨癌种或 FewClick 分割结果。

## 命令与验收

`conda run -n aligner python benchmarks/v5/phase_3_cell_region/tools/run_region_rna_prediction_gate.py --contract-dir /nfs-medical3/zyh/fewclick_v2/region_rna_target_smoke/region_rna_target_smoke_0908_032000 --timestamp 0908_032500`

输出：`/nfs-medical3/zyh/fewclick_v2/region_rna_prediction_gate/region_rna_prediction_gate_0908_032500/`。

验收：所有 feature/target 有限、train/test spatial group 隔离；paired target 的 held-out
`R2_vs_train_mean` 必须高于 shuffled target。通过只授权下一步实现 Phase 3 auxiliary
head 的 smoke，不代表可替换 v4 或提升下游分割。

## 完成结果

运行完成，`EXIT_CODE=0`；四个 spatial group 均与训练 patch 隔离。H&E feature 为冻结
Phase 2 256 维 token、按相同 assignment 加权的 74 维 H&E cell context，以及 RNA-cell
coverage，共 331 维；RNA 不作为输入。

| Arm | normalized MSE（mean ± std） | R2 vs train mean（mean ± std） |
| --- | ---: | ---: |
| paired RNA target | 0.628509 ± 0.256297 | 0.371491 ± 0.256297 |
| shuffled RNA target | 1.014517 ± 0.019426 | -0.014517 ± 0.019426 |

paired 相对 shuffled 的 mean R2 为 `+0.386008`，通过本 gate。解释限于“当前 9 个 COAD
patch 的冻结 H&E region/cell representation 含有与正确区域 RNA program 对应的信号”；
它不是 FewClick segmentation 提升，也不能解释为跨 section 泛化。下一步可检验真正的
`CellToRegionAttention + RNA head` 训练路径。
