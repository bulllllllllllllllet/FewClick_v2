用户授权：检索近期远端迁移论文，并选一个试验。沿用same-WSI、支持与query不同patch且full4x不重叠、固定支持点/零query人工点，不恢复cross-slide/SAM3或额外seed。当前WSI自动点桥继续，新增一个只读推理候选，不新训练。

检索核验（2026-11-09）：
- SANSA，NeurIPS2025，https://proceedings.neurips.cc/paper_files/paper/2025/hash/ac6ab84809cef04dbe11e9b80d63c281-Abstract-Conference.html ，https://github.com/ClaudiaCuttano/SANSA 。原生参考图到query语义迁移，Universal支持点/框/涂鸦/mask；论文benchmark checkpoints以mask为主。本试验固定Universal，不冒充论文mask benchmark复现，不按本数据成绩挑checkpoint。
- FSSAM，ICML2025，https://proceedings.mlr.press/v267/xu25an.html ，https://github.com/Sam1224/FSSAM 。伪query memory/迭代精炼/支持校准，原任务支持mask，不能把完整支持mask当同点击预算。
- Segment Any Tissue，Medical Image Analysis2025，https://doi.org/10.1016/j.media.2025.103550 ，作者仓库https://github.com/XueyuLiu/Segment-Any-Tissue 。医学参考自动提示；完整代码/支持注释可用性仍待核，不首选。
- V²-SAM，CVPR2026（官方仓库标注），https://github.com/jaychempan/V2-SAM 。跨视角同一物体实例对应，非同类不同组织区，且涉及DINO额外底座，次选；不因更新就优先错配任务。
- Conditional Point Sparsification，2026-02-05 arXiv，https://arxiv.org/abs/2602.05218 。跨域参考匹配点稀疏化，文中使用参考GT mask，代码可用性未核，不称已复现。
- 当前SAM1=2023底座，SAM2.1=2024系列；WSISAM是病理专用参考，不是新一代通用SAM。官方SAM3 repo已出现2026-03 SAM3.1：https://github.com/facebookresearch/sam3 。用户此前取消该臂，本轮仅说明代际，不恢复下载/运行。

决策：优先SANSA Universal。它直接解决参考图语义迁移且支持稀疏点，减少自建迁移桥偏差。固定官方public weights，zero target updates，披露通用数据adapter训练和fine单视野/原生1024编码，与本组等2000新增适配预算轨分开。支持原相同3正2负；负点直接传原生point_labels=0（官方示例仅正点，但接口支持label），须真实检查。queryGT只评分，完整支持GT不得进入推理，不用queryGT构造候选/选阈值。

有界试验：先权重与接口实际门控，再11类每类10任务（4大面积present/3其它present/3absent，SHA固定排序、少量不足按固定顺序补齐），总110。从现有11000同片任务取样，逐任务保留原支持点击，不按任何预测选样。固定logit>=0，保存全部mask，独立重读GT评分，报告全类别/面积>=20%/absentFPA及同110任务Few/SAM1/SAM2/WSI现成mask配对结果。范围是工程/小样本参考，不做泛化或胜负宣告，不自动扩11000。失败保留日志不静默用mask或别权重替代。
