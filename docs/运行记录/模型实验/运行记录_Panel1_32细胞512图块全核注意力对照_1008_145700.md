# Panel1 32像素细胞＋512像素图块全核注意力对照

- 问题：32像素目标核视野在单病例空间验证集略优于128，但补充测试集未稳定提升；加入整块512像素形态、并与该图块所有H&E检测细胞作cross-attention，能否改善五类识别。
- 既有实现边界：`train_crc_panel1_patch_attention.py`只在已抽样清单内取最多16个同图块邻居；本轮同名单717个图块的mask实际有266,574个检测核，必须区分“已标注邻居”和“全图块检测核”。
- 输入：`panel1_small_cell_crop_full_1008_143551/cells.csv`固定3,177目标细胞及其32/128冻结CTransPath特征；原2019注册H&E PNG、HE核mask、主清单和补充清单的源hash；空间split不变。输入仅H&E和几何，不把邻居mIF标签给模型。
- 特征准备：逐图块对全部检测核取以核中心为轴的32px裁剪，沿用目标核soft-attention和同一冻结CTransPath-768，另对完整512px H&E缩放224抽一条CTransPath-768全局特征。每图块保存HE ID、中心、全部细胞特征和整图特征。严格核对已选目标HE ID/中心与缓存一致；跨四个空闲GPU按图块哈希分片，先做真实图块smoke，再跑全量。生成物只放在NFS3 FewClick根下，源图只读。
- 分类对照：同一3,177目标细胞、train上限每类300、固定val/test/均衡补充清单，比较①目标32特征、②目标32＋512整图全局特征、③目标32＋512全局特征＋对全图块其他检测核32特征的cross-attention。对③另做同参数但打乱邻居位置或置零上下文的控制，避免将额外参数误认为有效上下文。只用原val选checkpoint，均衡补充test主要检查是否复现。报告macro-F1、accuracy、逐类F1及全部邻居数分布。
- 防泄漏：每图块只属一个空间split；所有预处理的可学习参数和分类头仅在train拟合，邻居仅为该图块H&E检测结果，不输入mIF身份、类别或其它split细胞特征。717图块及补充清单哈希固定。
- 资源与输出：特征分片`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_fullpatch_cell32_1008_145700_shard{0,1,2,3}`，GPU1/3/4/5各1张、CPU各4线程；tmux分片日志和`EXIT_CODE`。融合训练与评估输出另用同时间戳目录，GPU1/3；预计特征提取较长，监控实际worker PID与每分片完成计数。
- 验收：真实smoke中核裁剪与32缓存特征一致、512编码有限、逐图块所有核ID唯一且目标全覆盖；全量每分片的图块数/细胞数相加与独立mask库存一致；三臂同名单可训练、有限loss、无邻居泄漏，结合补充测试集判定是否有实际收益。未达到前不替换现有Panel1/Phase3。
- 真实图块smoke：`x10240_y14336`有329个检测核、3个已选目标，已选目标的新旧32px特征余弦相似度均≥0.9999999，最大绝对差≤0.00041；512px特征形状768且有限。输出`panel1_fullpatch_cell32_smoke_1008_151500`。
- 全量执行：四个分片已在`tmux`会话`p1cell32_1008_145700_s{0,1,2,3}`启动，GPU 1/3/4/5，真实Python worker PID为2295078/2295085/2295149/2295213；各分片逐图块写NPZ和`progress.jsonl`，日志同名前缀`.log`，末尾追加`EXIT_CODE`。
- 特征缓存验收：四个`audit.json`均完成、日志`EXIT_CODE=0`，共717图块、266,574检测核，数量与独立mask库存相同。`panel1_fullpatch_cross_attention_smoke_1008_151000`用全量缓存完成三臂各1 epoch，包含真实模型反传、原val选择及两套测试评估，所有loss和结果有限。
- 正式训练：`tmux`会话`p1fullattn_1008_150718_s{11,23,47}`分别在GPU 1/3/4上以seed 11/23/47训练；每个会话最多40 epoch、验证集macro-F1早停10 epoch，输出`panel1_fullpatch_cross_attention_1008_150718_seed{11,23,47}`与同名前缀`.log`，末尾追加`EXIT_CODE`。
- 训练结果：三个日志均`EXIT_CODE=0`，每个种子都使用相同3,177目标、717图块和266,574核缓存；目标可见其他核的中位数为362，范围9–876。对照输出`panel1_fullpatch_cross_attention_1008_150718_seed{11,23,47}`，模型及逐细胞预测均已保存。

- 同输入线性补充对照：`probe_crc_panel1_patch512_linear.py`采用train-only StandardScaler、balanced LogisticRegression(C=1)，输出`panel1_patch512_linear_1008_151145`。两臂在原test明显下降0.0617；补充test macro-F1虽增加0.0068，但accuracy下降0.004，且原val macro-F1下降0.0430，不能判为稳健提升。逐类补充test中淋巴内皮F1从0.283升到0.516、CAF从0.209升到0.286，但血管内皮从0.327降到0.170、SMA从0.492降到0.378，属于类别间转移。
- 注意力消融：三种子在补充test上把已训练模型的邻居上下文置零后，macro-F1分别为0.1771/0.2061/0.2731；保留上下文为0.1614/0.2112/0.2722，没有一致收益。原test也没有稳定收益。
- 判定：该单病例、弱标签、有限训练目标的设置下，512整图和全核注意力均未带来稳定识别增益；不替换当前32px线性基线，更不将其直接接入Phase3。完整512缩到224的冻结编码可能丢失细粒度信息，且当前训练目标仅1,359个；结果不能外推为更大数据或更合适编码器下注意力无效。
- 状态：全量特征、三随机种子训练及线性对照均完成。
