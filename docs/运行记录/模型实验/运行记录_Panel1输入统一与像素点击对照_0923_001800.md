# Panel1 输入统一与像素点击对照

- 时间戳：0923_001800；代码起点：1ad589b。依据：0922 Panel1 组成训练、联合 gate 及用户要求修正数据取样和实际评估。
- 问题：此前单病例24条CRC取样、缺失类别编码为0、仅region accuracy且未保存权重，不能回答像素与点击收益。
- 调整：双方74维输入的面积及类别通道2:10显式屏蔽，只用共同的坐标和64维HE特征，原缓存只读；不是推断未知类别。三例CRC在原有空间split内按病例/空间组覆盖取样，train额外按主要组成类别分散取样；固定GDPH清单与数据seed，模型seed独立；检查实际10x输入footprint缓冲隔离。既有预训练区域暴露仍未知，历史val仅内部诊断。
- 对照：seg_only、joint_003、joint_010、panel1_pretrain、seg_budget。所有臂同初始化、相同主任务步骤；pretrain先按新输入协议训练Panel1再训练主任务，seg_budget增加等数主任务步骤用于预算对照（不是等FLOPs）。不直接载入旧协议Panel1权重。
- 指标：12类像素macro Dice/IoU与逐类值；固定旧Phase5和Phase6 graph decoder，在当前Phase3特征上运行真实像素正负点击。首轮1正1负固定，随后在最大错误内距处按同一规则追加点击；报告总点击2/4/6的Dice/IoU、NoC@0.8/0.9（最大6，失败记7并单报失败率），排除已点像素。点击模拟读取GT，明确oracle；无Phase4上下文，属于fine-only兼容性诊断，不代表完整生产模型。
- 训练/选择：固定步数末次checkpoint，不依据val选择配方或模型。保存、重载核对权重；记录初始指标、CRC训练常数先验、训练日程hash、输入hash与所有配置。test不读取。
- 计算：GPU1，aligner，先真实两步完整路径smoke；通过后3seed，GDPH train96/val48，CRC每例train24/val12，主任务200步、pretrain/额外预算200步。
- 输出：/nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_controlled_<timestamp>/。长任务用tmux与EXIT_CODE日志，报告worker PID。
- 验收：输入协议/清单隔离/有限loss/权重重载/保存mask复算通过；报告全部臂，即使主指标下降也执行点击评估。收益只在配对验证中判断，不预设必须上涨。
- 风险与替代：冻结特征和旧点击头可能限制迁移；若无收益，下轮再单独比较可训练图像adapter，不能把它与本轮修复混合归因。区域组成不可充当组织边界真值。
- 状态：实现与冒烟中。
