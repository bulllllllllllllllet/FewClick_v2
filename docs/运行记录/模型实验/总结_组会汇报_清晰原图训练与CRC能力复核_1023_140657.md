# 组会汇报：FewClick v2清晰原图重训练与CRC能力复核

更新时间：2026-10-23。建议拆成以下6页；仅总结已完成结果，不启动新训练。

## 第1页：本轮目标与结论

目标：减少低分辨率输入及人工降质对组织分割训练的干扰，在扩展组织来源的同时保留原CRC能力。

本轮完成：训练数据清晰度筛选、三源原图20k重训练、验证范围同步清理、主验证真实回放，以及CRC同点击条件回归。

核心结论：**在统一代表性点击下，新模型CRC同图Dice为0.8249，与历史模型0.8237基本持平；三源原图主验证Dice为0.5889，较上轮0.5859略升，但跨图匹配仍是主要短板。**

这两个分数来自不同任务，不能串成一条提升曲线，也不能将0.8249称为多域或跨WSI整体成绩。

## 第2页：数据调整——只使用有足够原生细节的原图

问题：相同512×512尺寸、相同目标MPP，并不代表原图含有相同细节。OCELOT tissue原生约0.778µm/px，插值到0.5无法恢复细胞细节；上一轮还使用0.8/1.0µm/px人工降质版本。

本轮规则：训练仅保留original；文件可用MPP、实际网络输入MPP和渲染质量MPP的最大值≤0.6µm/px。该阈值为本实验筛选规则，不是通用失焦检测标准。

| 数据源 | 保留训练视野 | 处理 |
|---|---:|---|
| CRC | 37,230 | 原质量保留 |
| TIGER | 1,246 | 原质量保留 |
| IGNITE | 1,072 | 原质量保留 |
| 合计 | **39,548** | 单一original版本 |
| OCELOT | 0 | 排除3,574个训练视野 |

- 取消全部人工0.8/1.0降质训练版本，原始文件和历史缓存保留。
- 输入仍为512×512、约0.5µm/px，约256µm物理视野；实际主验证输入约0.49975–0.50006µm/px。
- 主验证同步排除OCELOT和人工降质，使用三源original的固定360个支持—查询任务，216有目标/144无目标。360是任务数，不是独立图像数。
- 原三源全部质量720任务另作挑战报告；原四源960仅保留历史记录，不再作为本轮主评价。
- 分辨率筛选不等于排除了全部失焦图；本轮没有用任意锐度阈值删除可能具有生物学意义的组织。

## 第3页：模型与训练设置

架构沿用fine_only J5+dense128，没有增加新模型分支：

```text
支持图像＋细胞特征＋正负点击 → 目标任务token
查询图像＋细胞特征 → 区域tokens
目标任务token与查询区域匹配 → 粗分割
粗分割＋深浅层图像特征＋任务条件 → 稠密解码 → 512×512结果
```

图像骨干为DeepLabV3-ResNet50；64个软区域、256维token。细胞实例由既有InstanSeg流程缓存，细胞融合参与训练；未启用完整多尺度父层上下文。

| 项目 | 本轮设置 |
|---|---|
| 初始化 | 从与前轮相同的原始J5+dense权重重新训练，不接退化终点 |
| 训练预算 | 20,000更新，全局batch4，共80,000动态任务 |
| 阶段 | 前2k暖身提示/细胞/解码，后18k联合更新骨干layer3/4与区域编码 |
| 学习率 | 头部1e-4、骨干1e-5，升温＋余弦衰减，BN统计冻结 |
| 训练任务 | 同图、同片/ROI异位置、跨片/跨图，以及查询不含目标的任务 |
| 点击 | 支持GT模拟1–5个正点及1–5个负点，采用代表性内部采样 |
| 损失 | BCE＋Dice＋2µm边界带，以及支持点/支持区域约束 |
| 资源及耗时 | 四卡训练，约1小时51分钟；20k及后续评估均已完成 |

采样中CRC/TIGER/IGNITE按原保留相对权重归一为37.5%/31.25%/31.25%；有放回抽样，80,000任务不等于80,000张独立图像或全池完整遍历。背景不作为正目标，但仍可作负证据。查询GT不进入模型，跨图时支持点坐标不复制到查询图。

本轮同时改变了数据来源和质量版本，属于联合干预；没有第二seed，不能分别声称移除OCELOT和取消降质的独立因果收益。

## 第4页：三源主验证——小幅改善，尚非稳定大幅提升

固定相同360任务、相同图像/GT/3正2负代表性点击、相同阈值，两轮均按新主范围重汇总全部10个检查点，并选中20k。

| 指标 | 上轮代表性点击20k | 本轮清晰原图20k |
|---|---:|---:|
| 原质360 Dice↑ | 0.5859 | **0.5889** |
| 原质360 BF1@2µm↑ | **0.3272** | 0.3164 |
| 原质无目标平均误报面积↓ | **7.97%** | 8.36% |
| 三源含降质720 Dice↑ | 0.5804 | **0.5826** |

结论：Dice约提升0.29个百分点，但边界和平均误报没有同步改善。主Dice按query空间块bootstrap的95%差值区间为[-1.88,+2.41]个百分点，区间跨0，不能宣称稳定显著提升。

已实际重新加载两权重各跑360任务，计数与归档逐例一致；同时核对了720份支持/查询MPP元数据、GT点符号和查询目标存在性，未发现分数汇总错误或低分辨率输入重新混入主验证。默认验证/扩展入口也已修复，防止重新引入OCELOT和降质版本。

## 第5页：关键发现——CRC能力结论依赖点击协议

此前CRC约0.69采用早期spread随机内部点。新训练和当前产品意图采用代表性点击，二者不能混为同一使用条件。因此补充了同一批CRC图像、GT、legacy细胞、相同点数的四权重对照；主评分排除93个背景正目标，保留931个组织任务。

| 权重 | 旧随机内部点Dice | 当前代表性点击Dice，统一size1 |
|---|---:|---:|
| 历史J5+dense | 0.6443 | **0.8237** |
| 旧多域C3 | **0.7271** | 0.7978 |
| 上轮代表性训练20k | 0.6904 | 0.8209 |
| 本轮清晰原图20k | 0.6900 | **0.8249** |

**正确解释：当前代表性点击条件下，新模型保住了历史CRC同图分割水平；早期随机点兼容性仍有下降。** 新模型与历史模型的同代表性点击差值约+0.11个百分点，105空间块区间跨0，应表述为基本持平。

- 表中只能同列比较模型，不能用跨列差值当作训练收益；也不能将新0.8249与旧历史质心协议0.8034直接比较。
- 原始size对照同样基本持平：历史0.8250、本轮0.8247；不支持size条件是大差值主因。
- 此CRC对照仍是GT模拟点击，沿用历史1–7正点/1–3负点预算及旧CRC/legacy细胞输入，不是人工交互验收或新版统一细胞输入总分。
- 先前“CRC能力未恢复”的概括过重，应修正为“旧随机内部点协议兼容性未恢复”。原随机点结果不删除。

## 第6页：当前瓶颈与下一步

主360按任务关系分层：

| 任务关系 | 上轮20k Dice | 本轮20k Dice |
|---|---:|---:|
| 同图 | 0.7050 | 0.7040 |
| 同源异位置（同WSI或同ROI） | 0.5213 | **0.5599** |
| 跨WSI或跨图像 | **0.5315** | 0.5028 |

结论：清晰原图重训练的收益主要体现在部分同源迁移任务，跨图任务没有同步改善。组间任务组成不同，不能把差值全归于跨片一个因素。

后续优先检查：

1. 支持样本能否覆盖查询组织的多种外观，按来源/目标类别/面积分层定位迁移失败。
2. 负点组织选择、代表性点与非典型点兼容；明确区分改善用户式点击和损失旧随机点鲁棒性。
3. 查询不存在目标时的拒识，联合检查Dice、漏检和误报。
4. 后续再做人工点击、统一细胞输入CRC及完整WSI/未见域验证，当前不宣称泛癌种已解决。

本轮没有自动替换部署权重，也没有启动下一轮训练。

### 可直接口述的结尾

> 本轮针对低分辨率数据干扰，去除了OCELOT tissue及人工降质版本，完成三源清晰原图20k重训练。统一验证范围后，三源Dice小幅提高，但跨图任务仍不稳定。进一步发现，此前CRC低分与旧随机点协议有关：在当前代表性点击下，新模型Dice为0.8249，与历史模型0.8237基本持平。因此当前重点应从笼统的CRC能力遗忘，转向提示—查询迁移及不同点击方式的兼容。
