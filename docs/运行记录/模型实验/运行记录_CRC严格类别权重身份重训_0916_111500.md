# CRC严格类别权重身份重训

时间：2026-09-16 11:15:00。

问题：扩量纯`reg64`身份训练中，原`effective_num_beta=0.999`对四个数万级类别饱和为近乎同一权重，未实际平衡CD8_T/B_cell与CD163_Macrophage。

方案：保持1,553图块、固定train/val划分、输入`reg64`、模型、随机种子和验证协议不变；仅将identity loss改为严格train-only inverse-frequency权重。权重与训练类别数成反比，并归一化为均值1，因此每个类别在全训练集的加权损失总质量相同。没有权重截断、没有伪标签、没有使用val计数，也不改变图块采样。

输入：`crc_pooled_identity_manifest_0916_110200/manifest.json`，train五类计数为44,210 / 39,492 / 1,731 / 31,214 / 282,920。对应权重会写入checkpoint metadata，验收时验证`weight × count`五类相等。

计算与验收：GPU 1，30 epoch、patience 5；先执行1 epoch真实训练冒烟，再正式训练和最佳checkpoint独立val评价。必须报告五类F1、recall、support及混淆矩阵；若CD8_T/B_cell/Treg的train与val仍近零，才能将原因从“原权重失效”进一步收敛到特征/任务本身。

## 运行结果

1 epoch全量冒烟`identity_0916_111600/`和正式训练`identity_0916_111700/`均为`EXIT_CODE=0`。正式训练于epoch 6提前停止，最佳checkpoint为epoch 1，patient macro-F1=0.189506；独立val重评估`evaluate_val_0916_112000/`与checkpoint/manifest指纹一致。

严格逆频率权重确实改变了少数类输出：CD8_T从F1=0/recall=0提升到F1=0.043621/recall=0.028495；B_cell从0.004007/0.002033提升到0.064000/0.044715；Treg从0/0提升到0.018648/0.603774。但Treg在仅53个val真实细胞上预测了3,379个细胞，表明严格等质量权重严重过预测Treg；同时Macrophage F1从0.767075降至0.436235。因此该运行证明上一轮权重确实失效，却不证明“严格全逆频率”可作为最终训练策略。

结论：下一步需在train-only数据中调整为受控的温和权重（例如inverse-square-root或Treg单独上限）并比较逐类precision/recall，而不是只看macro-F1；也应将细胞级平衡抽样作为独立变量。当前模型仍不能进入fusion。
