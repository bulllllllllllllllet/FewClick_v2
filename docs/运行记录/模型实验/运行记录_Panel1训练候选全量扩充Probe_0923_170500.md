- 问题：评估训练区域中尚未进入清单的基础合格候选全部加入训练后，少数类和MLP泛化是否改善。
- 输入：固定Panel1清单、训练空间组内未使用匹配patch；val/test及其补充清单保持完全不变。候选需通过接受匹配、距离≤4px、128安全边界、HE核mask存在及质心一致性检查。
- 规模预估：当前train 8,764个；基础候选上限13,937个，最多新增约5,173个。最终以去重和核mask复核后的manifest为准。

- 验收：train新增细胞不跨入val/test空间组；manifest无重复全局坐标；源hash和mask检查通过；比较扩充前后的少数类召回、macro-F1和补充test结果。
- 输出：`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_train_all_0923_170500/`及后续特征/评估目录。
