# FewClick第二版训练与区域提示检查总结

整理日期：2026-10-21。对应用户目标：使用少量正负点击指定组织示例，在本片其他位置乃至其他片上找到相同目标；提高多器官适应性、分辨率鲁棒性和轮廓精度。以下把不同评测协议分开，所有数字均为开发验证，不能代替未见癌种或整片盲测。

## 1. 当前做到哪里

- 数据标准化、三质量图像和InstanSeg细胞缓存已完成。
- 200步入口门控、四组2k短筛、四组20k正式训练均已完成；20k四组全部退出0、检查点重载输出一致，当前没有这一轮训练在等待完成。
- 多器官/质量增强在固定开发任务上有效；C3是当前多域训练候选，C0是CRC专训控制。
- 已完成原CRC1024回归和同图/同点击拆因。此前直接拿历史0.8034与新0.6683比较“遗忘”的解释不成立，因为两者解释提示坐标的方式不同；组织目标应使用下文匹配协议的分数。
- 用户已明确背景不作为正目标：主CRC范围固定为931个组织任务，93个背景正目标另作历史归档；组织任务中的背景像素仍是负例，目标缺失query仍评估误报。训练原本已如此，不需为背景补训。
- 本次新增检查“最近质心单区域／点击处归属最大单区域／点击处区域特征软混合”，只做推理对照，结果见末节；未自动切换部署或启动下一轮训练。

## 2. 当前模型和交互含义

```text
支持图像（RGB + 细胞） → 图像编码、软区域划分、细胞注入 → 区域tokens
正负点击 → 读取区域示例tokens → Prompt Encoder → 本次任务token
查询图像（RGB + 细胞） → 独立编码为区域tokens
任务token + 查询区域tokens → 区域匹配、图结构细化 → 粗概率图
粗概率图 + 深浅层图像特征 + 语义上下文 + 任务条件 → dense128 → 像素mask
```

- 基础仍为原J5区域/细胞/提示/图解码系统，加已验证有效的dense128稠密解码；本轮没有更换成一个新大模型。实际选中的实现是`fine_only`，跨尺度父上下文未开启，不能写成已完成全WSI多尺度联合训练。
- 支持与查询可以是同patch、同WSI不同patch、不同已核实WSI；远端query不接收支持点的空间热图。图里的裁剪框不是输入提示，真正提示是支持图上的正负点。
- **三种提示读取都用整块区域特征**：旧centroid选最近区域中心；当前soft按点击位置的assignment混合区域tokens；新hard对照取该位置归属最强的一块区域。当前soft仍是“点击指定组织示例”的实现，不是读取一个RGB像素作为表征。
- 训练时更新的图像特征、task和粗图在线重算，不能使用固定旧缓存冒充端到端训练。细胞缓存保存实例几何及图像预测特征；细胞融合层仍可训练。
- 当前细胞74维为几何3维、核身份7维、图像预测XCell特征64维；新版核身份统一unknown，64维不是实测RNA。

统一输入512×512，目标约0.5µm/px、视野约256µm。原质及0.8/1.0µm/px等效细节版本保持同一物理视野，再送入相同尺寸模型；这属于清晰度/可用分辨率增强，不是三张独立组织图。

- 尺度审计更正：原CRC文件约0.25MPP，但原loader把1024原生像素缩放到512，**实际模型输入为0.5027–0.5277MPP**；新版约0.5MPP。不能把原文件倍率直接当模型倍率，再把CRC差异解释成×2尺度错误。物理标准化仍有助于不同来源，但不是已证明能独自解决全部跨域问题。
- 按用户既定策略不强制患者互斥；已知同WSI/ROI跨split物理输入范围检查无重叠，质量变体同split。结果是同队列空间开发验证，历史初始化的区域暴露不能通过新split声明抹去。

## 4. 训练设计与实际执行

| 阶段 | 内容 | 状态与结论 |
|---|---|---|
| 旧边界主线 | J5增加稠密解码，匹配96k更新 | 历史区域提示协议Dice0.7274→0.8034、BF1@2px0.3290→0.5570，是此前主要提升 |
| 后续结构尝试 | 点细化/边界目标、多层特征、逐点交互、SegNext适配与延长 | 部分边界小幅收益，均未通过既定联合替换门槛；没有取代dense128，SegNext按用户决定停止 |
| 新训练门控 | 200更新×有效batch4 | 约172秒完成，真梯度、有限loss、保存/重载等通过；只验证可运行，不作最终效果结论 |
| 四臂短筛 | 各2,000更新，固定160开发任务 | 全完成，约21.5–23.5分钟/臂；有波动及误报取舍，继续长训 |
| 四臂正式长训 | 各20,000更新，固定960开发任务 | 全完成，约197.5–213.9分钟/臂；四臂并行，各卡一臂 |
| 训练后审计 | CRC1024、提示/细胞/size拆因、背景口径统一 | 已完成；本次追加同点击三种区域读取对照 |

20k四臂从同一原始最佳J5+dense初始化，**不接各臂短筛挑出的权重**。每臂有效batch4，即80,000个动态任务；前2,000更新暖身细胞/提示/解码，后18,000联合更新骨干layer3/4和区域embedding/assignment；BN统计冻结。head最大学习率1e-4、骨干1e-5，各自200步升温，联合阶段余弦衰减至0.1倍。

训练按CRC/TIGER/IGNITE/OCELOT=30/25/25/20采样，源内器官和目标平衡；任务占比为本地30%、同来源有目标35%、跨来源有目标15%、同来源无目标14%、跨来源无目标6%。准确地说，跨来源由实际来源元数据决定为cross_wsi或cross_image，不把所有跨图像都叫跨WSI，也不把不同数据集标签硬并成统一癌区。

支持GT模拟1–5正/负内部点击，距组织界面2µm；固定开发任务3正2负。模型不接收query GT或目标类别ID。损失含有效像素平衡BCE+Dice、2µm边界带项，另加支持点约束与远端支持监督；空目标用BCE和低概率惩罚，不强行要求每个query存在前景。

**全量池不等于全遍历**：C2/C3实际见到22,318/43,122个独立query视野、20,181个支持视野。其中CRC16,754/37,230（45.0%），TIGER1,243/1,246，IGNITE1,063/1,072，OCELOT3,258/3,574；平衡有放回采样使小源接近遍历，CRC尚有大量未用图像。80k不能写成80k独立图像。

## 6. 旧0.8与现在CRC结果应如何理解

旧0.803416是1,024个CRC任务的逐任务Dice算术平均，使用GT标记区域生成的历史质心提示，含93个背景正目标；micro Dice为0.858616，是另一个聚合口径。按现在排除背景正任务的统一规则，该**历史协议**为931例Dice0.802989、BF1@2px0.536903。

历史区域质心不保证落在区域内部：4,051个历史点若按像素含义解释，有671个（16.56%）与其正负符号不符。因此同坐标从centroid换成assignment读取并非同语义任务，不能直接用旧0.8034减新0.6683说“真实点击下降13.5点”。所有旧数字保留为兼容性档案。

匹配真实点击的比较统一原RGB、GT、细胞、视野、正负点数、size条件，并在GT内部固定点，使用当前soft读取；931个组织任务如下。

| 权重 | 同准确点击的组织Dice | BF1@2px | 肿瘤上皮Dice |
|---|---:|---:|---:|
| 原J5+dense | 0.6443 | 0.4621 | 0.7276 |
| C0：CRC专训 | **0.7534** | **0.5301** | **0.8735** |
| C3：多域训练 | 0.7271 | 0.4893 | 0.8133 |

C3比匹配的原权重Dice提高8.29个百分点，105个空间块配对bootstrap95%区间[+6.18,+10.46]个百分点；比C0低2.63个百分点，是需要继续改善的CRC/多域取舍。该旧输入检查与新版960多域任务的数据/采样也不同，不把0.7271和0.5845直接当同一成绩。

已排查：旧模型缓存精确回放0误差；准确点符号正确；未发现本检查中的x/y翻转或×2倍率错误；核身份unknown单因素、同图InstanSeg替换、size_id控制均不支持解释原跨协议的大差值。这个结论仅限所查条件，不能推成细胞检测质量等价或所有器官问题已排除。

## 7. 本次同点击区域读取检查

已完成931例×3权重×3读取=8,379次预测。相同图像、GT、细胞、准确点击、预算和size条件；既有centroid/soft所有预测mask及指标与前次保存结果逐例完全一致，hard mask落盘回读计数通过。3项新区域读取测试加原25项测试，共28项通过；真实11例门控后四卡正式检查均完成，约80–82.5秒/分片。

| 权重 | 最近区域中心Dice | 点击处最大归属单区域Dice | 当前软混合Dice |
|---|---:|---:|---:|
| 旧J5+dense | 0.5087 | 0.6276 | **0.6443** |
| C0：CRC专训 | 0.4704 | 0.7421 | **0.7534** |
| C3：多域训练 | 0.4806 | 0.7112 | **0.7271** |

C3对应BF1@2px为0.3677/0.4832/0.4893；hard相比soft Dice下降1.59个百分点，105空间块配对bootstrap95%区间为[-2.36,-0.88]个百分点。**现有权重下，直接换成单一区域读取没有提升，保留当前soft。**这只是推理读取消融，C0/C3原本用soft训练，不能据此断言专门匹配hard重新训练也一定更差。

C3的3,722个有效点中，最近质心和点击处最大归属只有35.30%选中同一区域；说明不规则/分散软区域的质心距离不能代替点击处归属。最大归属权重均值72.07%，熵对应有效区域数均值2.53；soft主要汇聚少数相关区域，并非把全图所有区域平均。hard区域在GT组织上的平均纯度略高却未带来分割收益，纯度诊断不能直接当改法有效的证据。

这不否定旧0.8：旧提示本来就是已选区域的质心，用最近质心读取是匹配其输入合同的；这里的0.4806使用真实内部点，不能与旧历史协议混比。用户“先选目标组织，用点击代表它”的交互逻辑保持，具体区域读取当前以soft实现。

## 8. 下一步的优先顺序

1. 保留当前点击处soft读取，不把直接换hard作为下一轮主优化。若以后研究可解释的单区域示例，需匹配训练预算和读取方式另做消融；旧质心任务高分不能作为实际点击下的最优读取证据。
2. 主训练候选保留C3，C0作CRC能力控制；用训练区回放/教师约束或保守更新的小试改善2.63点CRC取舍，同时检查多域Dice和无目标误报，不能只追一边总分。背景不作正目标。
3. 关注无目标拒识与困难负例：组织相近、支持不充分、跨片染色不同；阈值或校准只在开发集选定，再锁定盲测。现有结果尚不能保证“任意一张片给几个点都找全”。
4. 增加CRC真实独立训练视野覆盖，并以等更新量控制区分更多数据与更多计算；C2/C3第二seed验证多质量附加收益，避免直接换更大骨干后无法归因。
5. 按用户更重视的目标进入PUMA未见病种本片支持实验，再分开做跨片/跨病种支持来源实验；随后选固定WSI做整片分割/拼接与交互评估。已见多域、同WSI检索、不同WSI、未见癌种是不同验收问题。
