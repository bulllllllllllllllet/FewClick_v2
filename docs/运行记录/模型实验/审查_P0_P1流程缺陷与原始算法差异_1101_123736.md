# P0/P1流程审查：证据与结论边界

用户要求暂停后的只读审查；未恢复Goal、未运行训练、未修改模型/历史结果。核查goal/registry/现记录、实际decoder/缓存/任务/比较/最终验收代码及报告，重新读取1737catalog和raw cell index。

## 核心结论
P0作为当前开发数据的输入准备基本成立；没有在本轮检查范围发现query GT进入forward或PCA使用val拟合的证据，但未重新逐像素/逐源全量重跑全部P0审计。P1完成的是一套简化实验架构下的候选筛选，未完成完整原始FewClick上的替换验证。此前“P1 complete”不能当作候选已经提升原算法的科学验收。

## 已核实风险与缺陷
1. 架构外推缺口：image_features.py为fine512单视野；shared_prompt.py为新正负点原型+相似度+本图heatmap+RGB卷积dense decoder。未包含paper_multiscale/model.py的独立多尺度encoder/region assignment/cell-to-region attention/层级图/图decoder。优胜encoder未必在原架构继续优胜。
2. 细胞probe替身：CTransPath点中心并不是原XCell mask/context完整分支。LEMON vs CTransPath probe同时改变特征与上下文；组织比较虽保持同检测实例，XCell和LEMON的crop/context/PCA路径仍不同，不能归因为纯backbone优越。
3. 域与粒度差：OCELOT只有384train/186val、两类BC/TC，val99fields/57slides/41patients；不是186独立病人或细粒度词汇验证。组织LEMON输入由较低原生细节fineRGB重采样，不等于probe高细节真实40px。
4. 信息瓶颈：raw index为405708 detected/304747 retained，670图total>255；675图retained恰255。cell_inputs.py先按实例ID截255再排序，并非覆盖采样；cell_grid32×32均值汇聚，ContinuousPromptDecoder仅75→1024单1×1零初始化残差。失败不否定更完整细胞建模。
5. 训练诊断局限：原cell continuation完全重复父模型4000任务，公共decoder保持LR.001；seed0/1所有继续训练端点均低于父模型remote macro，image-only也退化。train remote same/cross=10/1990，dev333/602。验证了风险，不证明过拟合原因；冻结head修订没有测试融合模块共同适配。
6. 选型证据不足：初始冻结encoder比较仅1seed/80remote且代表性有限。Phikon local .6285优于ResNet .4758/SAM新头 .5367，但remote absent FPA .4279更差（ResNet .2105/SAM .3190）。后续任务适配集中在Phikon，未三底座都做同样适配。因此只能选工作候选，不是最佳encoder结论。
7. 联合适配负结果边界：仅最后block+norm、1seed、1000更新及固定LR。remote macro .3654245→.3650380说明该配方无收益，不证明Phikon已充分优化或全模型微调无效。
8. 评估外推：935对是重复图像/支持组合，不是935独立WSI；TIGER3仅2absent无present，不能证明该类检出。absent只在标注有效区成立；既有dev多次曝光、无盲测。空间块split符合用户策略，不能擅改为患者互斥；仍须报告同病例相关性。
9. 验收强度：close_p1_evidence.py主要检查既有报告/权重/索引SHA、状态和选型声明；其P1_complete不能自动证明选型因果有效。指标磁盘复算通常复用同score函数，是产物一致性检查，不是独立统计确认或所有实现错误的排除。

## 具体结果
- 冻结image公共decoder：local Dice ResNet47.58%、Phikon62.85%、SAM空间encoder+新头53.67%；不是原生SAM/SAM-FT胜负表。
- probe macroF1点中心CTransPath63.89%、LEMON72.35%、Phikon67.44%；LEMON暂作研究候选，组织收益未证。
- 冻结公共decoder细胞修订：image-only37.01%、XCell33.85%、LEMON36.24% remote macroDice；另两seedcell共同适配没有任何臂在两seed都过原全部守门。
- Phikon末层适配：frozen36.54% vs joint36.50% remote macroDice；不启动第二seed符合预算，但不是优化穷尽。

## 与原路线的差异
图像分支：原J5/region encoder或论文三视野重实现→当前公开权重Phikon空间token；未沿用J5 target-supervised初始化。
视野：论文/三视野重实现的真实fine/2x/4x→当前fine单视野；不能将历史J5统一说成三尺度，已有记录显示fine-only配置，投稿checkpoint对应性仍未完全溯源。
提示与解码：soft assignment读点/SetEncoder/图decoder→新点原型、cosine、局部heatmap及卷积dense decoder。
细胞：原XCell上下文特征保留为对照；另试LEMON10µm中心crop384→train-only PCA64。全实例检测并未在P1重新切换，沿用旧InstanSeg组织cache；Cellpose仅用于独立native成本/门控。
融合：cell-to-region/层级交互→32×32均值网格+1×1残差。tokenizer、K128码本、空间组合和完整WSI仍未实现，P2准备中。

## 建议的修正顺序
先将“工程筛选完成/原架构替换验证未完成”明确分开；保留原始/三视野模型作为桥接基线，以同数据、同任务和共同训练策略只改图像encoder，再只改细胞表示，验证真实架构收益。候选任务混合策略应匹配，学习曲线/父checkpoint退化要可见；统计按来源聚类并明确独立确认缺口。在此基础上做连续/固定词表/可学习词表才可区分表示贡献与decoder变更。不要因现有负结果直接永久替换XCell或删除细胞分支。
