# CRC 细胞级类别感知采样身份训练

## 目的

DRW 是当前最佳加权方案（patient macro-F1=0.221140），但 Treg 仍为零。本轮不使用任何类别 loss 权重，改用细胞级均衡 mini-batch，单独检验“少类在训练中实际出现次数不足”是否是主因。

## 设计

- 仅收集 train split 中医生审核、且唯一五类身份的 H&E `reg64`；不读取 val 标签构建采样池。
- 每个 mini-batch 每类各64个细胞；每 epoch 每类精确抽取50,000个细胞。Treg 的1,731个训练细胞允许**有放回**抽样，其他类也遵循同一机制；不生成数据、不改原始标签。
- 当前 identity 阶段只接收 `reg64`，故 one-cell batch 仅构造满足模型形状校验的中性坐标/区域占位；类别只出现在 loss target，绝不作为模型输入。验证仍采用原始完整图块。
- 与DRW互斥：`identity_balance=none`、无patch重采样、无延迟权重；固定数据、seed、验证划分、GPU1、epoch/patience。

## 验收

先完成真实1 epoch smoke（加载、采样、loss、checkpoint路径），再完成正式训练和独立val评价。报告五类F1、precision/recall和每病例macro-F1；Treg若仅通过大量假阳性获得recall则拒绝。仍是同病例内部图块验证，不能作为患者独立泛化或最终组织分割性能。

## 结果

1 epoch smoke `identity_0916_120400/`完成；正式训练`identity_0916_120500/`在 epoch 0 后持续下降，early stopping 于6个epoch结束，最佳 checkpoint 为 epoch 0。独立 val 重评估为`evaluate_val_0916_120900/`，patient macro-F1=`0.172248`，低于DRW的`0.221140`。

采样的确让少类产生输出，却是不可接受的过补偿：2019 Treg recall=0.9024但 precision=0.0101（F1=0.0200）；2022 Treg F1=0.0084。2017 Macrophage recall仅0.00365、F1=0.00726。故“每类每epoch 5万的强制等量细胞采样”被明确拒绝，不能与DRW或其他权重叠加，也不进入fusion。下一项应使用决策边界方法（Balanced Softmax / logit adjustment）作为独立对照，而不是进一步增加少类重复抽样。
