# 缺失目标拒识训练

## 问题与证据

`absent_tissue_target_0922_133000`显示，当前75% local＋25% cross的多原型模型在“远处support提示某组织、但同WSI且空间隔离query中没有该组织”时，固定0.5阈值的误触发率为0.7448、平均错误阳性面积（FPA）为0.2909。仅调阈值会同时改变所有存在目标任务的工作点，因此本轮将缺失目标作为显式训练任务；不替换Phase5基线，也不改变评测阈值。

## 训练设计

在现有严格配对训练的同一2304个基础target-present任务、相同shuffle顺序、1000步、每步12任务、AdamW和每seed/method相同初始化上新增`reject`臂（首轮只跑多原型）：

- 75%：原query的local support，目标存在；
- 15%：原query的同WSI空间隔离cross support，目标存在；
- 10%：同WSI、三尺度context间隔至少512 level-0像素的远处support；query标签确认不含该support请求目标，所有有效query区域监督为负类。

拒识query只把`binary_target`的非ignore位置设为0、取消其原始模拟点击的排除掩膜；其GT不输入模型，原始support点击仍是模型输入。每个候选缺失query在构造时和训练前均检查请求类确实不存在，找不到则失败而不放宽空间/同WSI约束。原query的任务类可与请求类不同，不参与损失语义。

## 对照与评价

本轮同时训练`local`、原`mixed`（75/25 target-present）与`reject`三臂，便于排除训练预算、随机顺序及初始化差异。存在目标仍使用冻结70个验证对、固定0.5阈值，报告local/cross task-macro Dice；缺失目标使用既有冻结64对和同一0.5阈值，报告activation rate及FPA。接受标准不是单一阈值：相对mixed基线，`reject`应降低空目标activation/FPA，且cross Dice不出现无法接受的塌陷；结果按三seed报告，不使用test。

## 执行计划

先运行每层1对、2步、seed17、三臂的真实GPU冒烟，检查缺失query标签、loss、checkpoint重载、70对子集评测以及冻结缺失对评测；随后以GPU4完整运行三seed×三臂×1000步，日志、真实PID与`EXIT_CODE`写入NFS时间戳目录。代码只修改`benchmarks/v5`，v4冻结不动；生成物仅写入`/nfs-medical3/zyh/fewclick_v2/extensible_prompt/`。

## 完成结果

首次完整运行`0922_134910`在训练前审计阶段发现一个support没有任何合格缺失query，`EXIT_CODE=1`且没有开始训练；未放宽约束。采样器改为仅从每个组织/提示尺度中选择同时具备target-present配对和target-absent配对的候选，并重新完成真实2步冒烟（`0922_135357`，三臂loss有限、checkpoint重载及2对mask重算通过）。

完整运行`paired_tissue_training_0922_135508`在GPU4以worker PID 2976991完成，`EXIT_CODE=0`。共有3 seed × 3 arm = 9个checkpoint；每个checkpoint的1000步loss有限且重载一致。70个冻结存在目标验证对产生1260条指标，保存mask重算一致。训练manifest记录2304个严格合格的基础任务和对应2304个请求组织缺失的训练query；reject日程在12000任务中精确为9000 local-present、1800 cross-present、1200 cross-absent。

固定64个缺失目标验证对的三seed评测均`EXIT_CODE=0`：local/mixed/reject的activation rate分别为0.7656/0.7188/**0.6510**，FPA分别为0.2590/0.2672/**0.2366**。因此相对同轮mixed，reject将误触发降低0.0677、FPA降低0.0306。存在目标验证中，local提示Dice为0.5632/0.5620/**0.5656**，cross提示Dice为0.5246/0.5440/**0.5517**；reject相对mixed的cross Dice提高0.0077。结果仅代表同队列空间区域验证（历史encoder可能已有暴露），不是独立病例或跨癌种泛化结论。
