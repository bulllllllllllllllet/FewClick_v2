# 跨patch组织错误分析

问题：严格配对实验中，Phase5从cross训练获益，而单/多原型下降。该差异应先定位到组织任务及错误类型，才能决定混合训练或结构改动。

输入为`paired_tissue_training_0922_122000`的冻结70对验证任务及逐episode像素计数。分析仅使用已保存预测、GT和指标，不重新训练，也不查看test。对于每个模型，比较local训练与cross训练在同一远处提示协议下的逐组织总TP/FP/FN；输出Dice、recall、FNR、FPR及cross-local差值，同时保留每seed任务统计。FPR以所有非目标有效像素为分母，FNR以目标像素为分母；不把任务数或像素数伪装成独立病例样本。

命令：aligner Python运行`benchmarks/v5/phase_5_prompt_encoder/tools/analyze_paired_tissue_errors.py --run /nfs-medical3/zyh/fewclick_v2/extensible_prompt/paired_tissue_training_0922_122000`。输出同一可复核产物目录`error_analysis.json`。验收：2520条指标输入完整，任务聚合与已保存汇总一致，空目标不制造Dice，结果明确说明只是内部空间验证。

错误分析结果：Phase5 cross训练提升主要来自肌肉（Dice +0.456）、正常间质（+0.154）和肿瘤间质（+0.088）；坏死下降0.194，主要是漏检增加。原型cross训练下降集中在血管（单/多 -0.471/-0.296）与坏死（-0.294/-0.205）的FPR明显上升，以及肿瘤间质（-0.234/-0.190）FNR上升；正常腺体、黏液、淋巴聚集改善。这支持先测试75% local＋25% cross混合episode，避免全量cross任务把血管/坏死等少数外观变异任务的误检扩散到整个特征投影。

混合训练保持严格配对的2304个query、顺序、初始权重、support数量、步数和冻结70对验证集，仅对每条训练episode以固定seed选择25%使用远处support；先仅测试单/多原型。评估同时报告local与cross提示，比较local、mixed、cross三臂，不能只选有利协议。冒烟后进行三seed×1000步。

## 75/25混合结果

混合冒烟0922_130100完成，EXIT_CODE=0：两模型×三训练臂、2步、2对验证均完成checkpoint重载及24条mask指标复核。完整运行0922_130300在GPU1完成，worker2796746、EXIT_CODE=0。每个模型三seed×三臂共18条1000步轨迹；2304个训练query、同一任务顺序、同一初始化副本和同一70对验证集。mixed共12000个训练episode，其中固定随机选择3000个（25%）使用远处support；2520条指标均由保存mask重算，6组local/cross/mixed初始化hash相同。

对应的local提示Dice：单原型0.5615/0.5578/0.5462；多原型0.5533/**0.5558**/0.5476。混合训练显著优于全cross训练，并且没有牺牲多原型的local表现；单原型与local训练相差0.0024，尚不能作为提升。三个seed的多原型cross结果为0.5373/0.5403/0.5319，方向稳定，但不是独立病例显著性结论。

结论：当前最好的兼顾local和远处提示方案是**75% local＋25% cross的多原型训练**。它只比local单原型的远处提示Dice低0.0050，超过local多原型0.0047，并避免了全cross导致的血管/坏死误检膨胀。下一步应以此模型进入缺失目标（negative task）评测；在加入蛋白或改变编码器前，先确认模型能拒绝不存在的组织请求。
