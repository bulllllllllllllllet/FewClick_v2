# Panel1 单细胞 H&E 分类试验

- 目的：预测一个已定位 H&E 细胞的结构身份，重点报告 Epithelial 与 Blood_endothelial；不等同于组织分割或全自动细胞检测。
- 输入：Panel1 自身的 `17-00538F_FAP/large_context_sift_registration`，使用已有 H&E 检测、局部配准图像和 accepted_match；医生标签作为标准监督。此处病例为 2019-00538F。其他两例尚无已核验的同等细胞匹配产物，第一轮明确为单病例诊断。
- 标签：Epithelial、Blood_endothelial、Lymphatic_endothelial、CAF（FAP_CAF 与 FAP_SMA_CAF 合并）、SMA_stromal。Undefined、仅 D2-40/S100 阳性不作为确定身份或背景；保留源标签。模型闭集输出不代表未知细胞也可正确分类。
- 工程核验：只取源 accepted_match 且局部匹配距离不超过4像素、H&E 核ID/质心可复核的细胞；不将跨panel区域计数转为单细胞真值。mIF 强度和坐标不作模型输入。继承源匹配选择偏差，不宣称未配准原图或跨病例泛化。
- 划分：mIF参考坐标4096像素空间块，块内512像素缓冲；512像素图块及128像素细胞crop完全在块内部。固定hash分train/val/test及图块顺序，不根据标签挑选测试图块；同一细胞去重。报告实际每类support。
- 表示：冻结CTransPath，128像素H&E核中心crop加H&E核mask软注意力，768维；比较训练集多数类、训练集原型与线性头。后两者只用train拟合；线性头仅按val macro-F1选epoch，固定3seed后一次test汇总。
- 预算：正式最多train/val/test=96/32/32个有效图块，各图块最多128细胞；三seed各30epoch。先3/2/2图块、2epoch真实smoke。GPU1、8CPU线程。
- 验收：真实源图像/核mask/标签逐项校验，完整特征提取、训练、保存重载和测试；逐类precision/recall/F1、混淆矩阵、预测表及匹配过滤计数。任何类缺失均显示support，不能宣称其识别成功。
- 工具：`benchmarks/v5/tools/run_crc_panel1_cell_identity.py`，`prepare`生成清单、`fit`提取特征并训练；`predict`接受128x128 H&E crop及其目标核二元mask。单细胞推理不读取mIF。
- 产物：`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_cell_identity_<timestamp>/`；长运行tmux，日志含EXIT_CODE和worker PID。
- 状态：完成。输出详见下文；识别效果严格限定于已定位、已成功配准匹配的五类或二类细胞。

## 实际执行与审计

- 代码：`benchmarks/v5/tools/run_crc_panel1_cell_identity.py`、`refit_crc_panel1_cell_identity.py`、`run_crc_panel1_binary.py`；v4 未改动。
- 冒烟：`panel1_cell_identity_smoke_0923_115500`，24/8/8图块，train/val/test五类细胞数分别为 `[445,49,12,28,77]`、`[67,25,9,27,31]`、`[95,17,0,5,38]`。真实H&E→冻结CTransPath→线性头→checkpoint→test和独立单细胞推理均完成。2 epoch线性头全判上皮，血管召回0；训练集原型在17个血管真值上的F1=0.414。此步骤仅检查链路。
- 正式：`panel1_cell_identity_0923_120304`，96/32/32图块；五类train=`[1808,208,35,118,368]`，val=`[434,75,18,40,126]`，test=`[421,56,2,26,120]`。固定manifest SHA256=`2a722c2935428b3eb2ea9377af1105c8286dfcbd82158a8de873c00cfc2ade20`；GPU1；tmux `panel1_cell_identity_0923_120304`，worker PID 279231，`train.log`记录`EXIT_CODE=0`。冻结特征3,855个，30 epoch×3 seed。
- 正式五类线性头：三个seed最佳epoch均为0，且测试全部预测上皮；macro-F1=0.16099，与训练集多数类基线相同，血管内皮F1=0。训练集原型macro-F1=0.30145，血管内皮precision/recall/F1=0.190/0.143/0.163；不够可靠。
- 诊断修正：原头输入为L2单位向量，使用`feature_scale=16`复用已提取特征、另存`panel1_cell_identity_refit_0923_121156`，没有覆盖原实验。三seed best epoch=21/25/26，测试macro-F1=0.24642/0.23463/0.27258；血管内皮F1=0.11268/0.06667/0.24444，召回为0.07143/0.03571/0.19643。上皮F1约0.84–0.86，CAF及淋巴内皮为0。此为看过原test后的探索性修正，不是独立确认。
- 二类任务：`panel1_cell_binary_0923_121320`复用同样的特征与split；只在源标签明确为Epithelial或Blood_endothelial的细胞上拟合。训练/验证/测试分别为`1808/208`、`434/75`、`421/56`。train-only StandardScaler，比较平衡线性logistic与RBF SVC，并按val macro-F1选择线性。val macro-F1=0.85463、血管F1=0.75610；test macro-F1=0.93573、准确率=0.97275，血管precision/recall/F1=0.86441/0.91071/0.88696，上皮F1=0.98451。测试混淆矩阵(真值行、预测列)为`[[413,8],[5,51]]`。始终预测上皮的test准确率=0.88260、血管F1=0。已用真实血管内皮H&E crop+核mask独立推理，输出Blood_endothelial。
- 空间复核：train/val/test覆盖22/10/11个4096px组；无重复全局细胞坐标，无跨split相同H&E图像或mask SHA；测试细胞到最近训练细胞至少1166.65px。病例仍仅2019-00538F，不能视为独立患者、跨癌种或完整WSI泛化。
- 二类test的56个血管内皮分布在8个空间组；其中两个组贡献31个，故477个细胞不是477个独立重复，不能仅凭细胞级分数推断跨区域稳定性。
- 重要解释：二类模型对任意未知类型也会强制二选一；其test已用于先前五类诊断，因此二类分数是探索性、同一测试集再使用的结果。只证明已定位且成功匹配的上皮/血管内皮细胞在这张切片的空间隔离区域有明显可分性；不证明自动细胞检测、五类身份、结构ROI或新癌种识别能力。

## 使用

二类模型权重：`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_cell_binary_0923_121320/classifier.joblib`。输入需为目标细胞的128×128 H&E图像crop及对应128×128二值核mask；运行：

```bash
PYTHONPATH=. conda run --no-capture-output -n aligner python benchmarks/v5/tools/run_crc_panel1_binary.py predict \
  --model /nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_cell_binary_0923_121320/classifier.joblib \
  --image /path/to/he_crop.png --mask /path/to/nucleus_mask.png --device cpu
```

该接口只在“候选已经确定属于上皮或血管内皮”时适用。未知、淋巴、CAF、SMA等会被强制误判为二者之一；实用部署需增加拒识/其他类和独立新病例评价。

后续对“为什么五类失败”的同清单诊断见`运行记录_Panel1五类失败原因诊断_0923_122824.md`：在train-only标准化后，五类模型不再全判上皮，test macro-F1提升至0.3504；SMA F1=0.510，但CAF与淋巴内皮仍差。原二类分数仅在限定候选类别时适用。
