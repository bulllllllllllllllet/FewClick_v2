# CRC 三四次幂逆频率身份训练

## 目的

在平方根权重（`alpha=0.5`）能避免 Treg 泛滥、但 Treg 仍 F1=0 的结果基础上，仅提高少类补偿强度到 `alpha=0.75`。这是严格逆频率（`alpha=1`）与平方根之间的单变量插值对照。

## 固定条件与命令

- 同一训练契约：`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/crc_pooled_identity_manifest_0916_110200/manifest.json`。
- 同一标签、`reg64` 输入、模型、seed、GPU1、epoch/patience 和 uniform patch sampling；不使用 validation 标签计算任何权重。
- 输出：`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/identity_0916_114100/`；日志：`crc_power075_0916_114100.log`。
- 验收：最佳 checkpoint 的独立 val 评价必须报告五类 F1、precision/recall、support 与每病例 macro-F1；若 Treg recall 升高但 precision 崩溃，则拒绝该候选。

## 结果

运行中。该验证为同病例内部图块验证，不能作为患者独立泛化或最终组织分割性能。
