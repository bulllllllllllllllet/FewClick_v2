# 组织原型统一像素评测

目的：以真实 H&E、像素组织真值和相同区域 support 比较冻结 Phase 5、正负单原型、正负多原型，建立后续任务接口。遵循 fewclick-v2：v4 只读、产物单独版本化。

输入：v4 phase4 multiscale_token_cache_20260719_205544、fine_region_labels_20260719_230128、phase5 prompt_eligibility_20260720_210851；Phase2 epoch028、Phase5 epoch027。

协议：历史 val 中每个组织×提示大小选一个固定 episode，最多36个。此清单只用于旧缓存兼容性诊断，不建立新病例划分，也不作为新训练清单。12类已被预训练监督，历史验证集参与过权重选择；不能声称独立测试或新类别泛化。每个 support 来自 region 真值，名为 point 的旧提示亦非精确像素点击。

三种方式共用 token、提示、Phase2 soft assignment 与0.5像素阈值。单原型采用每个符号的support均值，多原型使用每个support token（温度0.1，无query聚类）；学习过的Phase5与无训练原型的差异仅作部署基线诊断，不能解释为同训练预算架构消融。未接Phase6图模块。

指标：像素Dice/IoU，全有效范围和排除提示region后的范围分别统计；先episode再task宏平均；空目标Dice/IoU记null并报告误报面积。逐episode保存mask、提示位置、计数和输入来源。未计算NoC，不能将区域support数当点击数。

运行：GPU1，CPU4线程；先最大1 episode冒烟，验证后36 episode。命令模块 `benchmarks/v5/phase_5_prompt_encoder/tools/evaluate_tissue_prototypes.py --timestamp <MMDD_HHMMSS> --device cuda:1 --max-episodes <1或36>`。

产物根：`/nfs-medical3/zyh/fewclick_v2/extensible_prompt/tissue_prototype_eval_<timestamp>/`；tmux和同根日志，EXIT_CODE监控。

验收：真实loader和三个模型路径完成；指标及保存mask一致；未覆盖类别明确可见。之后再构建新的空间划分、跨patch support/query与真正点击协议，审计低倍上下文、预训练暴露、完整辅助target范围。未经这些审计不开展正式新任务训练。

进展：0921_210426 单episode冒烟通过；0921_210453/210602 的36 episode顺序取样诊断通过，但来自同一WSI，因此不作为跨切片比较。改为在组织×提示大小层内以固定seed 20260921均匀抽样，运行0921_210659；不改变任何模型、阈值或训练参数。此调整只解决输入排序导致的集中取样问题。

结论：直接用当前token做原型匹配低于训练过的Phase5，增加support原型数量未见收益。不可由此否定训练后的原型方法；也不可声称新组织泛化。下一阶段应先固定新的空间任务清单及相同训练预算，再检验可学习投影/原型方法。当前不启动panel1训练，不将粗细胞证据伪造组织mask。

后续验收项：真实点击协议（1/3/5/10次）与NoC及失败率；support/query跨空间区域；已见与任务阶段未见类别分别报告，并审计初始化暴露；低倍上下文和全辅助target区域跨split隔离；固定验证集后三训练seed。正式训练不得直接重用本诊断的历史val作为新独立测试。
