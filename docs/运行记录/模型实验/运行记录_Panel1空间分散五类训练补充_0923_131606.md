# Panel1空间分散五类训练补充

- 目标：在现有Panel1五类训练清单上，继续从此前未进入训练集的CRC H&E–mIF匹配图块中补充五类真实细胞。按本轮要求先限定现有2019-00538F病例；已有val/test和空间组保持不变。
- 基线：`panel1_cell_expand_0923_124600`，训练集7,586个独立细胞，覆盖22个空间组。虽然另有43个train空间组，但在原有匹配表和变换验收条件下，这些组没有可用的已匹配细胞；首轮严格限制在这43组的构建因此没有产出。随后改为在已有22个可用训练组内，从未进入原清单的patch补充样本，覆盖各组不同位置。
- 采样：每个已有训练空间组最多选3个未使用有效patch；从已接受匹配、配准距离≤4像素的五类标签中每类每patch最多抽24个；排除缺失变换、缺图/掩膜及与原清单重复的细胞。只读原图、匹配表与mask。结果为61个patch、1,178个真实新增细胞；按上皮/血管内皮/淋巴内皮/CAF/SMA顺序分别新增752/128/15/53/230个，分别分布在22/20/10/16/21个训练空间组；56/42/11/27/48个新增patch含有相应类别。训练支持从[5494,567,92,288,1145]变为[6246,695,107,341,1375]。
- 验收：原val/test `(patch, he_id, label, xy, group)`逐行一致；无重复细胞，train/eval空间组隔离。旧8,904个特征复用，新增1,178个独立细胞特征均提取成功；稀有类图像增强产生896个视图。对照旧训练集、只加真实空间patch、真实patch加增强三臂，验证集macro-F1分别为0.3726/0.3872/0.4146，均选择平衡逻辑回归；既有测试集macro-F1为0.4413/0.4309/0.4499，准确率为0.7360/0.7408/0.7712。
- 逐类结果：测试F1（上皮/血管内皮/淋巴内皮/CAF/SMA）旧训练为0.889/0.486/0/0.137/0.694，加入真实patch为0.904/0.421/0/0.151/0.679，增强臂为0.916/0.466/0/0.192/0.676。真实细胞扩充单独未提升macro-F1；增强臂较旧训练集高0.0086，但提升主要来自上皮与CAF，血管和SMA未同时改善。测试淋巴内皮仅2例，结果不能说明该类已学会。
- 模块：`benchmarks/v5/tools/supplement_crc_panel1_spatial.py` 的`bundle/prepare`；然后复用`expand_crc_panel1_cell_identity.py extract/compare`补特征并训练。
