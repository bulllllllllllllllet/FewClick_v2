2. **C并非全部无效，但不能晋升**：相对B大目标+3.28pp、召回+5.08pp，空预测18降6；相对原模型大目标-1.51pp、FPA+2.90pp。正常间质+2.20、脂肪+2.57、肌肉+3.60、正常腺体+1.74pp；淋巴-10.20(n28)、血液-12.26(n12)。排除这两类仅作解释时其余9类宏均值+0.65pp，不能删除不利类改写主结果或声称已确定改善。原模型23/2130空，C6/2130：解决空预测不等于解决正确分割。C是在A+B上加浅层refiner，尚无原Few+独立refiner对照，因此不能将C整体失败归因refiner，也不能推断refiner单独必涨。
3. **D误报降低伴随覆盖下降**：FPA6.71→5.08，召回74.99→72.27；precision78.26→77.92也没有提高。9/11类大目标Dice下降。更符合“减少预测范围但未提高目标判别”的表现，非证明判别学习原理无效。代码仅训练原64维projection的辅助目标，support多形态压成单prototype、hard-negative top64+固定margin；这些是可能机制，不是已隔离因果。停止继续盲扫系数。
4. **SANSA差距主要在完整覆盖与轮廓**：大目标recall82.98 vs74.99，BF1 45.51 vs33.96；其precision76.65低于原78.26，FPA14.79高于6.71。它不只是更敢预测：边界BF1也更高，但原Few仍有明确误报优势。潜在提升应同时看Dice/BF1/FPA，不能靠扩大mask宣称解决。Phikon原生32网格插值64不是增加细节；当前证据不证明encoder是唯一瓶颈。
