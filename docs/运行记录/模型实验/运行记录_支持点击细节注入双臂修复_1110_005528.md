# 支持点击细节注入：两臂受控修复

用户授权“想几个方案，尝试解决”，针对63例诊断发现的支持小目标region混杂及主分支背景偏置。当前 preparing，尚无质量结论。

- A point_detail：原region token加点击处fine dense特征的可学习投影。
- B local_detail：同位置3×3细特征邻域，按与中心余弦相似度softmax加权（固定温度0.1），再用相同投影补充原region token。
- C deferred：给region主分支单独分割监督，解决与匹配残差共适应；本轮不与表征同时改，先等A/B结果。

A/B各新增65792参数，零初始化保证初始输出与原模型一致；同时改正负提示的token及raw prompt attention路径。保留Phikon三视野、图解码器、SignedMatcher、全部原损失、优化器、dropout/BN策略；无细胞分支、无J5、无SAM2替换。与之前失败的全图预测support mask加权池化不同：这次改的是prompt token，局部证据不依赖预测support mask。特征网格64×64来自Phikon32×32插值，不宣称创造更高分辨率细节。

输出 `/nfs-medical3/zyh/fewclick_v2/cvpr_research/support_token_repair_1110_005528`；模块 `benchmarks.v5.support_token_repair.pipeline`。GPU1/3各一个独立臂，最多两训练worker，>=12288MiB允许共享。环境aligner及vendor/phikon-v2，CPU2线程。实际命令、PIDs、日志在launch.json、各arm/pipeline_stage.json、stage.json。
