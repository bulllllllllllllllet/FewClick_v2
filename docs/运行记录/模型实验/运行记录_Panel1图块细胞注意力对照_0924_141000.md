# Panel1 图块细胞注意力对照

- 目的：验证同图块细胞交叉注意力能否改善五类身份识别。
- 输入：panel1_train_all_0923_170500/cells.csv 与 panel1_train_all_features_0923_172500/features.npz；补充均衡评估清单 panel1_eval_supplement_0923_155834 和 panel1_eval_supplement_scores_0923_155610 中的特征。
- 实现：benchmarks.v5.tools.train_crc_panel1_patch_attention。128像素 CTransPath L2 特征、目标细胞 query、同图块16个最近的其他细胞 key/value、相对 HE 坐标、门控残差；仅用输入特征和几何坐标构建邻居，无同伴真值标签。与 target_only 在相同划分、种子、类别权重和优化参数下对照。
- 防泄漏：manifest 哈希核对，同图块单一 split，补充集空间组与训练空间组不相交；训练选原 val 最优 epoch，原 test 和补充 test 只评估。
- 输出：/nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_patch_attention_smoke_0924_141000 与后续 full 时间戳目录；GPU5、8CPU线程。
- 验收：首先完成真实数据两轮 smoke 并检查张量、单细胞图块、有限损失、输出结构；再运行两模型完整训练，比较 val/test/supplement test macro-F1、accuracy 和各类 F1。
- 局限：当前旧缓存每图块只含已选的部分细胞；均衡补充集平均同伴更少。全量三病例缓存完成后需重建训练/评估 manifest 复测。
- 状态：待运行。

| 输入 | 模型 | 原test macro-F1均值 | 补充均衡test macro-F1均值 |

- 三种子128注意力原test macro-F1分别0.354/0.337/0.357；补充test 0.263/0.242/0.237。双视野注意力原test 0.363/0.433/0.349；补充test 0.173/0.254/0.211。所有数值来自对应 metrics.json 的最佳原 val epoch checkpoint。
- 原test淋巴内皮仅2细胞，不能可靠判定该类。seed11的128注意力在补充test血管内皮F1由同条件target-only 0.220升至0.321、CAF由0升至0.074，但淋巴内皮仍为0。
- 旧128线性扩量基线补充均衡test macro-F1约0.398，仍高于本轮所有注意力模型；此数字来自另一训练脚本且存在收敛警告，作为参考而非完全同条件对照。
