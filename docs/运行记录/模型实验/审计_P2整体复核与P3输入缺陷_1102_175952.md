## 实测发现与优先级

### 1. 高优先级：细胞cap并非代表性采样，影响P3空间归因

`benchmarks/v5/phase_6_mask_decoder/diagnostics/external_cell_inputs.py:56`的`cells_from_instances`先截升序instance IDs前255，再按y/x排序。这符合历史复现约定，但不保证代表全视野。真实16个既定颜色审计fine视野中9个触发cap；本次逐一从完整instance mask重新计算质心与象限分布，并核对实际保留ID及输入metadata。

- 视野091617cdb5a28d60bb7c6738：429个检测实例，255个保留实例全部位于上半区；全部实例下半区占32.63%。
- 视野a377e74fc196bee22106467f：626→255，下半区占比由60.22%变成2.35%；四象限分布总变差57.87%。
- 9个截断视野的保留细胞平均y均向上偏移。16例是预先固定样本，不代表全1737帧/三个尺度的发生率。

`CellToRegionAttention`按保留cell的sampled assignment比例分配总数。乘total/selected只能修正总量，无法恢复漏掉区域的空间分布；这里实测的是象限偏差，不冒称已测soft-region误差或分割损失因果。也不能忽略XCell64自身依赖所选cell集合上下文。

**P3训练前要求**：审计全部三尺度cap/空间覆盖；冻结无需GT的代表性选择方案（确定性随机或空间分层方案先用train几何定规）；如改变实例集合，重提对应crop特征与XCell集合表示，不能重排旧255行冒充修复；新目录/新identity，train-only转换统计重新验收。统一各对照的选择、几何与密度定义，旧结果不能与新输入直接作模块效果对比。

### 2. 中优先级：细胞像素中心约定不一致

缓存metadata采用index质心/W、index质心/H；当前align_corners=False采样解释的是图像边界归一化坐标。应明确index质心+.5后再归一化。本次16例真实mask核验，遗漏量约为512输入的0.25像素（检测栅格1023/1024），不是0.5个512像素。既有组织上下文诊断已仅在GT读取时纠正，模型输入尚未纠正。

三臂同偏移，不直接解释词表失败。P3需固定统一坐标规范并验证实际assignment采样/真实中心/三尺度变换；修复必须所有匹配臂一致，不能只改候选或覆盖旧缓存。小偏移的质量影响未测，不承诺改善。

### 3. 中优先级：稀有代价守门只覆盖local

`compare_vocabulary.summarize_arm`的small/fat来自local302，而主收益与FPA来自remote935。原合同被忠实执行，但不能把local代价通过说成远端小目标也安全。本次新增事后描述统计，保持原P2门槛和结果不变：

### 4. 中优先级：功能门控强度与正式训练接受应分开

32-task功能门控实际只取两域各16个local任务；8-task工程门控虽含remote/absent，但不证明后者学会。swap规则是全样本最大像素变化达到阈值，可能由单任务单像素满足。正式训练仅保存固定末步，已核对2000更新/8000消费/优化器/finite，不能由此证明收敛或远端训练拟合。

P3训练前增加固定train-only local/remote/present/absent分层功能证据，记录每任务有效区空间变化、点击符号分离和提示响应分布，并在train-only预定节点监控。不可用开发GT调阈值、选择修复或最优checkpoint。P2全量mask接受是保存mask对GT重算，末步checkpoint只做state存盘核对；小门控有fresh恢复，但正式末步未另做全量fresh重新推理。后续至少补末步固定代表任务fresh-load预测一致性，不把SHA核对称完整重新推理。

### 5. 研究解释限制：当前测试不是全部tokenizer路线

只有K128、共同Linear、无commitment/对比/重建辅助目标的ST/EMA配方与一个seed。固定码本下mapper可漂移，EMA按优化器后映射空间跟踪，属于已明确的设计而非已发现实现bug；有限量化误差/有效码数说明未塌缩，不证明学到生物语义。颜色翻转高，实例空间偏采样也可能影响码本分布。不能写“离散词汇无效”，只能写“在此输入与固定配方下，Dice提高但误报代价超界，故本轮未晋升”。第二seed未跑符合门槛规则；不确定性仍存在，不以它宣称普遍优劣。

### 6. 接续文档风险

fair_comparison/README仍含历史AAAI 40k任务/最佳checkpoint/旧队列描述；当前CVPR以goal、阶段合同及P2机器合同为准。P3必须引用具体有效规则而非照搬旧队列。既有16场颜色与组织上下文接受属于诊断，不等于染色鲁棒、生物细胞类型或WSI验证。P2缺少image-only/形态shuffle不能归因cell必要性；这些仍是P3必须执行的匹配重训控制。
