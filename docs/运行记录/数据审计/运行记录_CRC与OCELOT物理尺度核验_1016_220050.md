# CRC与OCELOT物理尺度核验

- 用户问题：两类图像缩放倍率是否一致，是否尺度不匹配导致跨域退化。
- 已知：CRC清单全53534项均level0裁剪1024²→网络512²，但target_mpp为空；不能只用字段10x推断实际倍率。OCELOT根据组织ROI的resized_mpp_x/y重采样到约0.5MPP。需核对原WSI物理标定。
- 方法：只读训练3k/验证1024实际来源WSI的TIFF X/YResolution与ResolutionUnit，按cm/inch单位转换µm/px，再乘裁剪/输出像素比；另用libvips xres/yres交叉核对。与OCELOT23例实际重采样尺寸、原组织图像MPP及细胞检测插值倍率分别比较。
- 初步12片实际TIFF标定可读：level0约0.252–0.264µm/px，网络输入约0.504–0.528µm/px；OCELOT目标0.5。尚待全来源片覆盖，暂不称全量确定。
- 输出：`/nfs-medical3/zyh/fewclick_v2/dataset_audit/scale_match_1016_220050/`，保存headers、逐片标定/原标签、统计、脚本与异常。CPU/零GPU，仅头信息与已有清单，不改图像或预测。
- 验收：单位换算正确、来源覆盖明确、重采样MPP与原生细节分辨率分开。相同物理视野不代表原始图像包含相同细节；OCELOT原组织图低分辨率插值需单列。若确有较大MPP误差再做固定视野/尺度对照，不先假定已找到主因。
