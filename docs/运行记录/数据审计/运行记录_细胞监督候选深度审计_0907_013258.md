# 细胞监督候选深度审计运行记录

- 时间戳：`0907_013258`
- 目标：对 COAD、HCC、OV 的 Xenium/CosMx 共六个已解压 cohort，核查可用于 H&E-only cell encoder 监督训练的实际数据合约。
- 输入：每个 cohort 的 H&E、`transcriptome/adata.h5ad`、细胞边界/多边形 CSV、转录本 parquet；蛋白 H5AD 仅记录存在性。
- 模块/命令：`benchmarks/v5/tools/audit_cell_supervision_cohorts.py`；读取 H5AD 元数据、CSV header 与 cell ID 集合、Parquet schema/metadata、TIFF header，不读取完整表达矩阵或图像像素。
- 输出：首次输出目录 `/nfs-medical3/zyh/fewclick_v2/dataset_audit/cell_supervision_audit_0907_013258/` 未写出报告；第二次在 CosMx OV 转录本文件格式处退出；第三次确认 CosMx 需使用复合 ID 但顺序尚需修正；最终重试输出 `/nfs-medical3/zyh/fewclick_v2/dataset_audit/cell_supervision_audit_0907_014551/`。
- 计算：CPU/文件系统 I/O，无 GPU。扫描边界 CSV 的 cell ID 列以计算与 H5AD obs ID 的实际重叠。
- 验收：每个 cohort 写出一个结构化记录，包含 section 数、H&E 形状、H5AD obs/var、annotation 覆盖、边界/obs ID overlap、转录本 cell ID/空间坐标字段及可用性门禁。
- 最终状态：完成（`EXIT_CODE=0`）。最终使用 CosMx `cellID_fov` 复合键。6 个 cohort 中 5 个通过完整数据合约：三套 Xenium（COAD/HCC/OV）和两套 CosMx（COAD/HCC）；CosMx-OV 的边界/H5AD ID overlap 为 `0.9997`，但 `tx_file.parquet` footer 不可由 PyArrow 读取，暂记为待修复。

## 核心结果

- 5 个通过 cohort 的 H5AD—边界 ID overlap 为 `0.9996–1.0000`，annotation 覆盖均约 `90.0%`。
- Xenium 的有效细胞数：COAD `405,927`、HCC `271,687`、OV `410,193`；对应转录本行数约 `3.50/3.63/4.95` 亿。
- CosMx 的有效细胞数：COAD `292,371`、HCC `237,030`；对应转录本行数约 `4.31/2.42` 亿。
- 可立即进入下一阶段的五 cohort 合计约 `1,617,208` 个带边界、H&E、RNA 和 annotation 的细胞；这仍是细胞数而非独立 donor 数。
