# 细胞队列样本与本体审计运行记录

- 时间戳：`0907_015233`
- 目标：统计 5 个通过数据合约的 cohort 可证明的 section/donor 信息，并将各 H5AD `annotation` 建立为第一版跨癌种细胞类型本体映射。
- 输入：`cell_supervision_audit_0907_014551/cohorts.json` 及五个转录组 H5AD 的 `obs/annotation`、`uns`、H&E 文件列表。
- 输出：初版 `/nfs-medical3/zyh/fewclick_v2/dataset_audit/cell_ontology_audit_0907_015233/` 发现聚合计数实现错误；最终版 `/nfs-medical3/zyh/fewclick_v2/dataset_audit/cell_ontology_audit_0907_015339/`。
- 计算：只读 HDF5 元数据和目录名；不读取表达矩阵，不改写原始注释。
- 验收：每个保留 cohort 报告 H&E section 文件数、是否有可验证 donor/sample 元数据、原始 annotation 分布、映射后本体分布和未映射类别；不将缺失 donor 信息伪造成独立病人数量。
- 最终状态：初版只影响合并大类的总数、不影响原始 annotation；修正为累加同一 broad class 下的全部原始标签后完成最终运行。

## 结果

- 5 个通过 cohort 各有一张根目录 H&E 文件，观测到 `5` 张 section；H5AD `obs/uns` 中没有 donor/sample ID，独立 donor 数仍为未知，不能据此作病例级 split。
- 建立 `v1_0907` broad ontology：`epithelial_parenchymal`、`fibroblast`、`vascular_smooth_muscle`、`t_cell`、`b_plasma_cell`、`myeloid_antigen_presenting`、`innate_lymphoid`、`granulocyte_mast`。
- 所有已注释的原始类别均映射到该八类本体；映射后的数量以 `epithelial_parenchymal` 917,725 最大，随后为 `vascular_smooth_muscle` 137,071、`fibroblast` 136,937、`myeloid_antigen_presenting` 93,622、`b_plasma_cell` 86,293、`t_cell` 58,454。
- 本体仅用于第一版训练采样/辅助监督，`Epithelial` 与 `Hepatocyte` 的合并不得被解释为肿瘤/正常状态标签；独立 donor 元数据与专家复核后才可冻结为正式标签体系。

- 最终产物：`/nfs-medical3/zyh/fewclick_v2/dataset_audit/cell_ontology_audit_0907_015339/`
