# CRC Panel 2 空间隔离训练清单

- 输入：`crc_patch_region_alignment_0921_170938` 的 1,553 个唯一审核 H&E patch 及其 panel_2 区域观测候选。
- 模块：`build_crc_panel2_spatial_manifest.py`；不读取或写入源数据。
- 输出：`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/crc_panel2_spatial_manifest_0921_173523/`。
- 划分：按公共 H&E 物理坐标的 2,048 µm block 作稳定哈希分配（目标约 train/val/test=70/20/10），不以病例 ID 划分；病例 ID 只保留为来源和分层报告字段。
- 泄露控制：任何不同 split 且 256 µm 缓冲后的局部 patch 足迹相交的候选均从全部 split 删除，而非任意一侧保留。每个保留样本保留 `spatial_group_id`、source/context footprint，随后由 `ExtensibleTaskManifest` 做跨 split overlap 校验。
- 非目标：这不是组织分割标签清单；panel_2 target 仍是局部配准/区域聚合得到的 `candidate_only` 免疫组成观测。
- 命令：`PYTHONPATH=. conda run -n aligner python benchmarks/v5/phase_3_cell_region/tools/build_crc_panel2_spatial_manifest.py --timestamp 0921_173523`。
- 验收：train/val/test 均非空；同一 `spatial_group_id` 不跨 split；256 µm 缓冲下无跨 split context 重叠；每个病例在报告中可见但不要求病例互斥。
- 结果：完成，`EXIT_CODE=0`。输入 1,553 个 patch，因跨 split 256 µm context 相交剔除 415 个，保留 1,138 个；train/val/test=861/188/89，覆盖 166 个空间组。三例的 train/val/test 数分别为 103/36/23、513/48/37、245/104/29；三例均跨 split，符合“病例仅用于溯源和报告”的约束。
- 验证：manifest hash `68b9cb89461473c246e45cf42aac41479f3ce979a6816ef2227e4fa0c1001ac8`；`ExtensibleTaskManifest` 空间组与跨 split context overlap 审计通过，三个 split 均非空。
- 状态：完成；清单为下一步小规模 panel_2 辅助监督对照的唯一输入，不能作为组织分割真值。
