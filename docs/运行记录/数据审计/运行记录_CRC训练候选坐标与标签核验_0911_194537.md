## 核验结果

命令：`conda run -n aligner python benchmarks/v5/tools/audit_crc_training_candidates.py --timestamp 0911_194537`；实际使用aligner绝对Python路径执行。代码完整读取三个offset0 niche表，六个细胞表各抽取前20,000行（共120,000行），不以有序头部样本估计全切片类别分布。

|---|---:|---:|---:|---|
| 2017-23800D | 1,982,730 | 1,615,649 | 5,983 | panel1原表位于NFS5，实际可访问 |

细胞数为完整manifest记录，非本次全表逐行计数；两panel不可相加当作独立生物学细胞。eligible niche三例合计12,541，与two_view_mining摘要一致；这里只计offset0，其他offset不是额外独立样本。

- 三张panel1 HE实际尺寸依次为156025×77006、166010×76105、156004×82290，均与coordinate manifest一致。OpenSlide读出的x/y MPP均0.2457，与niche参数一致。
- 三例panel2仿射链矩阵乘积与记录组合矩阵误差0。六表抽读行重算坐标最大误差<6e-11 px，in_bounds标记与图像尺寸计算一致。此结果证明坐标运算自洽，不证明图像配准或单细胞身份对应准确。
- **组成分母问题已确定**：niche表的五类lineage fraction等于该类count除以五类count之和，误差约1e-16；并不等于该类count除以n_panel。不能直接作为全部细胞组成target，也不能据此把缺测免疫/间质类标成阴性。具体class_fraction另有口径，必须逐项区分。
- **局部配准源不可访问**：三例panel2_source_cells及每例抽查10个registered_he_patch/local_transform原路径均指向不存在的 `/home/hwx/panel2_cell_level_registration/`。公共坐标表可读，但原局部图像变换QC不能复现；已向用户询问搬迁路径。
- 跨panel semantic matching的summary明确写明serial sections，接受的匹配不是同一物理细胞证明；不可把双panel直接当作同一细胞全marker真值。
- tumor-rule版本含 `Tumor_cell` 等派生类别，若其由Tumor ROI规则生成，再用同一ROI评价会形成循环证据；暂不作为独立组织分割真值。

## 可交付的训练准备产物

- `audit.json`：逐例真实图像尺寸、MPP、来源路径、抽读schema、坐标误差、niche比例分母与几何字段。
- `review_candidates.csv`：每例12个、共36个空间分散的128 µm候选复核窗口。窗口由高计数niche中心选出；niche细胞数不是该窗口内细胞数。清单显式记录 `registration_qc=not_verified`，身份与组织监督允许标记均为false，不冒充trainer所需verified manifest。
- `he_review/`：通过 `render_crc_review_candidates.py --audit-dir <上述产物目录>` 实际读取H&E的36个crop及每例一张contact sheet，包含level0坐标。仅供组织外观复核，不代表HE–mIF对齐已验收。
