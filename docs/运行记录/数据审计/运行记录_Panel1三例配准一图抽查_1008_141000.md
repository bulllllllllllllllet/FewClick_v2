# Panel1 三例配准一图抽查

- 用户目的：在一张图上直接检查三张 H&E 与其 mIF DAPI 的局部对应，而不是仅看≤4px匹配的数字。
- 挂载核查：2017原始标注表位于`/nfs-medical5`（服务器10.214.117.186，NFSv4.1）；三例mIF QPTIFF及配准H&E SVS位于`/nfs-medical6`（10.214.117.187）；候选特征缓存位于`/nfs-medical3`（10.214.117.183）。是三个独立挂载。当前只有NFS5原始标注读取超时，NFS6原图和NFS3缓存可读；具体故障在NFS5服务端、网络或客户端挂载的哪一层尚未诊断，不能简单称为“源数据丢失”。
- 输入：三例`panel1_three_case_full_0924_134324_CASE`的候选NPZ、`panel1_candidate_integrity_cache_full_1008_135230`的图块风险表、NFS6各病例配准H&E SVS和mIF Scan1 QPTIFF。QPTIFF page0为DAPI（原始报告通道顺序确认）；相同level0像素坐标取512×512视野。源图只读。
- 抽样：每例一个图块真实/平移对照比≥5、一个≤3，尽量覆盖五类并限制候选量，使图可读。此抽样用于人工检查局部配准，不用于计算全量准确率。
- 图：一张六行×三列PNG，各行按病例/风险层，列为配准H&E、mIF DAPI、HE核信号与DAPI伪彩叠加。每行在HE与DAPI上画同一批候选mIF中心（彩色实点）及匹配HE核中心（白圈），并标图块坐标、匹配数、对照比和颜色类别。另存所选细胞CSV以供追溯。DAPI做每图块对比度拉伸，仅影响显示。
- 运行：`conda run -n aligner python -m benchmarks.v5.tools.visualize_crc_panel1_three_case_registration --output /nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_registration_contact_sheet_1008_141000`，CPU，无GPU；单图块真实smoke后绘制全图。验收：六图块原图可读、尺寸512×512、所画点均在图内，mIF与HE点距离与缓存吻合，PNG及CSV生成。
- 状态：完成。真实2017单图块smoke输出`panel1_registration_contact_sheet_smoke_1008_141000`通过；按同一绘图路径生成三例六图块正式图`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_registration_contact_sheet_1008_141725/three_case_registration_contact_sheet.png`（2040×3519像素）及`displayed_cells.csv`（共84个展示细胞，每图块14个）。全部原图为512×512像素；所画点均在图内，缓存HE/mIF中心距离复算与`match_distance_px`一致、最大展示距离3.975px。原始数据未修改。
- 抽样清单：2017强`x20480_y55808`（比7.11）、低`x23040_y18944`（2.77）；2019强`x21504_y16896`（6.64）、低`x13824_y15872`（2.76）；2022强`x36864_y64000`（5.70）、低`x25088_y20992`（2.88）。这里“强/低”仅指相对于平移对照的匹配数，不是病理标签正确率。
- 阅读重点：先看第三列DAPI核形态与H&E核形态、组织边界是否整体重合，再看同色实点与白圈是否落在同一颗核上；DAPI显示使用每图块对比度拉伸，颜色深浅不能用于marker阳性判断。2017的原始TSV仍因NFS5超时未重读，图中类别为缓存标签，需保留此限制。
