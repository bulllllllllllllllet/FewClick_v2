# Panel1五类细胞H&E上下文可视抽查

- 问题：抽查五类 mIF 对应细胞在注册H&E上的局部外观，比较模型当前128×128输入与256/512像素上下文，评估是否需要更大图块。
- 输入：Panel1空间补充后固定清单`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_spatial_add_0923_131606/`，既有测试预测`panel1_spatial_compare_0923_134500/expanded_augmented_test_predictions.csv`，只读源图像和核mask。类别顺序：上皮、血管内皮、淋巴内皮、CAF、SMA间质。
- 抽样：每类最多2个新增训练细胞，加测试集预测正确/错误各1个；无正确预测时展示错误例，测试细胞不足时全部展示。固定随机种子，优先选择配准距离≤2像素样本；具体样本、预测和核质心核验误差另存CSV。
- 可视化：画出目标HE核轮廓；同一细胞并列显示居中128×128、居中256×256及原始完整512×512图块。128像素是当前分类特征提取的原始空间裁剪（后续resize到224输入编码器）。每类详细图包括2个新增train例及1个预测正确、1个预测错误的既有test例；淋巴内皮没有预测正确的test例，故列出两例错误。
- 验收：样本类别均来自mIF匹配标签；H&E图与核mask尺寸一致、目标核ID存在、轮廓质心与已存HE核中心偏差≤0.1像素；所有原始文件只读。抽查图仅用于人工质控，不作为独立准确率估计或训练数据。
- 实现：`benchmarks/v5/tools/visualize_crc_panel1_context_audit.py`。
- 产物（最终可视化）：`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_cell_context_audit_0923_141206/`，共20例；首版`140603`因512视野边缘填充产生条纹保留但不作为审阅版。
- 状态：完成；Python编译通过，实际20例图像/mask读取及标签、目标核ID、质心误差≤0.1px检查通过。可视图为抽样质控，不是准确率评估。
