# 空间病理 RNA 候选数据可用性核验

问题：为 FewClick v5 的“区域 RNA 仅训练期监督”寻找可直接核验、且比现有 COAD Xenium 更适合组织/TLS program 的配对数据。候选来自 `docs/数据集情况/【7】基因-病理-疾病相关数据.csv`，并逐一只读核对 NFS 实体文件；目录名或 CSV 记录本身不作为可用性证据。

核验时间：09-08 04:50:00。范围仅为数据可用性与模态，不提议此处具体训练实现。

| 优先级 | 数据 | NFS 证据 | 粒度与可用用途 | 限制 |
| --- | --- | --- | --- | --- |
| A | COAD CosMx | `/nfs-medical3/fyx/PKU_DATA/CosMx/COAD/HE.tif`、`transcripts/tx_file.parquet`（8.1 GB）、`transcriptome/adata.h5ad`（2.9 GB）、`segmentation_mask/polygons.csv`（467 MB），并有 5 份 manual segmentation mask | 细胞级 RNA + 细胞边界 + H&E；可按 v4 Phase 2 assignment 聚合为 region target，亦可能用于 TLS/组织 program 的同域验证 | 需下一步只读核对 h5ad/transcript schema、基因 panel、细胞 ID 与 H&E 坐标变换；当前 `aligner` 环境未安装 `anndata/h5py`，尚未读取内部 schema |
| A | Visium HD Human Colon Cancer | `/nfs-medical3/fyx/Visium_HD_Human_Colon_Cancer/` 中有 H&E `.tif`、`feature_slice.h5`、binned output archive、alignment JSON、54,586 行 probe set | H&E + 全转录组的空间 bin/spot；probe set 已核到 EPCAM、KRT8/18/19/20、COL1A1、PTPRC、CD3D/E、MS4A1、CD79A、CXCL13、LYZ、PECAM1、ACTA2、MUC2、HBB、ADIPOQ 等组织/TLS marker。适合区域级 RNA 监督 | 非细胞级；必须读取 binned matrix 和 alignment 后才能确认 bin 坐标、分辨率及是否可映射至 Phase 2 region |

| C | 当前 COAD Xenium | 已有坐标审计与 1,020 cell marker audit | 可作配准和机制 smoke；B/plasma/TLS 有 4 个 marker 覆盖 | panel 对间质/髓系/肌肉/黏液/血液等组织 program 覆盖不足，不能作为全面组织监督主数据 |

结论：下一步的首选不是继续扩大当前 COAD Xenium，而是先做 COAD CosMx 的内部 schema/基因覆盖/坐标三项小审计；若其 panel 仍不足，再转向 Visium HD Colon 的区域级对齐。乳腺与肺 Xenium 是可用的后备多癌种数据，但当前样本数不足以单独支持“多癌种泛化”结论。

验证准则：每个候选至少确认（1）病理图像尺寸与空间坐标系；（2）表达矩阵或 transcripts 的 cell/bin ID 与坐标字段；（3）目标组织/TLS marker 的真实 panel 覆盖；（4）样本/切片数及真实配对关系。四项完成前不进入训练。
