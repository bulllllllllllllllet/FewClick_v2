# COAD RNA–H&E 坐标配准审计

审计目标：独立验证 RNA transcript 点、Xenium cell boundary 与 H&E 共用坐标系，而非只核对
`cell_id`。从本项目 COAD 窗口内 RNA 合格细胞中以固定 seed 抽取 50 个；读取对应 polygon，
逐 transcript 用 point-in-polygon 检查其是否在其 assigned cell boundary 内，并验证 cell
center 是否在 polygon 内。生成 H&E + boundary + transcript overlay 供人工检查。

命令：`conda run -n aligner python benchmarks/v5/phase_3_cell_region/tools/audit_xenium_he_rna_geometry.py --timestamp 0908_040000`。
输出：`/nfs-medical3/zyh/fewclick_v2/rna_geometry_audit/rna_geometry_audit_0908_040000/`。
## 结果

原始严格 polygon-inside 比例为 92.89%，未达到过严的 0px 阈值；补充 point-to-polygon
signed distance 后，50 个细胞的 43,614 条 transcript **100% 位于所属 boundary 内或距边界
不超过 2px**（5px 也为 100%），中位 signed distance `+1.27px`。这说明少量 outside 点均
贴近边界，符合 polygon 整数取整/栅格化差异，不支持存在明显全局平移或尺度错配。

49/50 个 `center_x,center_y` 位于 polygon 内；该 center 是 bbox 中点而非 polygon centroid，
单例不作为配准失败。H&E overlay 未见系统性整体偏移，但细胞很小，人工图仅作辅助证据。

**结论：COAD 当前 RNA–boundary–H&E 共用坐标契约通过，可用于本项目 region RNA target；
精度表述限制为约 2px 边界容差，不宣称亚像素或跨平台配准。**
