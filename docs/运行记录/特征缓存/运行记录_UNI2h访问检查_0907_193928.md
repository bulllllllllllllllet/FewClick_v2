# UNI2-h 权重访问检查

## 目的

按用户要求，将 UNI2-h 作为新的病理 backbone 候选，与 v4 CTransPath 和已测试的 Phikon-v2 做同一 H&E cell crop 的冻结特征对照。该记录只审计权重可获取性；尚未下载、提取 feature 或启动训练。

## 输入与检查

- 候选：Hugging Face `MahmoodLab/UNI2-h`，现有模型选择建议记录在 `docs/建议/模型与训练/建议_PhikonV2替代CTransPath与验证设计_0907_021303.md`。
- 通过 `aligner` 环境的 `huggingface_hub.HfApi` 对模型仓库执行只读文件清单和本机认证检查。
- 预定的后续 smoke 输入（获得权重后）：与 Phikon 相同的 COAD Xenium H&E 实例 crop；输出根应为 `/nfs-medical3/zyh/fewclick_v2/uni2h_smoke/`，GPU 与 acceptance criterion 在启动前另行记录。

## 结果与阻塞

- 仓库元数据可见：`ACCESS_OK`，包含 `config.json` 与 `pytorch_model.bin`。
- 本机 `HfApi.whoami()` 返回 `LocalTokenNotFoundError`：没有 Hugging Face token。UNI2-h 的权重下载受访问条款/认证控制，因此当前不能开始下载或 smoke。
- 所需外部操作：用户在 Hugging Face 接受 `MahmoodLab/UNI2-h` 的访问条款，并在本机以拥有访问权限的账户执行一次 `hf auth login`。不要在聊天中提供 token。
- 在此之前不以替代权重、镜像或未审计 checkpoint 继续，避免损坏公平 backbone 对照。
