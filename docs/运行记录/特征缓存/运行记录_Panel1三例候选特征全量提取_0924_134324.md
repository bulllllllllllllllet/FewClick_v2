# Panel1 三例候选特征全量提取

- 目标：继续三张 H&E 的五类候选细胞特征提取，不将原始 419.8 万 mIF 标注声称为可训练 H&E 样本。
- 输入：extract_crc_panel1_three_case_cells.py 中 CASES 的三例配准 SVS 与原始 cell_tables；源数据只读。
- 先前证据：0923_201400 两例各 12 图块试提取完成，2017 得到 374、2022 得到 553 个候选特征；旧流程先筛五类再匹配，不能作为修正后正式计数。
- 修正：移除小于 1000 字节标注文件的筛除；双向最近邻在全部源细胞类别上计算，距离≤4像素后才筛五类；128px 安全边界不变。逐图块保存 JSONL 审计及 NPZ，保存原始标签、权重与代码哈希。
- 配准限制：全局配准图局部可有偏移；新增四方向平移32像素的零假设匹配计数用于审计。不凭距离自动宣称标签已验证，不自动以新阈值删样本；训练前需独立筛查配准质量并制定空间划分。本次是冻结编码器候选缓存，无训练/拟合。
- 命令：aligner Python -m benchmarks.v5.tools.extract_crc_panel1_three_case_cells --case CASE --output OUTPUT --device cuda:GPU --encode；smoke 加 --max-patches 32，正式不限制图块数。
- 输出根：/nfs-medical3/zyh/fewclick_v2/semantic_phase3/panel1_three_case_{smoke,full}_0924_134324_CASE。
- 资源：2017 GPU1、2019 GPU3、2022 GPU4，各8 CPU线程；tmux 独立会话及带 EXIT_CODE 日志。
- 验收：每例先真实32图块运行，至少有实际768维有限特征；完整执行后审计 processed_patches == source_patch_tables，核对每例每类计数及平移对照。不以新缓存说明分类/分割已有改善。
- 状态：修正后真实 smoke 待运行；完成后决定全量启动。
