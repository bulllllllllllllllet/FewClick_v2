# Panel1三例全切片细胞特征可行性

- 目标：为三例panel1 H&E的五类明确mIF细胞提取可比较的128像素冻结CTransPath特征，先核验另外两例的逐细胞HE–mIF配准质量。
- 已知源：00538F已有7,055份HE核匹配表与相应mask；23800D和39941E的`large_context_sift_registration`局部patch分别仅1,199、1,631份，变换状态均无`ok`，抽样patch为全白。两例整张配准SVS在中下部有实际组织。
- 标注总数：三例4,197,639个mIF细胞，其中五类规则可映射1,637,314个；这些均是原始标注数，不是H&E已匹配细胞。
- 方法：从整张配准SVS在mIF标注patch坐标读取512像素HE区域；用同一CPSAM检测HE核，与该mIF patch五类细胞质心作双向最近邻≤4像素匹配；检查128裁剪安全边界，再以HE目标核soft attention和冻结CTransPath抽768维特征。每patch单独存储特征与匹配审计，支持分片运行。
- 先行验收：2017与2022病例各抽取空间分散的多个真实patch，报告检测核数、五类候选数、匹配率和特征形状；只有匹配稳定才扩大到全切片。其他类别保持原始标签，不并入五类。
- 资源：源数据只读，输出仅位于`/nfs-medical3/zyh/fewclick_v2/semantic_phase3/`时间戳目录；GPU1、8CPU线程；长任务tmux日志记录EXIT_CODE。
- 状态：可行性验证中。
