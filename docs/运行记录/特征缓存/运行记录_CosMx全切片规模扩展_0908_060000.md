# CosMx 全切片规模扩展

问题：此前 paired-vs-shuffled gate 只使用 COAD CosMx 单张切片的 4 个局部 view（36 patch、3,530 个 RNA target cell），数量可能不足以区分随机波动与真实 H&E→RNA 信号。用户明确要求当前阶段先不以跨病人泛化为门槛，优先扩大同一切片内训练样本。

方案：先只读扫描全量 `polygons.csv` 和 `tx_file.parquet` 各一次，建立逐 cell 的 H&E 坐标、面积、总 transcript 数和 6 个固定语义 program score 索引。随后从全 WSI 挑选不重叠的 1536px H&E view，目标为 64 个有效 view（576 个 512px patch）；每个 view 内仍以冻结 H&E-only XCellFormer 提取输入 feature，并用全部 RNA cell 聚合 target。不会把 RNA 作为输入。

输入：`/nfs-medical3/fyx/PKU_DATA/CosMx/COAD/{segmentation_mask/polygons.csv,transcripts/tx_file.parquet,HE.tif}`，已完成的 CosMx affine contract，及冻结 v4 Phase 2/XCell 权重。

输出根：`/nfs-medical3/zyh/fewclick_v2/cosmx_fullslide_rna_cache/`，每阶段使用 `MMDD_HHMMSS` 子目录。

第一阶段命令：`conda run -n aligner python benchmarks/v5/phase_3_cell_region/tools/build_cosmx_fullslide_cell_index.py --timestamp 0908_060000`。CPU 运行，tmux `fewclick_cosmx_index_0908_060000`，日志在 output root。验收：cell ID 去重；坐标经已审计 affine 在 H&E 范围；6 个 program 和总 transcript 均 finite；输出 index 仅包含 derived metadata，不复制源数据。

风险与边界：同一张切片的 64 个 view 仍不等于 64 个独立病人；该实验只检验“样本量不足”这一解释。若大规模 paired 仍不超过 shuffle，就不以“细胞数少”为由继续扩大同一监督目标。

当前状态：待实现和运行。
