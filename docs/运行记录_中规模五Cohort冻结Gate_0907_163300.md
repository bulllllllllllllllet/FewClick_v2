# 中规模五 cohort 冻结 H&E gate

## 目的

使用完成的 2,266-cell cohort-sharded H&E dual-view feature cache，重跑 leave-one-cohort-out frozen cell-adapter gate，判断将每类样本从约 8 扩大至最多 64 后，正确 H&E 配对能否稳定胜过 feature-label 打乱对照。

## 输入与设计

- manifest：`/nfs-medical3/zyh/fewclick_v2/multisection_cell_manifest/multisection_cell_manifest_0907_161850/`
- cache：`/nfs-medical3/zyh/fewclick_v2/multisection_cell_feature_cache/multisection_cell_feature_cache_0907_162801/`；首先要求 `index.json` 为 `all_complete=true`，再逐 shard 验证 `cell_id` 与 feature 顺序。
- 5 个 held-out cohort；每 fold 的其余 4 cohort 训练。`paired_he` 与仅打乱训练 feature-label 对应的 `shuffled_he` 各 3 seeds。
- 训练的是冻结 Phikon 特征上的 adapter/classifier；RNA 不读取、不输入模型。

## 运行与验收

- 输出：`/nfs-medical3/zyh/fewclick_v2/multisection_cell_gate/multisection_frozen_gate_0907_163300/`
- 单 GPU，tmux `fewclick_medium_gate_0907_163300`；日志 `/nfs-medical3/zyh/fewclick_v2/multisection_cell_gate/logs/multisection_medium_gate_0907_163300.log`。
- 接受条件：所有 shard identity、feature `[N,2048]`、loss 和 split isolation 通过；全体 held-out 的 paired macro-F1 与 balanced accuracy 均超过 shuffled。无论结果如何，都仍非独立 donor/patient 验证。

最终状态待运行完成后追加。

## 最终状态

- 完成，`EXIT_CODE=0`；五个 cache shard 的 cell identity 逐一通过，feature 矩阵为 finite `[2266,2048]`；5 held-out cohort × 2 arms × 3 seeds 的 split 均无 cohort 重叠。
- 正确 H&E 配对：macro-F1 `0.1247`、balanced accuracy `0.1305`；打乱对照：`0.1264`、`0.1273`。BA 增益 `+0.0032`，但 macro-F1 为 `-0.0017`，不满足两个主指标均超过 shuffled 的接受条件。
- 与 288-cell gate 相比，paired macro-F1 从 `0.1180` 升至 `0.1247`，但仍接近 8 类机会水平且不稳定。结论：单纯将每类样本扩至最多 64 并不足以证明冻结 Phikon H&E 特征的跨 cohort cell-type 泛化；不进入 LoRA/RNA teacher 或正式全量训练。

结果：`/nfs-medical3/zyh/fewclick_v2/multisection_cell_gate/multisection_frozen_gate_0907_163300/`。
