# FewClick_v2 v5 development area

This directory is reserved for new FewClick_v2 methods, beginning with RNA/spatial-omics-enhanced Phase 3 cell-to-region features.

Do not edit the copied `benchmarks/v4/` baseline to implement v5 methods. Keep v5 imports under `benchmarks.v5` and record each experiment's source revision and timestamped artifact path under `/nfs-medical3/zyh/fewclick_v2/`.
