```bash
CUDA_VISIBLE_DEVICES=3 /home/zhaoyh/miniconda3/envs/aligner/bin/python \
  -m benchmarks.v5.generic_cell_control.gate --catalog FIXED_CATALOG \
  --output NEW_TIMESTAMPED_OUTPUT
```

实际两训练样本CRC/TIGER×fine/2x/4x六项输入已通过：fine复用原核实例，context重做原InstanSeg；细胞位置/面积/未知类型、数量和顺序一致，原XCell74维参考逐值误差0。保存raw768、geometry10及实例，独立磁盘重放和核计数也通过。组织GT路径禁用，输入特征提取不读GT。

这是原生输入门控，不是完整1737视野缓存、64维变换拟合、受控训练或精度实验。后续转换若采用PCA/标准化，只能在训练细胞拟合，不改变模型74维细胞接口，且不得按验证分数挑变换。普通H&E外观控制不等于同数据同网络预训练目标的因果消融。

## 完整提取入口与已发现的历史依赖

`extract.py`的新mod3分片原型及其失败输出只保留作审计证据，不能用于正式全缓存。两个旧缓存分片的首项在冷启动时重放误差0，放到新调用前序后会改变部分核面积和外观；这不是浮点末位误差，未放宽原身份断言。底层具体算子尚未隔离，不推断为标签或训练泄漏。

正式版本为`history_extract.py`：读取原context准备目录的`completed.jsonl`，恢复原进程分组和图像顺序、构造顺序及逐调用推理模式。三个同源码门控（原双域4视野、旧02/03组各前2视野）共24尺度条目全部误差0后，才启动四个完整历史组。原4视野完整门控raw显式复用；联合应精确覆盖1737个视野、5211尺度条目。任一新差异仍停止对应组，不重试或代换样本。

`fit.py --gate`已在1530个真实训练细胞验证PCA64及投影回放；独立直接协方差核对通过。`--wait-for-shards`只观察真实存活计算进程，等全部完整产物后才拟合；fit仅打开train raw768，不读取val raw或reference74。原完整4视野门控只作为其自身四个完整历史成员复用，不能用部分门控代替全池。

固定报告不whiten PCA64及同主成分whiten PCA64两种尺度条件，不按验证结果挑选。新增敏感性的依据是训练输入中原始与对齐特征数值尺度相差明显，非观察控制模型成绩后的调参。二者都维持10+64维接口；完整受控训练和精度仍待。
